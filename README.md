# happinesea-site

happinesea.com の公開Webサイトです。

製品情報、技術マニュアル、サポート、航空・RC・ドローン分野の業界・技術情報を、static siteとして提供します。Radiolink製品を最初の実運用ケースとします。

## Technology

- Astro
- AstroWind-based UI
- Starlight
- Tailwind CSS
- Static Site Generation
- GitHub Pages

## Public-data policy

このリポジトリには、公開可能と確認された情報のみを保存します。内部運用情報、認証情報、未公開情報、内部AI設定は含みません。

製造・小売分野の商品情報、manual、support、related knowledgeをstatic publishingへ接続するreference implementationです。
