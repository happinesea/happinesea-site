### 2. 受信機プロトコルの選択

<span id="r8fgh-w014" data-translation-unit="r8fgh-w014"></span>

R8FGHをRC8Xと使用する場合は、先にRC8Xで正しい受信機プロトコルを選択し、その後バインドしてください。RC8Xの「Basic Menu」から「Receiver setting」を開き、FHSS V1またはFHSS V2を選択します（下図参照）。R8FGHは両プロトコルに対応します。FHSS V1のPWM出力分解能は2048、FHSS V2は4096です。分解能が高いほどサーボの動作角度を細かく制御できます。このため、R8FGHではFHSS V2の選択を推奨します。

### サーボ速度の設定方法

<span id="r8fgh-w023" data-translation-unit="r8fgh-w023"></span>

(1) 送信機：RC8XのファームウェアをV1.1.5以降に更新し、FHSS V2を選択すると、この項目が表示されます。サーボ速度は14 ms、4 ms、3 msから選択できます。既定値は14 ms（アナログサーボ用）で、4 msと3 msはデジタルサーボ用です。

<span id="r8fgh-w024" data-translation-unit="r8fgh-w024"></span>

(2) 受信機：デジタルサーボを使用する場合は、サーボ速度を4 msまたは3 msに選択する必要があります。受信機もデジタルサーボに対応している必要があります。R8FGHはデジタルサーボに対応します。
(3) 状態表示：サーボ速度を切り替えたときに受信機の緑色LEDが1回点滅すれば、切り替え成功です。切り替えても緑色LEDが点滅しない場合は、切り替え失敗を示します。

<span id="r8fgh-w025" data-translation-unit="r8fgh-w025"></span>

### 4. バインド

<span id="r8fgh-w026" data-translation-unit="r8fgh-w026"></span>

各受信機には固有のIDコードがあり、使用前に送信機とのバインドが必要です。バインドが完了するとIDコードが送信機に保存されるため、再バインドは不要です。新しく購入したR8FGHを送信機で使用するには、バインドを行ってください。

<span id="r8fgh-w027" data-translation-unit="r8fgh-w027"></span>

### バインド手順

<span id="r8fgh-w028" data-translation-unit="r8fgh-w028"></span>

(1) RC8Xで受信機プロトコルを選択します（第2章「受信機プロトコルの選択」参照）。注：RC6GS/RC4GS/T8S/T8FBなど、RC8X以外の送信機を使用する場合は、手順(2)に進んでください。

<span id="r8fgh-w029" data-translation-unit="r8fgh-w029"></span>

(2) 送信機と受信機を約60 cmの距離に近づけます。

<span id="r8fgh-w030" data-translation-unit="r8fgh-w030"></span>

(3) 送信機と受信機の電源を入れると、R8FGHのLEDがゆっくり点滅し始めます。

<span id="r8fgh-w031" data-translation-unit="r8fgh-w031"></span>

(4) 受信機側面の黒いバインドボタン（ID SET）を1秒より長く押してから離します。LEDが速く点滅し、バインド処理中であることを示します。

<span id="r8fgh-w032" data-translation-unit="r8fgh-w032"></span>

(5) LEDの点滅が止まり常灯するとバインド完了です。送信機のIPS画面上部に電波塔のアイコンが表示されます（右図参照）。失敗した場合はLEDがゆっくり点滅し続けます。上記の手順を繰り返してください。

<span id="r8fgh-w033" data-translation-unit="r8fgh-w033"></span>

<ManualFigure src="/assets/radiolink/r8fgh/web-ja-v1/r8fgh-p4-f2.jpeg" width={770} height={300} figureId="r8fgh-p4-f2" alt={"バインド成功後の送信機電波塔アイコンの表示例。"} caption={"バインド成功後の送信機電波塔アイコンの表示例。"} />

<span id="r8fgh-w034" data-translation-unit="r8fgh-w034"></span>

原典印刷ページ：4

<span id="r8fgh-w035" data-translation-unit="r8fgh-w035"></span>

### 注記

<span id="r8fgh-w036" data-translation-unit="r8fgh-w036"></span>

:::caution[注意]
1. 送信機と受信機の電源が入っている状態で、バインドに失敗した場合や信号が失われた場合は、R8FGHのLEDが点滅し続けます。
:::

<span id="r8fgh-w037" data-translation-unit="r8fgh-w037"></span>

:::caution[注意]
2. 送信機と受信機が近すぎると、信号のブロッキングによりバインドに失敗したり、信号が失われたりする場合があります。バインド成功後も、RC8XとR8FGHが近すぎる場合（例えば60 cm以内）、信号のブロッキングにより信号が失われることがあります。両者をさらに離すと、信号喪失は自動的に解消します。
:::

### 6. サブID

<span id="r8fgh-w066" data-translation-unit="r8fgh-w066"></span>

RC8Xは複数の受信機とバインドできます。RC8Xと複数の受信機のバインドが成功し、RC8Xとバインド済みのすべての機器の電源を同時に入れた場合、次の2通りの使用方法があります。

<span id="r8fgh-w067" data-translation-unit="r8fgh-w067"></span>

1. サブID機能をオフにすると、RC8Xで複数の機器を同時に操作できます。

<span id="r8fgh-w068" data-translation-unit="r8fgh-w068"></span>

2. サブID機能をオンにすると、選択したサブIDに応じて特定の機器を操作できます。RC8Xには16グループのサブIDがあり、各IDが受信機1台に対応します。先にサブIDを設定しておくと、すべての機器の電源が入っている状態でも、サブID機能でそのうち1台を操作できます。このとき、ほかの機器は待機状態になります。

<span id="r8fgh-w069" data-translation-unit="r8fgh-w069"></span>

例：RC8Xをトラックと車にバインドして、すべての電源を入れます。まずRC8Xで車をトラックの荷台まで走らせ、その後トラックの受信機IDに切り替えて、車を目的地まで運び戻します。

<span id="r8fgh-w070" data-translation-unit="r8fgh-w070"></span>

### サブIDモードの設定手順

<span id="r8fgh-w071" data-translation-unit="r8fgh-w071"></span>

<span id="r8fgh-w079" data-translation-unit="r8fgh-w079"></span>

R8FGHはジャイロを内蔵し、PWM信号だけでなくSBUS信号も出力できます。通常のPWMモード、SBUSモード、ジャイロモード、ジャイロ＋SBUSモードの4種類があります。各モードのチャンネル信号は次のとおりです。

### 7.1 動作モードの設定

<span id="r8fgh-w082" data-translation-unit="r8fgh-w082"></span>

ジャイロのオン／オフ：2秒以内にバインドボタンを3回短く押すと、ジャイロのオン／オフが切り替わり、LEDの色も切り替わります。

<span id="r8fgh-w083" data-translation-unit="r8fgh-w083"></span>

ジャイロの動作方向の切り替え：2秒以内にバインドボタンを2回短く押すと、ジャイロの動作方向が切り替わります。

<span id="r8fgh-w084" data-translation-unit="r8fgh-w084"></span>

SBUSのオン／オフ：バインドボタンを1回短く押すとSBUSのオン／オフが切り替わり、LEDの色も切り替わります。SBUS信号を有効にすると、CH1～CH7はPWM信号、CH8はSBUS信号を出力します。

### 8. ジャイロの概要

<span id="r8fgh-w090" data-translation-unit="r8fgh-w090"></span>

### 8.1 ジャイロ機能

<span id="r8fgh-w091" data-translation-unit="r8fgh-w091"></span>

R8FGHはジャイロを内蔵しています。高性能ジャイロはソフトウェアフィルターとPIDアルゴリズムを採用し、感度を迅速かつ正確に補正して安定性を高めます。さまざまな模型に柔軟に対応し、ドリフトカーでも本格的な性能を発揮できます。

<span id="r8fgh-w092" data-translation-unit="r8fgh-w092"></span>

### 8.2 ジャイロの有効化

<span id="r8fgh-w093" data-translation-unit="r8fgh-w093"></span>

R8FGHのジャイロ機能は既定でオフです。内蔵ジャイロはセルフチェックを行うため、電源を入れるときはR8FGHを静止させておくことが重要です。赤色LEDがジャイロの状態を示し、赤色LEDの消灯はジャイロなしを示します。バインドボタンを3回（各間隔1秒未満）押すと、赤色LEDが3回点滅し、ジャイロが有効になったことを示します。

<span id="r8fgh-w094" data-translation-unit="r8fgh-w094"></span>

:::caution[注意]
注意：受信機に接続したサーボが動き続けることがありますが、ジャイロ機能がオンの場合、サーボの操舵角を自動的に補正するためで、正常です。この機能が不要な場合は、ジャイロをオフにできます。
:::

<span id="r8fgh-w095" data-translation-unit="r8fgh-w095"></span>

:::caution[注意]
受信機を動かしていないのにサーボが動き続ける場合、次の2つの原因があります。
:::

<span id="r8fgh-w096" data-translation-unit="r8fgh-w096"></span>

:::caution[注意]
① サーボが受信機のSBUSチャンネルに接続されています。標準サーボはPWM信号入力のみに対応するため、CH1/2/3/4/5/6/7に接続し直してください。
:::

<span id="r8fgh-w097" data-translation-unit="r8fgh-w097"></span>

:::caution[注意]
② ジャイロ感度が高すぎます。DL1スイッチを回して感度を下げてください。
:::

<span id="r8fgh-w098" data-translation-unit="r8fgh-w098"></span>

### 8.3 ジャイロのリバース

<span id="r8fgh-w099" data-translation-unit="r8fgh-w099"></span>

ジャイロを正方向に設定し、車体を左右に向けて動作を確認します。車体を右へ向けると車輪は左へ、車体を左へ向けると車輪は右へ動きます。逆に動作する場合は、バインドボタンを2回押します。赤色LEDが2回点滅し、ジャイロのリバースが修正されます。

<span id="r8fgh-w100" data-translation-unit="r8fgh-w100"></span>

### 8.4 ジャイロ感度の調整

<span id="r8fgh-w101" data-translation-unit="r8fgh-w101"></span>

RC8Xでは、既定でDL1/PS3ノブスイッチが操作するCH8でジャイロ感度を調整します。DL1/PS3ノブを時計回りに回すと感度が上がり、反時計回りで下がります。ノブを回すと画面上部に黄色い背景の案内が表示され、チャンネルの値も変化します。＋100に近いほど感度が高くなります。値が0の場合はジャイロ機能がオフです。他のスイッチを割り当てたり、設定画面で調整したりすることもできます。

<span id="r8fgh-w102" data-translation-unit="r8fgh-w102"></span>

### 10. アンテナ取り付け時の注意

<span id="r8fgh-w111" data-translation-unit="r8fgh-w111"></span>

信号伝送を最大限に活かすため、次の事項を強く推奨します。

<span id="r8fgh-w112" data-translation-unit="r8fgh-w112"></span>

(1) 模型を操作する前にRSSI（受信信号強度表示）をテストしてください。方法は https://www.radiolink.com/newsinfo/561239.html を参照してください。

<span id="r8fgh-w113" data-translation-unit="r8fgh-w113"></span>

:::caution[注意]
(2) 模型を操作する前に、受信機と送信機のアンテナを確認してください。受信機の灰色の線は同軸ケーブルで、先端の長さ約4～5 cmの透明な線がアンテナです（下図参照）。透明な線が切れたり損傷したりすると、操縦距離に直接影響します。異常が見つかった場合は、速やかに受信機アンテナを交換してください。
:::

<span id="r8fgh-w114" data-translation-unit="r8fgh-w114"></span>

<ManualFigure src="/assets/radiolink/r8fgh/web-ja-v1/r8fgh-p12-f1.jpeg" width={1000} height={270} figureId="r8fgh-p12-f1" alt={"アンテナ、同軸ケーブル、バインドボタンの位置。"} caption={"アンテナ、同軸ケーブル、バインドボタンの位置。"} />

<span id="r8fgh-w115" data-translation-unit="r8fgh-w115"></span>

(3) アンテナはできるだけまっすぐにしてください。曲がっていると有効操縦距離が短くなります。

<span id="r8fgh-w116" data-translation-unit="r8fgh-w116"></span>

<ManualFigure src="/assets/radiolink/r8fgh/web-ja-v1/r8fgh-p12-f2.jpeg" width={700} height={383} figureId="r8fgh-p12-f2" alt={"2本のアンテナを90°の角度に配置する例。"} caption={"2本のアンテナを90°の角度に配置する例。"} />

<span id="r8fgh-w117" data-translation-unit="r8fgh-w117"></span>

(4) 右図のように、2本のアンテナを90°の角度に配置してください。

<span id="r8fgh-w118" data-translation-unit="r8fgh-w118"></span>

(5) 大型の模型には信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状況でも最良の信号状態を保つため、アンテナを模型の両側に配置してください。

<span id="r8fgh-w119" data-translation-unit="r8fgh-w119"></span>

:::caution[注意]
(6) アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に折り曲げないでください。
:::

<span id="r8fgh-w120" data-translation-unit="r8fgh-w120"></span>

(7) アンテナをモーター、ESC、その他の干渉源となり得るものから離してください。

<span id="r8fgh-w121" data-translation-unit="r8fgh-w121"></span>

(8) 受信機の取り付け時は、振動を防ぐためスポンジや発泡材を使用することを推奨します。

<span id="r8fgh-w122" data-translation-unit="r8fgh-w122"></span>

:::caution[注意]
(9) 受信機には高精度な電子部品が含まれています。強い振動や高温を避けてください。
:::

<span id="r8fgh-w123" data-translation-unit="r8fgh-w123"></span>

(10) 受信機を保護するため、RC用の発泡材やゴム布などの専用防振材で包みます。密閉性の高いビニール袋に入れることで、制御不能の原因となり得る湿気やほこりを防げます。
