## 第1章 はじめに

### 1.1 安全上の注意

1. 雨の中で送信機を使用しないでください。送信機に湿気が入らないようにしてください。

<span id="t8fb-bt-p4-weather-exception" data-translation-unit="t8fb-bt-p4-weather-exception"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="t8fb-bt-p4-safety-remaining" data-translation-unit="t8fb-bt-p4-safety-remaining"></span>

2. 雨や雪のときは使用しないでください。送信機器が影響を受け、機体を制御できなくなったり、事故が発生したりするおそれがあります。
3. 人が密集した場所や法令で禁止されている場所で使用しないでください。
4. 14歳未満の子どもに本製品を触らせないでください。本製品は玩具ではありません。子どもがいる場所で操作するときは十分に注意してください。
5. 安全に飛行できるよう、飛行時は現地の法令を厳守してください。
6. 電源を入れる前にスロットルスティックとトリムボタンが最下端にあることを確認します。送信機の電源を入れ、電源容量が十分であることを確認してから、受信機の電源を入れてください。
7. 模型を操作する前に、各サーボが対応するスティック方向と一致して動くことを確認してください。一致しない場合は使用前に調整してください。
8. 使用を終えるときは受信機と制御対象機器の電源を先に切り、その後で送信機の電源を切ってください。順序を逆にすると制御を失い、事故につながるおそれがあります。
