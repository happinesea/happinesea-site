### 取扱説明書

<span id="su04-w006" data-translation-unit="su04-w006"></span>

### はじめに

<span id="su04-w007" data-translation-unit="su04-w007"></span>

SU04は送受信一体型の超音波センサーで、PIXHAWKおよびMINI PIXに対応します。ドローンの水平8方向の自律障害物回避、上方向の障害物回避、下方向の高度保持を支援します。検出距離は40 cm～450 cmです。フライトコントローラーには3つのモジュールを同時接続でき、接続ポートはtelem1、telem2、i2cです。

:::note[原典について]
文書版・発行日・対象SU04 Revisionは不明です。基板写真にはSR05 V1.0等の表示がありますが、SU04との同一性・対応Revisionは確定できません。写真のMini Pix V1.0等もSU04の文書版へ転記しません。
:::
