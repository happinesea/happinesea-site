<span id="f121-p2-safety" data-translation-unit="f121-p2-safety"></span>

:::caution[注意]
- 悪天候時には模型を操作しないでください。視界が悪いと方向を見失い、模型の制御を失うおそれがあります。
- 人混みや法律で使用が禁止されている場所では使用しないでください。
- 受信機の接続前に、送信機のトリムが0で、バッテリーが適切に充電されていることを確認してください。
- 飛行中は、高速回転するプロペラやブラシモーターなどで負傷しないよう、機体から一定の距離を保ってください。
- 着陸後は、ディスアームされ、プロペラが止まっていることを確認してから、機体へ近づいて触れてください。
- 必ず受信機や機体の電源を切ってから、送信機の電源を切ってください。
- 飛行中に外れないよう、プロペラの取り付け指示に従ってください。
- 良好な無線通信のため、高圧電線、通信基地局、送信塔などの干渉がない場所で飛行してください。
:::

## 第2章 飛行前の準備

### 2.1 電源

T8S送信機：満充電であることを確認してください。

F121：付属の1S LiPoバッテリーは出荷時に満充電ではないため、飛行前にCM120で充電してください。1S LiPo専用のCM120は、CB86PLUSの専門的な開発技術と高精度を受け継ぎ、より安全な充電とバッテリー寿命を確保します。

<span id="f121-p5-f1-unit" data-translation-unit="f121-p5-f1-unit"></span>

<ManualFigure src="/assets/radiolink/f121/web-ja-v1/f121-p5-f1.jpeg" width={646} height={153} figureId="f121-p5-f1" alt={"RadioLink CM120充電器の写真。赤・緑LEDと2A／1A切替スイッチを表示。"} caption={"RadioLink CM120充電器の写真。赤・緑LEDと2A／1A切替スイッチを表示。"} />

<span id="f121-p5-charging" data-translation-unit="f121-p5-charging"></span>

充電器側面のスイッチで、充電電流を1Aまたは2Aへ設定できます。赤色LEDがゆっくり点滅している間は充電中、緑色LEDが点灯し続けると満充電、赤・緑の交互点滅は異常を示します。

CM120は一般的なUSB端子を使用し、パソコンやモバイルバッテリーを電源にできます。



<span id="f121-p5-input-voltage-warning" data-translation-unit="f121-p5-input-voltage-warning"></span>

:::caution[注意]
注意：電源の出力電圧は5Vを超えてはいけません。
:::

## 2.2 送信機

T8Sの2本のスティックは4つの基本チャンネルに対応します。例はRadioLink T8SのMode2（左スロットル）です。

左スティック：上下のスロットル操作で上昇・下降し、左右のヨー操作で時計回り・反時計回りに旋回します。

右スティック：上下のピッチ操作で前進・後退し、左右のロール操作で左右へ移動します。

## 3.4 F121の電源を入れる

先に1S LiPoバッテリーを満充電にしてください。バッテリーのPH2.0端子をF121へ接続してから、機体底部のバッテリーフレームへ入れます。

(1) 標準ではオレンジ色のプロペラが機首を示します。電源を入れて飛行準備するときは、安全のため操縦者と同じ方向へ向けてください。
(2) 電源を入れると緑色LEDが点滅を始め、消灯すると校正完了です。

## 3.7 バインド

RTF版（T8S＋F121＋バッグ）では、工場出荷時にR8SMを取り付けてバインド済みのため作業不要です。PNP版を購入した場合は、次の手順でバインドしてください。

<span id="f121-p13-folio" data-translation-unit="f121-p13-folio"></span>

原典印刷ページ：11

<span id="f121-p14-binding" data-translation-unit="f121-p14-binding"></span>

PNP版のバインド手順：

(1) 送信機と機体に取り付けた受信機を50cm以内へ近づけます。
(2) 送信機とF121の電源を入れます。
(3) 受信機側面の黒いID SETボタンを1秒を超えて押します。LEDの点滅でバインド開始を示します。
(4) LEDが点灯し続けると完了です。
(5) 次節の方法でアームし、スロットルを軽く上げてモーターが動くか確認します。動かなければバインドをやり直します。

## 第6章 仕様

### 6.1 F121

| 項目 | 原典記載 |
| --- | --- |
| 名称 | F121（高度維持ミニレーシングドローン） |
| 重量 | 47.5g（機体のみ） |
| 機体寸法 | 121×55mm（アンテナ含む。アンテナなしは41mm） |
| 梱包寸法 | RTFバッグ170×210×113mm、単体箱210×163×67mm |
| 送信機周波数 | 2.4G |
| 映像伝送周波数 | 5.8G |
| 材質 | フレーム：カーボンファイバー、カバー・映像伝送／バッテリー台・プロペラガード：プラスチック |
| モーター | ソフトウェアでノイズ低減する8520コアレス |
| プロペラ | 直径65mm GEMFAN |
| 送信機 | RadioLink8チャンネルT8S |
| 受信機 | RadioLink8チャンネルミニ受信機R8SM |
| FC | RadioLink F121 |
| バッテリー | FULLYMAX3.7V 660mA 25C LiPo（mAは原典表記） |
| 充電器 | USB充電器（1A／2A） |
| 飛行時間 | 10分、屋内外対応 |
| 低電圧アラーム | 3.8V未満で緑LEDが速く点滅 |
| 制御距離 | 空中2km（遮蔽物・干渉のない場所での最大値試験） |

:::note[原典について]
FCの緑LED警告は3.8V、OSDの電圧点滅は3.4V未満40秒/3.2V未満と別の表示条件です。異なる表示系統を同じ閾値へ統一しません。原典6.1は緑LED速い点滅、4.3は点滅開始と記載し、点滅速度を他の章へ補完しません。
:::

:::note[原典について]
同梱表は660mAh、仕様6.1は660mAという単位です。容量と電流を推測で統一せず、原文単位を保持して注記します。
:::

### 6.2 映像伝送システム

動作周波数：5.8G（48チャンネル、6バンド×8チャンネル）。出力：25mW／100mW／200mW。電圧：DC3～5.2V（1S）。4.2V時の電流：420mA（25mW）／450mA（100mW）／520mA（200mW）。重量：4.4g。寸法：18.03×16.83×16.55mm。解像度：800TVL。視野角：150度。焦点距離：1.2mm。

画面：3.0インチ、480×272画素。明るさ：230cd/m²、高輝度LEDバックライト。映像方式：NTSC／PAL。AV端子：外部映像入力または内部AV出力。電源アダプター：DC5V／1.5A（USB）。OSD：信号強度、バッテリー、チャンネル。バッテリー：3.7V／1800mAh、満充電で約3.5時間。動作時間：3.5時間。充電時間：3時間。アンテナ端子：RP-SMA（内側ピン）。寸法：155×135×55mm。重量：236.4g（ヘッドバンド・アンテナ含む）。周波数範囲：5362～5945MHz。48チャンネル。
