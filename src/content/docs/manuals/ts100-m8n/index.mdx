## TS100

<span id="ts100-w023" data-translation-unit="ts100-w023"></span>

Radiolink MINI M8N GPS TS100は、Radiolinkのエンジニアが15年間にわたって培った無線技術の経験を生かし、回路図の設計からPCB上の部品配置に至るまで、ICの感度指標の限界を超えるように開発されています。

<span id="ts100-w024" data-translation-unit="ts100-w024"></span>

測位精度は50 cmです。開けた場所では6秒で20基の衛星を捕捉し、谷間でも定点保持が可能です。外観特許を取得しています。

<span id="ts100-w025" data-translation-unit="ts100-w025"></span>

TS100は、Radiolink MINI PIXおよびPIXHAWKに対応します（マルチコプター／ヘリコプター用ファームウェアはV3.5.4以降、固定翼機用はV3.8.0以降）。TS100のコンパスを使用しない場合は、他のフライトコントローラーでも使用できます。

<span id="ts100-w026" data-translation-unit="ts100-w026"></span>

<ManualFigure src="/assets/radiolink/ts100-m8n/web-ja-v1/ts100-p3-f1.jpeg" width={957} height={522} figureId="ts100-p3-f1" alt={"TS100の寸法図。30 mm、32 mm、12 mmの表示があります。"} caption={"TS100の寸法図。30 mm、32 mm、12 mmの表示があります。"} />

<span id="ts100-w027" data-translation-unit="ts100-w027"></span>

### Radiolink MINI M8N GPS TS100の構成

<span id="ts100-w028" data-translation-unit="ts100-w028"></span>

GPSデコーダーチップ：Radiolink M8N GPSは、u-blox UBX-M8030（M8）、72チャンネル、Infineon製MMIC BGA715L7を使用し、単独GNSSの7Nよりも優れています。

<span id="ts100-w029" data-translation-unit="ts100-w029"></span>

GPS／QZSS L1 C/A、GLONASS L10F、BeiDou B1を同時受信し、2つのGNSSを同時に動作させます。

<span id="ts100-w030" data-translation-unit="ts100-w030"></span>

SBAS L1 C/A：WAAS、EGNOS、MSAS。

<span id="ts100-w031" data-translation-unit="ts100-w031"></span>

地磁気センサー：HoneywellのHMC5983と同じ技術を用いたQMC5883L。

<span id="ts100-w032" data-translation-unit="ts100-w032"></span>

アンテナ：ゲイン2.5 dBi、高選択度のセラミックアンテナ。

<span id="ts100-w033" data-translation-unit="ts100-w033"></span>

パワーアンプIC：Infineon製MMIC BGA715L7。

<span id="ts100-w034" data-translation-unit="ts100-w034"></span>

ダブルフィルター：Murata製SAWF（表面弾性波フィルター）。

<span id="ts100-w035" data-translation-unit="ts100-w035"></span>

### パラメータ

<span id="ts100-w036" data-translation-unit="ts100-w036"></span>

1）測位精度：複数のGNSSの同時動作時に50 cm。

<span id="ts100-w037" data-translation-unit="ts100-w037"></span>

2）速度精度：0.1 m/s。最大更新レート：最大10 Hz。

<span id="ts100-w038" data-translation-unit="ts100-w038"></span>

3）最大高度：50,000 m。最大速度：515 m/s。

<span id="ts100-w039" data-translation-unit="ts100-w039"></span>

4）最大加速度：4G。

<span id="ts100-w040" data-translation-unit="ts100-w040"></span>

5）感度：トラッキング・航法は−167 dBm、再捕捉は−163 dBm、コールドスタートは−151 dBm、ホットスタートは−159 dBm。

<span id="ts100-w041" data-translation-unit="ts100-w041"></span>

6）初回測位時間：コールドスタート26秒、ホットスタート1秒。

<span id="ts100-w042" data-translation-unit="ts100-w042"></span>

7）接続端子：電源電圧5 VDC±5%、電流50～55 mA。

<span id="ts100-w043" data-translation-unit="ts100-w043"></span>

8）インターフェース：

A. GPS UARTインターフェース。ボーレート：1.2K／4.8K／9.6K／19.2K／38.4K／57.6K／112.5K。

B. 地磁気センサーI2Cインターフェース。

:::note[原典について]
原典のボーレート列挙は末尾が112.5Kです。115.2Kなどへ推測で修正せず原記載を保持しています。
:::

## コネクターの定義

<span id="ts100-w046" data-translation-unit="ts100-w046"></span>

フライトコントローラーへ接続する側：黒線はGND、黄線はSDA、緑線はSCL、青線はRX、白線はTX、赤線はVCCです。

<span id="ts100-w047" data-translation-unit="ts100-w047"></span>

GPSメイン基板側：白線はRX、青線はTX、赤線はVCC、黒線はGND、緑線はSCL、黄線はSDAです。

<span id="ts100-w048" data-translation-unit="ts100-w048"></span>

<ManualFigure src="/assets/radiolink/ts100-m8n/web-ja-v1/ts100-p4-f1.jpeg" width={973} height={369} figureId="ts100-p4-f1" alt={"配線定義図。"} caption={"原典4頁の図"} />

配線定義図。

|線の色|MINI PIX端子側|MINI GPS端子側|
|---|---|---|
|黒|GND|GND|
|黄|SDA|SDA|
|緑|SCL|SCL|
|青|RX|TX|
|白|TX|RX|
|赤|VCC|VCC|

原図では、MINI PIX端子側は黒・黄・緑・青・白・赤、MINI GPS端子側は白・青・赤・黒・緑・黄の順に表示されています。
