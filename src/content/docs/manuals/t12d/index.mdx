## 第1章 T12Dの送受信システム

### 1.1 安全上の注意

1. 雨天時に屋外で操作したり、水たまりを通過させたり、視界の悪いときに使用したりしないでください。水や雪などの湿気が機器に入ると、異常動作や操縦不能が起こるおそれがあります。
2. 人や道路の近くでは操作しないでください。
3. 本製品は玩具ではなく、14歳未満の子どもには適していません。子どもの手の届かない場所に保管し、子どもがいる場所で操作するときは十分注意してください。
4. 飛行時は現地の法令を厳守し、安全を確保してください。
5. 電源投入前にスロットルスティックとトリムが最下位置にあることを確認します。送信機の電源を入れ、電源が十分であることを確認してから受信機の電源を入れます。
6. 操作する前に、各サーボが対応するスティックの向きに動くことを確認します。一致しない場合は使用前に調整してください。
7. 電源を切るときは先に受信機と制御対象機器、次に送信機の順としてください。逆にすると、操縦不能となり事故につながるおそれがあります。


:::
