## 安全上の注意

:::caution[注意]
1. 雨の中では飛行させないでください。雨や湿気で飛行が不安定になり、制御を失うおそれがあります。雷が発生しているときは絶対に飛行させないでください。雨、霧、雷、風のない良好な天候での飛行を推奨します。
2. 地域の法令・規則を厳守し、安全に飛行させてください。空港や軍事基地などの飛行禁止区域では飛行させないでください。
3. 人混みや建物から離れた、開けた場所で飛行させてください。
4. 飲酒、疲労、その他の精神状態が良くないときは操作しないでください。取扱説明書に厳密に従って操作してください。
5. 高圧電線、高圧送電施設、携帯電話基地局、テレビ放送塔などの電磁干渉源の近くでは注意してください。これらの場所では送信機の無線伝送性能が干渉を受けることがあります。干渉が強いと送信機と受信機の信号伝送が途絶え、墜落するおそれがあります。
6. 説明書に従ってプロペラを取り付けてください。逆向きのプロペラを取り付けると墜落するおそれがあります。

:::

<span id="d16pro-p2-disarm-confirmation-warning" data-translation-unit="d16pro-p2-disarm-confirmation-warning"></span>

:::caution[注意]
7. 飛行後はディスアームが完了したことを確認してください。
:::

<span id="d16pro-p2-battery-removal-ambiguous" data-translation-unit="d16pro-p2-battery-removal-ambiguous"></span>

:::caution[原典確認待ち]
飛行後、具体的にいつバッテリーを取り外すかは、原典の記載から確認できていません。以下の注意9は、機体と送信機の電源を切る順序を示します。
:::

<span id="d16pro-p2-body-rest" data-translation-unit="d16pro-p2-body-rest"></span>

8. フライトコントローラーをMission Plannerへ接続するとき、またはESCを校正するときは、機体にプロペラを取り付けないでください。
9. 離陸時は送信機、機体の順に電源を入れてください。飛行終了後は機体のバッテリーを先に抜き、その後で送信機の電源を切ってください。
10. アーム完了時は、安全のため機体から一定の距離を取ってください。飛行開始時はスロットルをゆっくり上げてください。
警告：本製品は玩具ではなく、14歳未満のお子様には適していません。大人はお子様の手が届かない場所に保管し、お子様がいる場所で操作するときは十分注意してください。
