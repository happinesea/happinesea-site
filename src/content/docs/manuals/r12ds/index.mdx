## R12DS
（FHSSおよびDSSSスペクトラム拡散方式）

<span id="r12ds-w002" data-translation-unit="r12ds-w002"></span>

<ManualFigure src="/assets/radiolink/r12ds/web-ja-v1/r12ds-p1-f1.jpeg" width={612} height={245} figureId="r12ds-p1-f1" alt={"R12DS受信機の外観。筐体表記：RadioLink、R12DS、DSSS/FHSS、Status（状態）、2.4GHz、V1.0、4.6-10V/DC、GND、SDA、SCL、VCC、CE、FC、RoHS。図中の表記であり、日本語が実機に表示されることを示すものではありません。"} caption={"R12DS受信機の外観。筐体表記：RadioLink、R12DS、DSSS/FHSS、Status（状態）、2.4GHz、V1.0、4.6-10V/DC、GND、SDA、SCL、VCC、CE、FC、RoHS。図中の表記であり、日本語が実機に表示されることを示すものではありません。"} />

<span id="r12ds-w003" data-translation-unit="r12ds-w003"></span>

Radiolink R12DSは、DSSSとFHSSスペクトラム拡散方式が同時に動作する2.4 GHz・12チャンネル受信機です。Radiolink送信機AT9、AT9S、AT10、AT10IIに対応します（AT9、AT9S、AT10はファームウェアの更新だけで12チャンネルにアップグレードできます。ファームウェアは http://radiolink.com.cn/doce/at10upgraded.html からダウンロードできます。AT10IIは標準で12チャンネルです）。
S-BUS信号とPWM信号は同時に動作できます。

<span id="r12ds-w004" data-translation-unit="r12ds-w004"></span>

<span id="r12ds-w011" data-translation-unit="r12ds-w011"></span>

### SBUS信号とPPM信号の切り替え
1秒以内にID SETスイッチを2回短く押すと、信号がPWMからSBUSへ切り替わります。赤色LEDはPWM、青／紫色LEDはSBUSを示します。

:::note[原典について]
見出しは「SBUS and PPM signal change」だが本文はPWMからSBUSへの切り替え。PPM対応を補完せず原文を維持。
:::

<span id="r12ds-w012" data-translation-unit="r12ds-w012"></span>

### 送信機とのバインド（リンク）方法
1. 送信機と受信機を50 cm以内に近づけます。
2. 送信機の電源を入れてから、R12DSに電源を供給します。
3. R12DSのCH3をESC、フライトコントローラー、またはサーボに接続します。
4. R12DSの黒いバインドボタンを、細い棒またはペンで1秒間押し、受信機のLEDが点滅し始めたら放します。約8回点滅した後、受信機の信号LEDが点灯状態になれば、バインド完了です。

:::note[原典について]
バインドボタンの「in one second」は押下時間の表現が曖昧。1秒間という暫定訳とし実機未確認。
:::

<span id="r12ds-w013" data-translation-unit="r12ds-w013"></span>

### 受信機アンテナの取り付け
1. アンテナはできるだけまっすぐに保ちます。曲がっていると有効範囲が狭くなります。
2. 2本のアンテナを90°に配置します。

<span id="r12ds-w014" data-translation-unit="r12ds-w014"></span>

<ManualFigure src="/assets/radiolink/r12ds/web-ja-v1/r12ds-p3-f1.png" width={501} height={275} figureId="r12ds-p3-f1" alt={"2本のアンテナを90°に配置する例を2種類示しています。図中文字：90°、R12DS。"} caption={"2本のアンテナを90°に配置する例を2種類示しています。図中文字：90°、R12DS。"} />

<span id="r12ds-w015" data-translation-unit="r12ds-w015"></span>

3. 大型模型航空機では、金属部品が信号に干渉する場合があります。この場合はアンテナを機体の両側に配置します。これにより、どの飛行姿勢でも最良の無線信号状態を得られます。

<span id="r12ds-w016" data-translation-unit="r12ds-w016"></span>

<ManualFigure src="/assets/radiolink/r12ds/web-ja-v1/r12ds-p3-f2.png" width={984} height={433} figureId="r12ds-p3-f2" alt={"固定翼機とヘリコプターでのアンテナ配置例。図中のAntennaはアンテナを示します。"} caption={"固定翼機とヘリコプターでのアンテナ配置例。図中のAntennaはアンテナを示します。"} />

<span id="r12ds-w017" data-translation-unit="r12ds-w017"></span>

4. アンテナは、金属やカーボンなどの導電性材料から少なくとも0.5インチ離してください。アンテナの同軸部分にはこの配置条件は適用されませんが、小さな曲げ半径で曲げないでください。
5. アンテナは、モーター、ESC、その他のノイズ源からできるだけ離します。
6. Easy Link（ID SET）を1秒間押し続けると、受信機が動作を開始します。
7. 上記の手順をすべて終えると、LEDインジケーターが赤色で点灯し続けます。
8. 機体に取り付けるときは、衝撃を防ぐため受信機をスポンジや発泡材で包むことができます。
上記の手順をすべて終えたら、各機能を操作し、正しく接続されて送信機で制御できることを確認します。
