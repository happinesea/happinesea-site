### 安全上の注意

<span id="r7fg-w020" data-translation-unit="r7fg-w020"></span>

:::caution[注意]
- 悪天候のときにモデルを操作しないでください。視界が悪いと方向を見失い、モデルを制御できなくなることがあります。
- 人混みや使用が禁止されている場所で本製品を使用しないでください。
- 受信機を接続する前に、トリムレバーが0で、バッテリーが十分に充電されていることを必ず確認してください。
- 走行前に、すべてのサーボと接続状態を必ず確認してください。
- 電源を切るときは、必ず送信機より先に受信機の電源を切ってください。
:::

## 1. R7FGの概要

<span id="r7fg-w033" data-translation-unit="r7fg-w033"></span>

### 1.1 対応送信機

<span id="r7fg-w034" data-translation-unit="r7fg-w034"></span>

RadioLink R7FGは、防滴仕様の2.4 GHz・7チャンネル受信機です。本格的なドリフト走行用のジャイロを内蔵し、高電圧サーボに対応します。RadioLink RC6GS V3／RC6GS V2／RC6GS／RC4GS V3／RC4GS V2／RC4GS／RC3S／RC4G／T8FB／T8Sに対応します。

:::note[原典について]
原典の導入と仕様では送信機の列挙範囲が異なります。それぞれの原典記載を保持し、列挙の省略から非対応を推測したり、別の製品版の条件を補ったりしていません。
:::

## 2. テレメトリー

<span id="r7fg-w052" data-translation-unit="r7fg-w052"></span>

R7FGは、RSSI、受信機電圧、模型用バッテリー電圧などの飛行情報をリアルタイムで送信機へ返すことができます。

<span id="r7fg-w053" data-translation-unit="r7fg-w053"></span>

この機能を使用するには、RC6GS（3ポジションスイッチ版）を、https://www.radiolink.com/rc6gs_firmware からダウンロードしたファームウェア「RC6GS_RadioLink_bin_1d15_V_6_1_2」へ更新してください。

<span id="r7fg-w054" data-translation-unit="r7fg-w054"></span>

または、RC4GS（2018年1月1日より後に製造されたもの）を、https://www.radiolink.com/rc4gs_firmware からダウンロードした「RC4GS_RX_RadioLink_bin_2f50_V_6_0_1」へ更新してください。

<span id="r7fg-w055" data-translation-unit="r7fg-w055"></span>

RC6GS V3、RC6GS V2、RC4GS V3、RC4GS V2を使用する場合は、標準のファームウェアでテレメトリー機能に対応しています。

<span id="r7fg-w056" data-translation-unit="r7fg-w056"></span>

### 2.1 信号とRSSIのテレメトリー

<span id="r7fg-w057" data-translation-unit="r7fg-w057"></span>

送信機と受信機の電源を入れてバインドを完了すると、送信機のメイン画面に信号が表示されます。「EXIT」を2回短押しすると、RSSI値などのテレメトリー情報を表示する画面に入ります。

<span id="r7fg-w058" data-translation-unit="r7fg-w058"></span>

<ManualFigure src="/assets/radiolink/r7fg/web-ja-v1/r7fg-p5-f2.jpeg" width={500} height={500} figureId="r7fg-p5-f2" alt={"RC6GSのメイン画面例。MODEL4、8.0 V、ID01、12.2 V、ST、THが表示されています。"} caption={"RC6GSのメイン画面例。MODEL4、8.0 V、ID01、12.2 V、ST、THが表示されています。"} />

<span id="r7fg-w059" data-translation-unit="r7fg-w059"></span>

<ManualFigure src="/assets/radiolink/r7fg/web-ja-v1/r7fg-p5-f3.jpeg" width={500} height={500} figureId="r7fg-p5-f3" alt={"RC6GSのテレメトリー画面例。RSSI：−31 dBm、RATE：0000 rpm、EXT：12.2 V、RX：4.1 V、T：NULLと表示されています。"} caption={"RC6GSのテレメトリー画面例。RSSI：−31 dBm、RATE：0000 rpm、EXT：12.2 V、RX：4.1 V、T：NULLと表示されています。"} />

<span id="r7fg-w060" data-translation-unit="r7fg-w060"></span>

距離を変えてテストした後、特定の低いRSSI値で警報するように設定できます。

<span id="r7fg-w061" data-translation-unit="r7fg-w061"></span>

「EXIT」と「ENTER」を同時に押してメニューへ入り、「Inc(+)」で「19. ALARM」を選択します。「ENTER」で警報の有効／無効を切り替え、RSSI警報値を設定します。

<span id="r7fg-w062" data-translation-unit="r7fg-w062"></span>

注意：R7FGはデュアルアンテナ受信機です。送信機とR7FGの距離が50 cmのとき、RSSI値が0～−30 dBmの範囲であれば正常です。0に近いほど信号が強いことを示します。RadioLink送信機のRSSI値の範囲は0～−99 dBmです。RSSI値の絶対値が大きいほど、信号は弱くなります。例えば、−90 dBmの信号は−75 dBmの信号より弱いことを示します。

<span id="r7fg-w063" data-translation-unit="r7fg-w063"></span>

### 2.2 模型用バッテリー電圧と受信機電圧のテレメトリー

<span id="r7fg-w064" data-translation-unit="r7fg-w064"></span>

受信機電圧に加え、模型用バッテリーの電圧（最大8Sのリチウムバッテリー）もリアルタイムで送信機へ返すことができます。模型用バッテリーの低電圧警報値は、実際の必要に応じて設定できます。

<span id="r7fg-w065" data-translation-unit="r7fg-w065"></span>

「EXIT」と「ENTER」を同時に押してメニューへ入り、「Inc(+)」で「19. ALARM」を選択します。「ENTER」を押して、模型用バッテリーの電圧警報値を設定します。

<span id="r7fg-w066" data-translation-unit="r7fg-w066"></span>

## 3. サブID

<span id="r7fg-w076" data-translation-unit="r7fg-w076"></span>

サブID機能は、複数のバインド済み受信機の中からサブIDを指定し、その受信機を制御する機能です。RC6GS（3ポジションスイッチ版、最新ファームウェアV6.0.0）またはRC4GS（2018年1月1日より後に製造されたもの、最新ファームウェアV6.0.1）の「ID SEED」メニューで使用できます。送信機には独立したサブIDを合計10個保存できます。

:::note[原典について]
この節の「最新」は原典に記載された時点の表現です。前の節のRC6GS V6.1.2と本節のV6.0.0等を統合せず、現在の最新版と読み替えていません。
:::

<span id="r7fg-w077" data-translation-unit="r7fg-w077"></span>

例えば、RC6GSが10艇の異なるボートとバインドし、それぞれの設定を完了しているとします。「ID SEED」を有効にしてID.1のボートを選び、水面の中央まで操縦したところ、予期せず動作しなくなった場合を考えます。このときID.2のボート（または別の任意のサブIDのボート）へ切り替えて独立して操作し、ID.1のボートを救助できます。2艇を同時に操作して救助を難しくすることはありません。従来のバインド方式とは異なり、独立したIDで簡単に実現できます。

<span id="r7fg-w078" data-translation-unit="r7fg-w078"></span>

「EXIT」と「ENTER」を同時に押してメニューへ入り、「Inc(+)」／「DEC(-)」で「22. ID SEED」を選択します。「ENTER」を押して「MODE」を「OFF」から「ON」へ変更し、サブID番号を設定して、バインドと各パラメータの設定を完了します。

<span id="r7fg-w079" data-translation-unit="r7fg-w079"></span>

完了すると、RC6GSのメイン画面に対応するID番号が表示されます。他の受信機も、続く番号を使って同じ方法でバインドできます。

<span id="r7fg-w096" data-translation-unit="r7fg-w096"></span>

<span id="r7fg-w098" data-translation-unit="r7fg-w098"></span>

<span id="r7fg-w100" data-translation-unit="r7fg-w100"></span>

## 5. ジャイロの説明

<span id="r7fg-w102" data-translation-unit="r7fg-w102"></span>

### 5.1 ジャイロ機能

<span id="r7fg-w103" data-translation-unit="r7fg-w103"></span>

R7FGに内蔵された本格的なドリフト走行用ジャイロは、有効／無効を切り替えられます。有効にすると、競技中の旋回安定性を最大限に高めます。姿勢が乱れた場合にも、車体の直進と正確な旋回を維持します。

<span id="r7fg-w104" data-translation-unit="r7fg-w104"></span>

### 5.2 ジャイロの有効化

<span id="r7fg-w105" data-translation-unit="r7fg-w105"></span>

工場出荷時はジャイロ機能が「OFF」です。「ID SET」を1秒未満の間隔で3回短押しすると、赤のインジケーターが3回点滅します。赤のLEDの点灯／消灯が、ジャイロ機能の有効／無効を示します。

<span id="r7fg-w106" data-translation-unit="r7fg-w106"></span>

### 5.3 ジャイロの補正方向

<span id="r7fg-w107" data-translation-unit="r7fg-w107"></span>

ジャイロの正方向補正を有効にしたら、モデルカーを回して、ジャイロが車輪を補正しているか確認します。通常、車体を左へ回したときは車輪が右へ、車体を右へ回したときは車輪が左へ補正されます。補正方向が逆の場合は、Mode 3またはMode 4でバインドボタン「ID SET」を1秒以内に2回短押しします。インジケーターが1回点滅すると、補正方向の設定完了です。

<span id="r7fg-w108" data-translation-unit="r7fg-w108"></span>

### 5.4 送信機での感度調整

<span id="r7fg-w109" data-translation-unit="r7fg-w109"></span>

ジャイロ感度は、工場出荷時にはCH3に割り当てられており、VRロータリースイッチで調整できます。調整中は割合が表示され、割合が大きいほど感度が高くなります。

<span id="r7fg-w110" data-translation-unit="r7fg-w110"></span>

VRロータリースイッチ／CH3を別の機能に設定している場合は、メニューの「GYRO」設定で「MODE」を「STD」へ変更すると、「Dec(-)」と「Inc(-)」ボタンでジャイロ感度を調整できます。

:::note[原典について]
原典は感度調整ボタンをDec(-)とInc(-)と記載しています。符号を推測で修正せず原表記を保持し、実機UIの確認済みとは扱っていません。
:::

## 7. アンテナの取り付けに関する注意

<span id="r7fg-w131" data-translation-unit="r7fg-w131"></span>

信号伝送性能を最大限に引き出すため、次の点を強く推奨します。

<span id="r7fg-w132" data-translation-unit="r7fg-w132"></span>

<ManualFigure src="/assets/radiolink/r7fg/web-ja-v1/r7fg-p9-f2.jpeg" width={501} height={275} figureId="r7fg-p9-f2" alt={"R7FGの2本のアンテナを90°に配置する例。"} caption={"R7FGの2本のアンテナを90°に配置する例。"} />

<span id="r7fg-w133" data-translation-unit="r7fg-w133"></span>

1. アンテナはできるだけまっすぐにしてください。曲がっていると有効操縦距離が短くなります。

<span id="r7fg-w134" data-translation-unit="r7fg-w134"></span>

2. 下図のように、2本のアンテナを90°の角度にしてください。

<span id="r7fg-w135" data-translation-unit="r7fg-w135"></span>

3. 大型モデルには、信号の送信へ影響する金属部品が含まれる場合があります。その場合は、どのような状況でも最良の信号状態となるよう、モデルの両側へアンテナを配置してください。

<span id="r7fg-w136" data-translation-unit="r7fg-w136"></span>

4. アンテナを金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。

<span id="r7fg-w137" data-translation-unit="r7fg-w137"></span>

5. アンテナをモーター、ESC、その他干渉源になり得るものから離してください。

<span id="r7fg-w138" data-translation-unit="r7fg-w138"></span>

6. 受信機を取り付けるときは、振動を防ぐためスポンジやフォーム材を使用することを推奨します。

<span id="r7fg-w139" data-translation-unit="r7fg-w139"></span>

7. 受信機には高精度の電子部品が含まれています。強い振動や高温を避けるよう注意してください。

<span id="r7fg-w140" data-translation-unit="r7fg-w140"></span>

8. 受信機を保護するため、フォームやゴム布などRC用の防振材で包みます。密封したビニール袋に入れておくと、制御不能の原因になり得る湿気やほこりを防げます。
