### 1. R12Fの概要

<span id="r12f-w016" data-translation-unit="r12f-w016"></span>

RadioLink R12Fは、2.4 GHz FHSSスペクトラム拡散アルゴリズムと67チャンネルの擬似ランダム周波数ホッピングを採用した12チャンネル受信機です。PWM、SBUS、CRSF信号に対応します。高電圧サーボに対応し、ファームウェアの更新で新機能を追加できます。R12FはRadioLink T16D/T12D/T8FB/T8S/RC8X/RC8P/RC6GS V3/RC4GS V3/RC6GS V2/RC4GS V2/RC6GS/RC4GS送信機に対応します。

<span id="r12f-w017" data-translation-unit="r12f-w017"></span>

(1) RSSI（受信信号強度表示）テスト。方法は本書の第7章「RSSIテスト」を参照してください。

<span id="r12f-w021" data-translation-unit="r12f-w021"></span>

:::caution[注意]
(2) アンテナの点検：R12Fの灰色の線は同軸ケーブルで、先端の長さ約4～5 cmの透明な線がアンテナです。透明な線が切れたり損傷したりすると、操縦距離に直接影響します。異常が見つかった場合は、速やかに受信機アンテナを交換してください。

### 4. 動作モード

<span id="r12f-w045" data-translation-unit="r12f-w045"></span>

R12FはPWM、SBUS、CRSFの3種類の信号出力に対応し、合計4種類の動作モードがあります。

<span id="r12f-w046" data-translation-unit="r12f-w046"></span>

### R12Fの動作モード設定

<span id="r12f-w047" data-translation-unit="r12f-w047"></span>

(1) SBUSのオン／オフ：バインドボタンを1回短く押すと、SBUSのオン／オフが切り替わります。青色LEDはSBUSがオンであることを示し、CH12からSBUS信号を出力します。

<span id="r12f-w048" data-translation-unit="r12f-w048"></span>

(2) CRSFのオン／オフ：2秒以内にバインドボタンを2回短く押すと、CRSFのオン／オフが切り替わります。緑色LEDはCRSFがオンであることを示します。CH10はRXを受信し、CH11はTXを出力します。

<span id="r12f-w049" data-translation-unit="r12f-w049"></span>

### 5. ファームウェア更新

<span id="r12f-w070" data-translation-unit="r12f-w070"></span>

R12Fはファームウェア更新に対応しています。更新手順は次のとおりです。

<span id="r12f-w071" data-translation-unit="r12f-w071"></span>

(1) Type-CケーブルをR12FのType-Cポートに接続します。

<span id="r12f-w072" data-translation-unit="r12f-w072"></span>

<ManualFigure src="/assets/radiolink/r12f/web-ja-v1/r12f-p8-f2.jpeg" width={1076} height={777} figureId="r12f-p8-f2" alt={"ファームウェア更新用Type-Cポート。"} caption={"ファームウェア更新用Type-Cポート。"} />

<span id="r12f-w073" data-translation-unit="r12f-w073"></span>

(2) R12Fのバインドボタンを押し続けます。

<span id="r12f-w074" data-translation-unit="r12f-w074"></span>

(3) Type-Cケーブルのもう一端をパソコンに接続してから、バインドボタンを離します。

<span id="r12f-w075" data-translation-unit="r12f-w075"></span>

(4) 受信機のLEDが点灯し、パソコンにUSBドライブが表示されます。

<span id="r12f-w076" data-translation-unit="r12f-w076"></span>

(5) R12Fの新しいファームウェアをUSBドライブにコピー＆ペーストすると、更新が完了します。

<span id="r12f-w077" data-translation-unit="r12f-w077"></span>

### 6. アンテナの取り付け

<span id="r12f-w078" data-translation-unit="r12f-w078"></span>

受信機のアンテナを模型に正しく取り付けることが重要です。取り付け方が正しくないと、信号品質が低下します。アンテナの取り付け方が信号品質に与える影響について、よくある取り付け上の誤りを以下に示します。

<span id="r12f-w079" data-translation-unit="r12f-w079"></span>

:::caution[注意]
(1) アンテナを金属物の近くに配置しないでください。導体面による反射で信号が著しく悪化します。
:::

<span id="r12f-w080" data-translation-unit="r12f-w080"></span>

:::caution[注意]
(2) アンテナを地面と平行にしないでください。地面に対して垂直に配置してください。
:::

<span id="r12f-w081" data-translation-unit="r12f-w081"></span>

(3) 大型の模型には信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状況でも最良の信号状態を保つため、アンテナを模型の両側に配置してください。

<span id="r12f-w082" data-translation-unit="r12f-w082"></span>

:::caution[注意]
(4) アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に折り曲げないでください。
:::

<span id="r12f-w083" data-translation-unit="r12f-w083"></span>

(5) アンテナをモーター、ESC、その他の干渉源となり得るものから離してください。

<span id="r12f-w084" data-translation-unit="r12f-w084"></span>

原典印刷ページ：7

<span id="r12f-w085" data-translation-unit="r12f-w085"></span>

(6) 受信機の取り付け時は、振動を防ぐためスポンジや発泡材を使用することを推奨します。

<span id="r12f-w086" data-translation-unit="r12f-w086"></span>

:::caution[注意]
(7) 受信機には高精度な電子部品が含まれています。強い振動や高温を避けてください。
:::

<span id="r12f-w087" data-translation-unit="r12f-w087"></span>

(8) 受信機を保護するため、RC用の発泡材やゴム布などの専用防振材で包みます。密閉性の高いビニール袋に入れることで、制御不能の原因となり得る湿気やほこりを防げます。

<span id="r12f-w088" data-translation-unit="r12f-w088"></span>

受信機アンテナの取り付けガイドは、次のリンクを参照してください。
https://www.radiolink.com/receiver_antenna_installation

### 7. RSSIテスト

<span id="r12f-w090" data-translation-unit="r12f-w090"></span>

操縦距離が短い場合は、この手順で送信機と受信機の間のRSSIをテストしてください。送信機のRSSI値のテスト手順と、異常なRSSI値への対処方法を説明します。

<span id="r12f-w091" data-translation-unit="r12f-w091"></span>

<ManualFigure src="/assets/radiolink/r12f/web-ja-v1/r12f-p9-f1.jpeg" width={319} height={241} figureId="r12f-p9-f1" alt={"送信機ホーム画面のRSSI表示例。"} caption={"送信機ホーム画面のRSSI表示例。"} />

<span id="r12f-w092" data-translation-unit="r12f-w092"></span>

(1) 送信機と受信機の電源を同時に入れると、両者が接続されます（接続されない場合は再バインドが必要です）。送信機画面に電波塔のアイコンが表示されれば、バインド成功です。ホーム画面にRSSI値が表示され、送信機と受信機の距離に応じて値が変化します（右図参照）。

<span id="r12f-w093" data-translation-unit="r12f-w093"></span>

(2) 受信機と送信機のアンテナを平行にします。両者を約30 cm離し、両アンテナをまっすぐにします。RSSI値が0～−30 dBmの範囲であれば正常です。値が0に近いほど信号が強いことを示します（下図参照）。

<span id="r12f-w094" data-translation-unit="r12f-w094"></span>

<ManualFigure src="/assets/radiolink/r12f/web-ja-v1/r12f-p9-f2.jpeg" width={1076} height={760} figureId="r12f-p9-f2" alt={"送受信機を約30 cm離したRSSIテスト配置例。"} caption={"送受信機を約30 cm離したRSSIテスト配置例。"} />

<span id="r12f-w095" data-translation-unit="r12f-w095"></span>

### 信号強度が異常な場合の対処

<span id="r12f-w096" data-translation-unit="r12f-w096"></span>

受信機と送信機のアンテナに損傷がないか確認してください。信号強度の低下の多くはアンテナの損傷が原因です。損傷している場合は交換が必要です。損傷がない場合は、受信機を交換して送受信機の故障を切り分けることができます。解決しない場合は、after_service@radiolink.com.cnにメールでサポートを依頼してください。

### 8. サブID（T12D送信機を例として）

<span id="r12f-w099" data-translation-unit="r12f-w099"></span>

RadioLink送信機は複数の受信機とバインドできます。T12Dと複数の受信機をバインドし、T12Dとバインド済みのすべての機器の電源を同時に入れた場合、次の2通りの使用方法があります。

<span id="r12f-w100" data-translation-unit="r12f-w100"></span>

1. サブID機能をオフにすると、T12Dで複数の機器を同時に操作できます。

<span id="r12f-w101" data-translation-unit="r12f-w101"></span>

2. サブID機能をオンにすると、選択したサブIDに応じて特定の機器を操作できます。T12Dには16グループのサブIDがあり、各IDが受信機1台に対応します。先にサブIDを設定しておくと、すべての機器の電源が入っている状態でも、サブID機能でそのうち1台を操作できます。このとき、ほかの機器は待機状態になります。

<span id="r12f-w102" data-translation-unit="r12f-w102"></span>

例：T12Dをトラックと車にバインドして、すべての電源を入れます。まずT12Dで車をトラックの荷台まで走らせ、その後トラックの受信機IDに切り替えて、車を目的地まで運び戻します。

<span id="r12f-w103" data-translation-unit="r12f-w103"></span>

### サブID機能の設定手順

<span id="r12f-w104" data-translation-unit="r12f-w104"></span>

1. サブID機能をオンにします。模型に応じてID番号を設定し、各受信機のバインドとパラメータ設定を完了します。

<span id="r12f-w105" data-translation-unit="r12f-w105"></span>

<ManualFigure src="/assets/radiolink/r12f/web-ja-v1/r12f-p10-f1.jpeg" width={636} height={475} figureId="r12f-p10-f1" alt={"T12DのSub ID設定画面。"} caption={"T12DのSub ID設定画面。"} />

:::note[原典について]
サブIDの原典画面にはFHSS V2.1が表示されていますが、この図はサブID表示の説明用です。確認待ちのプロトコルやチャンネル数を推奨・確定する根拠にはしないでください。
:::

<span id="r12f-w106" data-translation-unit="r12f-w106"></span>

2. サブIDをオンにすると、対応するID番号がT12Dのメイン画面に表示されます。

<span id="r12f-w107" data-translation-unit="r12f-w107"></span>

注：T16D/T12D送信機では、2ポジションまたは3ポジションスイッチをサブID番号の切り替えに割り当てることができます。詳しくはT16D/T12Dの「CONDITION」機能を参照してください。
