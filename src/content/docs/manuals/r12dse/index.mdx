### R12DSEの概要

<span id="r12dse-w028" data-translation-unit="r12dse-w028"></span>

RadioLink R12DSEは、制御距離4000 mの小型12チャンネル受信機です。データ伝送機能を内蔵しており、外部センサーなしで送信機の画面に信号強度と受信機電圧の情報を表示し、「RECEIVE」メニューにRSSI値を表示します。テレメトリーモジュールPRM-03およびフライトコントローラーと組み合わせると、さらに多くのテレメトリー情報を画面に表示します。R12DSEはPPMおよびSBUS信号出力に対応し、RadioLink送信機AT10II、AT10、AT9S Pro、AT9S、AT9に対応しています。

### バインド

<span id="r12dse-w031" data-translation-unit="r12dse-w031"></span>

各受信機には固有のIDコードがあり、使用前に送信機とのバインド（リンク）が必要です。バインドが完了すると、IDコードが送信機に保存され、再度バインドする必要はありません。そのため、新しいR12DSEを購入した場合は、送信機で使用するためにバインドを行う必要があります。

<span id="r12dse-w032" data-translation-unit="r12dse-w032"></span>

#### バインド手順

<span id="r12dse-w033" data-translation-unit="r12dse-w033"></span>

1. 送信機とR12DSE受信機を30 cmより離して置きます。

<span id="r12dse-w034" data-translation-unit="r12dse-w034"></span>

2. 送信機とR12DSEの電源を入れます。

<span id="r12dse-w035" data-translation-unit="r12dse-w035"></span>

3. 受信機側面のバインドボタンを1秒より長く押すと、受信機のLED表示が点滅し、バインドが開始したことを示します。

<span id="r12dse-w036" data-translation-unit="r12dse-w036"></span>

4. LED表示の点滅が止まると、バインドは完了です。

<span id="r12dse-w037" data-translation-unit="r12dse-w037"></span>

5. 模型のサーボをテストし、送信機で操作できることを確認します。

<span id="r12dse-w038" data-translation-unit="r12dse-w038"></span>

:::caution[注意]
送信機と受信機の電源が入っているときにR12DSEのLED表示がゆっくり点滅する場合は、バインドされていないか、飛行中に受信機が信号を失ったことを示します。
:::

<span id="r12dse-w039" data-translation-unit="r12dse-w039"></span>

<ManualFigure src="/assets/radiolink/r12dse/web-ja-v1/r12dse-p4-f2.jpeg" width={500} height={300} figureId="r12dse-p4-f2" alt={"送信機の「SYSTEM」画面。「CH-SELECT」が「12CH」に設定された例です。"} caption={"送信機の「SYSTEM」画面。「CH-SELECT」が「12CH」に設定された例です。"} />

<span id="r12dse-w040" data-translation-unit="r12dse-w040"></span>

:::caution[注意]
注意：R12DSEは12チャンネル受信機のため、RadioLink AT9S Pro／AT10II送信機で使用する場合は、「BASIC MENU」→「SYSTEM」に入り、「CH-SELECT」を「12CH」に設定してください（図参照）。「10CH」を選択するとサーボが振動します。

### アンテナ取り付け上の注意

<span id="r12dse-w049" data-translation-unit="r12dse-w049"></span>

信号伝送を最大限に確保するため、以下を強く推奨します。

<span id="r12dse-w050" data-translation-unit="r12dse-w050"></span>

<ManualFigure src="/assets/radiolink/r12dse/web-ja-v1/r12dse-p5-f1.jpeg" width={1000} height={700} figureId="r12dse-p5-f1" alt={"2本のアンテナを互いに90°に配置する例。製品ラベルを含む原画像を保持しています。"} caption={"2本のアンテナを互いに90°に配置する例。製品ラベルを含む原画像を保持しています。"} />

<span id="r12dse-w051" data-translation-unit="r12dse-w051"></span>

1. アンテナはできるだけまっすぐにしてください。そうしないと、有効な制御範囲が狭くなります。

<span id="r12dse-w052" data-translation-unit="r12dse-w052"></span>

2. 2本のアンテナは互いに90°になるように配置してください（図参照）。

<span id="r12dse-w053" data-translation-unit="r12dse-w053"></span>

3. 大型模型には、信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状況でも良好な信号状態を確保できるよう、アンテナを模型の両側に配置してください。

<span id="r12dse-w054" data-translation-unit="r12dse-w054"></span>

4. アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。

<span id="r12dse-w055" data-translation-unit="r12dse-w055"></span>

5. アンテナはモーター、ESC、その他の干渉源となる可能性のあるものから離してください。

<span id="r12dse-w056" data-translation-unit="r12dse-w056"></span>

6. 受信機の取り付け時には、振動を防ぐため、スポンジや発泡材の使用を推奨します。

<span id="r12dse-w057" data-translation-unit="r12dse-w057"></span>

7. 受信機には高精度の電子部品が含まれています。強い振動や高温を避けるよう注意してください。

<span id="r12dse-w058" data-translation-unit="r12dse-w058"></span>

8. 発泡材やゴム布などのR/C用防振材で受信機を包んで保護します。密閉したビニール袋に入れることで、受信機が制御不能になる原因となり得る湿気やほこりを防げます。

### リアルタイム内蔵テレメトリー

<span id="r12dse-w060" data-translation-unit="r12dse-w060"></span>

### R12DSEの仕様

<span id="r12dse-w074" data-translation-unit="r12dse-w074"></span>

- 型名：R12DSE
- 寸法：長さ×幅＝30.5×16 mm（1.2×0.63インチ）
- アンテナ長：90 mm（3.54インチ）
- 重量：2.5 g（0.09 oz）
- チャンネル数：12チャンネル
- 動作電圧：DC 3～6 V
- 動作電流：35 mA（5 V時）
- 受信電流：32 mA未満（5 V時）
- テレメトリー送信電流：125 mA未満（5 V時）
- 信号：SBUSおよびPPM
- 周波数：2.4 GHz ISM帯（2400～2483.5 MHz）
- スペクトラム拡散方式：DSSSおよびFHSS
- 受信感度：-97 dBm
- 出力：20 dBm（100 mW）
- チャンネル分解能：4096、通常のジッター0.25 μs
- 制御範囲：空中で4 km（2.49マイル）。障害物や干渉のない場所で試験した最大範囲で、地域の規制によって異なる場合があります。
- 対応模型：フライトコントローラーと組み合わせた回転翼機、固定翼機、グライダー、マルチコプター、車、ボート、ロボット
- リアルタイムテレメトリー：受信機電圧とRSSI値のリアルタイム内蔵テレメトリー
- ハードウェアインターフェース：3ピン・2.54 mmピン／4ピン・1.0 mmソケット
- 対応送信機：AT10II、AT10、AT9S Pro、AT9S、AT9
