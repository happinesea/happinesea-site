<span id="ld_b20_drone_soccer-p2-u02" data-translation-unit="ld_b20_drone_soccer-p2-u02"></span>

:::caution[注意]
安全上の注意
1. 雨天では飛行させないでください。雨や湿気で飛行が不安定になり、制御不能になるおそれがあります。雷のあるときは飛行させないでください。雨・霧・雷・風のない天候での飛行を推奨します。2. 現地の法令を守り、安全に飛行してください。空港・軍事施設などの飛行禁止区域では飛行させないでください。3. 人や建物から離れた開けた場所で飛行させてください。4. 飲酒時、疲労時など正常な判断が難しい状態で操作しないでください。製品説明書に従って操作してください。5. 高圧線・変電所・携帯電話基地局・テレビ放送塔など電磁干渉源の付近では注意してください。干渉により送信機の無線性能が影響を受け、送信機と受信機の通信が途絶えて墜落するおそれがあります。6. 逆回転用プロペラを誤って取り付けないよう、説明書に従ってプロペラを取り付けてください。
:::

<span id="ld_b20_drone_soccer-p2-u03" data-translation-unit="ld_b20_drone_soccer-p2-u03"></span>

:::

<span id="ld_b20_drone_soccer-p2-u05" data-translation-unit="ld_b20_drone_soccer-p2-u05"></span>

:::caution[注意]
警告
本製品は玩具ではなく、14歳未満には適しません。大人は子どもの手の届かない場所に保管し、子どもの近くで操作するときは注意してください。電子機器の隙間から水分が送信機や小型ドローンに入り、機体が不安定または制御不能になることがあります。ゲーム等で湿潤環境での飛行が避けられない場合は、送信機をビニール袋または防水布で覆ってください。
:::

<span id="ld_b20_drone_soccer-p2-u06" data-translation-unit="ld_b20_drone_soccer-p2-u06"></span>

:::caution[注意]
本機器はFCC規則Part 15に適合します。動作は次の2条件に従います：(1)有害な干渉を発生させないこと、(2)望ましくない動作を引き起こす干渉を含む外部の無線干渉を「防ぐ」こと（原文は“prevents external wireless interference”と記載。条件としての意味に曖昧さがあります）。
:::

:::note[原典について]
FCC条件(2)の原文は“prevents external wireless interference”です。干渉を防ぐという記述がFCCの動作条件として曖昧ですが、原文を受容条件へ書き換えず、原典の語義を維持して注記します。
:::

1. 飛行の原理
1.1 送信機
T12Dの2本のスティックは4つの基本チャンネルに対応します。以下はすべてT12D Mode 2（左スティックがスロットル）の例です。左スティック：上下（THROTTLE）でLD-B20を上昇／下降させ、左右（YAW）で時計回り／反時計回りに旋回させます。右スティック：上下（PITCH）で前進／後退、左右（ROLL）で左右へ移動させます。
1.2 スティックと飛行動作
A. スロットル：上昇／下降（T12D Mode 2の例）。左スティックを上へ動かすと上昇し、下へ動かすと下降します。

RadioLink送受信機の手順：①送信機と機体搭載受信機を50 cm以内に置く。②送信機と受信機の電源を入れる。③受信機側面の黒いバインドボタンを1秒以上押す。LED点滅で開始を示します。同じ場所に同型機が複数ある場合は、他機の電源を切ってからバインドすることを推奨します。④LEDが常時点灯したら完了です。R16SMのLEDはCRSFを示す青色であることを確認します。赤色（SBUSモード）の場合はバインドボタンを1回押して青色に切り替えます。他社製送受信機は各製品の説明書を参照してください。

13. モード設定
Betaflight ConfiguratorのModeで、チャンネル5～12（またはそれ以上）を使ってFCの一般機能を設定します。送信機スイッチとモード割当ての組合せをrangeおよび／または他モードへのlinkで構成できます。受信機チャンネル値がrangeの最小～最大内にあるとモードが有効になります。別モードが有効なときにモードを有効にするlinkも設定できます。ARMは他モードへlinkできず、他モードからもlinkできません。複数range/linkを設定し、各条件をANDまたはORにできます。すべてのAND条件、または少なくとも1つのOR条件が有効ならモードが有効です。Saveで保存します。例：ノブスイッチをLEDLOW（照明）に割り当てる場合、右側のボックスでAutoを選び、ノブを回して照明スイッチとして自動認識させます。黄色リンクはLED消灯を示します。
