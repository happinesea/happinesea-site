<span id="bds200-p2-safety" data-translation-unit="bds200-p2-safety"></span>

:::caution[注意]
## 安全上の注意

- 悪天候時には模型を操作しないでください。視界が悪いと方向を見失い、模型の制御を失うおそれがあります。
- 人混みや法律で使用が禁止されている区域では使用しないでください。
- 受信機を接続する前に、トリムレバーが0であり、バッテリーが適切に充電されていることを必ず確認してください。
- 毎回の運転前に、すべてのサーボと接続を確認してください。
- 必ず受信機の電源を切ってから送信機の電源を切ってください。
- 良好な無線通信のため、高圧電線、通信基地局、送信塔などの干渉がない場所で飛行させてください。
:::

<span id="bds200-p2-warning" data-translation-unit="bds200-p2-warning"></span>

:::caution[注意]
## 警告

本製品は玩具ではなく、14歳未満のお子様には適していません。大人の方はお子様の手の届かない場所に保管し、お子様のいる場所で操作するときは十分注意してください。

アンテナやスティックの隙間から水分が送信機内部へ入り、模型が不安定になったり制御不能になったりするおそれがあります。競技などで湿った天候での使用を避けられない場合は、必ずビニール袋や防水布で送信機を覆ってください。
:::

## 1.1 BDS200の特長

<span id="bds200-p5-feature1" data-translation-unit="bds200-p5-feature1"></span>

1. BDS200は競技用の本格的なドローンです。ジャイロ、加速度計、気圧計による慣性航法とカルマンフィルターによる高度維持アルゴリズムが、高速性と安定性の両立を実現します。初心者の操作の難しさを大幅に減らし、競技飛行の楽しさを体験できます。

<span id="bds200-p5-feature2" data-translation-unit="bds200-p5-feature2"></span>

2. RTF版には、スマートフォンアプリでパラメーター調整ができる8チャンネル送信機が付属します。日本のNoble製の高品質ポテンショメーターを搭載し、スティックの制御精度は0.25マイクロ秒です。Bluetooth接続したAndroidまたはiOSアプリで設定・変更できます。送信機、受信機、動力用バッテリーの低電圧アラーム値は、必要に応じて設定できます。

## 第2章 飛行前の準備

<span id="bds200-p6-power" data-translation-unit="bds200-p6-power"></span>

## 2.1 電源

T8S送信機：送信機が満充電になっていることを確認してください。

BDS200：付属の2S LiPoバッテリーは出荷時には満充電ではありません。飛行前にCM210充電器で充電してください。

2S LiPo専用のCM210は、CB86PLUSの専門的な開発技術と高精度を受け継ぎ、より安全な充電とバッテリー寿命を確保します。

<span id="bds200-p6-charge-heading" data-translation-unit="bds200-p6-charge-heading"></span>

## CM210の使用方法

<span id="bds200-p6-charge1" data-translation-unit="bds200-p6-charge1"></span>

1. 標準USBケーブルの一端をCM210のType-C入力端子へ挿入し（下図参照）、もう一端をモバイルバッテリー、コンピューター、携帯電話用アダプターなどの電源へ接続します（入力電圧：5V）。正しく接続すると赤色LEDが点灯し続けます。

<span id="bds200-p6-charge2" data-translation-unit="bds200-p6-charge2"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="bds200-p6-charge3" data-translation-unit="bds200-p6-charge3"></span>

3. 4つのLEDがすべて緑色で点灯し続けると満充電になり、充電器が自動的に充電を停止します。

<span id="bds200-p6-charge4" data-translation-unit="bds200-p6-charge4"></span>

4. バッテリーを取り外してから、電源を切り離します。

## CM210のLED表示の状態

<span id="bds200-p7-led-table" data-translation-unit="bds200-p7-led-table"></span>

| LEDの色 | 状態 | 意味 |
| --- | --- | --- |
| 赤 | 点滅 | 充電器が異常を検出 |
| 赤 | 点灯し続ける | バッテリー未接続 |
| 緑 | 4つすべてが1回点滅 | 充電器の電源が入った |
| 緑 | 1つ目が点滅。他は消灯 | バッテリー電圧が7.4V未満 |
| 緑 | 1つ目が点灯し続け、2つ目が点滅。他は消灯 | バッテリー電圧が7.8V未満 |
| 緑 | 最初の2つが点灯し続け、3つ目が点滅。他は消灯 | バッテリー電圧が8.2V未満 |
| 緑 | 最初の3つが点灯し続け、4つ目が点滅。他のLEDは消灯 | バッテリー電圧が8.4V未満 |
| 緑 | 4つすべてが点灯し続ける | バッテリーは満充電 |
