## 1. 安全上の注意

<span id="cm120-p3-u02" data-translation-unit="cm120-p3-u02"></span>

:::caution[注意]
1. CM120を安全に使用するため、使用前に本書をよく読んでください。

<span id="cm120-p3-u10" data-translation-unit="cm120-p3-u10"></span>

:::caution[注意]
3. 充電器は常に子どもやペットの手が届かない場所に置いてください。
4. 充電中は充電器から目を離さないでください。
5. バッテリーに液漏れ、膨らみ、外装の剥がれ、変色、変形などの異常がある場合は充電しないでください。
6. 充電器を改造・分解しないでください。
7. 使用中は充電器やバッテリーを可燃物の近くに置かないでください。
8. 充電式ではない乾電池を充電しないでください。
:::

## 2. CM120の概要

<span id="cm120-p3-u04" data-translation-unit="cm120-p3-u04"></span>

RadioLink CM120は1S LiPoバッテリー用充電器です。高精度の充電によって充電時の安全性とバッテリー寿命を確保し、急ぎの場合には急速充電が可能です。

<span id="cm120-p3-u05" data-translation-unit="cm120-p3-u05"></span>
