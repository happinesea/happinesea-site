## 2. 基本設定

<span id="elrs24-p3-u06" data-translation-unit="elrs24-p3-u06"></span>

ATA ELRS 1W 2.4G長距離モジュールはCrossfireシリアルプロトコル（CRSF）に対応しています。送信機がCRSFシリアルプロトコルに対応していることを確認してください。OpenTX搭載送信機とRadioLink T16Dを例に、CRSFプロトコルとLuaスクリプトの設定を説明します。

<span id="elrs24-p3-u07" data-translation-unit="elrs24-p3-u07"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="elrs24-p3-u08" data-translation-unit="elrs24-p3-u08"></span>

:::caution[注意]
電源を入れる前にアンテナを取り付けてください。取り付けずに通電するとモジュール内部のPAチップが破損します。
:::
