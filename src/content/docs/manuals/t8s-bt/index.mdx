## 第1章 はじめに

### 1.1 安全上の注意

1. 雨天時は送信機を使用しないでください。送信機に水分が入らないようにしてください。

<span id="t8s-p4-body-damp-weather" data-translation-unit="t8s-p4-body-damp-weather"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="t8s-p4-body-weather-and-power-safety" data-translation-unit="t8s-p4-body-weather-and-power-safety"></span>

:::caution[注意]
雷が鳴っている場合は飛行させないでください。
2. 雨や雪の中では使用しないでください。送信機器に干渉し、操縦不能となり事故につながるおそれがあります。
3. 人混みや法令で使用が禁止されている場所では使用しないでください。
4. 14歳未満の子どもに本製品を触らせないでください。本製品は玩具ではありません。子どもがいる場所での操作には十分注意してください。
5. 飛行時は現地の法令を厳守し、安全を確保してください。
6. 電源投入前にスロットルスティックとトリムが最下位置であることを確認してください。送信機の電源を入れ、バッテリー残量が十分であることを確認してから、受信機の電源を入れてください。
7. 操縦する前に、各サーボがスティックに対応する向きに動くことを確認してください。方向が一致しない場合は、使用前に調整してください。
8. 使用を終えるときは先に受信機と制御対象機器の電源を切り、その後に送信機の電源を切ってください。順序を逆にすると操縦不能となり、事故を起こすおそれがあります。
:::

<span id="t8s-p4-body-battery-compatibility" data-translation-unit="t8s-p4-body-battery-compatibility"></span>
