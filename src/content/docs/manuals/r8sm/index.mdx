### 安全上の注意

<span id="r8sm-w010" data-translation-unit="r8sm-w010"></span>

:::caution[注意]
- 悪天候下では模型を絶対に操作しないでください。視界不良によって方向が分からなくなり、模型を制御できなくなるおそれがあります。
- 人混みや使用が法律で禁じられた場所では、本製品を絶対に使用しないでください。
- 受信機を接続する前に、トリムレバーが0で、バッテリーが適切に充電されていることを必ず確認してください。
- 走行・飛行のたびに、すべてのサーボと接続を必ず確認してください。
- 電源を切るときは、送信機より先に受信機の電源を必ず切ってください。
:::

### 1. R8SMの概要

<span id="r8sm-w017" data-translation-unit="r8sm-w017"></span>

RadioLink R8SMは、重量1.5 g（0.05 oz）、寸法18×13 mm（0.71×0.51インチ）の2.4G・8チャンネル受信機です。PPMおよびSBUS信号出力に対応し、RadioLink送信機T8FB／T8Sと互換性があります。

<span id="r8sm-w018" data-translation-unit="r8sm-w018"></span>

### 2. バインド（リンク）

<span id="r8sm-w019" data-translation-unit="r8sm-w019"></span>

各受信機には固有のIDコードがあり、使用前に送信機とのバインドが必要です。バインドが完了するとIDコードが送信機に保存され、再バインドは不要です。したがって、新しいR8SMを購入した場合は、送信機と組み合わせて使用するためにバインドを行う必要があります。

<span id="r8sm-w020" data-translation-unit="r8sm-w020"></span>

#### バインド手順

<span id="r8sm-w021" data-translation-unit="r8sm-w021"></span>

1. 送信機と受信機を近づけ（約50 cm）、両方の電源を入れます。
2. 送信機の電源を入れると、R8SMの赤いLEDがゆっくり点滅し始めます。
3. 受信機の側面に黒いバインドボタン（ID SET）があります。ボタンを1秒より長く押してから離すと、赤いLEDが速く点滅し、バインド処理中であることを示します。
4. 赤いLEDの点滅が止まり、常時点灯になればバインド完了です。成功しない場合は、上記手順を繰り返してください。

:::note[原典について]
バインド手順1で両方の電源を入れた後、手順2で再び送信機の電源を入れる記述です。重複を保持し、操作順は推測補正していません。
:::

<span id="r8sm-w022" data-translation-unit="r8sm-w022"></span>

### 3. 動作モード

<span id="r8sm-w023" data-translation-unit="r8sm-w023"></span>

#### 2種類の信号動作モード

<span id="r8sm-w024" data-translation-unit="r8sm-w024"></span>

青／紫のLED：S.BUS信号、全8チャンネル。
赤いLED：PPM信号、全8チャンネル。

<span id="r8sm-w025" data-translation-unit="r8sm-w025"></span>

#### S.BUS／PPM信号の切り替え

<span id="r8sm-w026" data-translation-unit="r8sm-w026"></span>

ID SETスイッチを1秒以内に素早く2回押すと、信号がS.BUSからPPMに切り替わります。赤いLEDはPPM、青／紫のLEDはS.BUSを示します。

### 4. R8SMの仕様

<span id="r8sm-w031" data-translation-unit="r8sm-w031"></span>

1. 周波数：2.4 GHz ISM帯（2400 MHz～2483.5 MHz）
2. 寸法：18×13 mm（0.71×0.51インチ）
3. 重量：1.5 g（0.05 oz）
4. チャンネル数：8チャンネル
5. 信号出力：PPM／SBUS
6. 対象模型：車／船／固定翼機／グライダー／マルチローター
7. 符号化方式：FHSS・67チャンネル疑似ランダム周波数ホッピング
8. アンテナ長：200 mm
9. 電圧範囲：4.8～6 V
10. チャンネル分解能：4096
11. 動作電流：30 mA（電源によって異なります）
12. 操作距離：上空で2000 m（6562 ft）
