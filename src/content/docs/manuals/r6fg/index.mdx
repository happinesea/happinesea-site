### 受信機アンテナの取り付け

<span id="r6fg-w043" data-translation-unit="r6fg-w043"></span>

1. アンテナはできるだけまっすぐにしてください。曲がっていると有効距離が短くなります。

<span id="r6fg-w044" data-translation-unit="r6fg-w044"></span>

2. 大型模型航空機では金属部品が信号に干渉する場合があります。その場合、アンテナを機体の側面に配置してください。

<span id="r6fg-w045" data-translation-unit="r6fg-w045"></span>

3. アンテナは、金属やカーボンなどの導電性材料から少なくとも0.5インチ離してください。同軸部分にはこの条件を適用する必要はありませんが、小さな曲げ半径で曲げないでください。

<span id="r6fg-w046" data-translation-unit="r6fg-w046"></span>

4. アンテナはモーター、ESC、その他のノイズ源からできるだけ離してください。

<span id="r6fg-w047" data-translation-unit="r6fg-w047"></span>

5. 受信機を模型に搭載する際は、衝撃対策としてスポンジや発泡材で包むことができます。

<span id="r6fg-w048" data-translation-unit="r6fg-w048"></span>

上記の手順をすべて終えたら、正しく接続された状態で送信機から制御できることを確認するため、各機能を設定します。
