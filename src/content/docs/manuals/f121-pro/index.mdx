:::caution[注意]
## 安全上の注意

- 悪天候時は機体を操作しないでください。視界不良により方向を見失い、機体の制御を失うおそれがあります。
- 人混みや使用が法令で禁止されている場所では、本製品を使用しないでください。
- 受信機を接続する前には、送信機のトリムレバーが0で、バッテリーが適切に充電されていることを確認してください。
- 飛行中は機体から一定の距離を取り、プロペラやブラシ付きモーターなどの高速回転部品でけがをしないようにしてください。
- 着陸後、機体に近づいて触れる前に、ディスアームされ、プロペラが停止していることを確認してください。
- 送信機の電源を切る前に、受信機または機体の電源を切ってください。
- 飛行中に脱落しないよう、プロペラの取付手順に従ってください。
- 無線通信を確保するため、高圧線、通信基地局、送信塔などからの干渉がない場所で飛行させてください。
:::
