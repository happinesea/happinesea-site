## 安全上の注意

<span id="cool9030-p3-insulation" data-translation-unit="cool9030-p3-insulation"></span>

:::caution[注意]
1. ESCを各機器に接続する前に、配線と接続部分がすべて十分に絶縁されていることを確認してください。短絡するとESCが損傷します。
:::

<span id="cool9030-p3-matching" data-translation-unit="cool9030-p3-matching"></span>

:::caution[注意]
2. ESCを使用する前に、電源機器と車体の説明書をよく読み、機器の組み合わせが適切であることを確認してください。不適切な組み合わせはモーターの過負荷を招き、ESCの損傷につながります。
:::

<span id="cool9030-p3-suspended-car" data-translation-unit="cool9030-p3-suspended-car"></span>

:::caution[注意]
3. ご自身や周囲の方の安全のため、車体を浮かせた状態で配線と動作調整を行ってください。
:::

<span id="cool9030-p3-disconnect" data-translation-unit="cool9030-p3-disconnect"></span>

:::caution[注意]
4. 使用後はバッテリーとESCの接続を外してください。バッテリーを接続したままでは、ESCのスイッチを切っても電力を消費し続けます。使用せずに長時間接続したままにすると、バッテリーが完全に放電し、バッテリーやESCの故障につながります。
:::

<span id="cool9030-p3-liability" data-translation-unit="cool9030-p3-liability"></span>

:::caution[注意]
誤った操作によって生じた損害について、RadioLinkは責任を負いません。
:::

### 2.1 電源入力

<span id="cool9030-p7-input-requirements" data-translation-unit="cool9030-p7-input-requirements"></span>

このブラシ付きDCモーター用ESCは、非リチウム系バッテリー（Ni-MH、ニッケルカドミウム、鉛蓄電池など）とリチウム系バッテリー（リチウムポリマーバッテリー）に対応します。システムを安定して動作させるには、電源電圧を6.0～16.8 V（リチウム系バッテリーモードでは6～18 V）の範囲内にしてください。バッテリーの種類によって電圧保護の方式が異なります。詳しくは以下の表を参照してください。

:::

<span id="cool9030-p8-protection-intro" data-translation-unit="cool9030-p8-protection-intro"></span>

以下に、低電圧保護、半出力保護、過電圧保護の3つの状態を説明します。

<span id="cool9030-p8-undervoltage" data-translation-unit="cool9030-p8-undervoltage"></span>

1. 低電圧保護：入力電源の電圧がこの値を下回ると、ESCはモーターの出力制御を停止し、入力信号に応答しなくなります。電源インジケーターが点滅して知らせます。低電圧保護状態でバッテリー電圧が半出力保護値まで戻ると、低電圧保護を解除し、通常動作とモーターの通常出力制御が復帰します。

<span id="cool9030-p8-half-power" data-translation-unit="cool9030-p8-half-power"></span>

2. 半出力保護：入力電源の電圧がこの値を下回ると、ESCはモーターの出力を元の半分にします。この状態でも入力信号には応答します。電圧が過電圧保護値付近まで上がっても、半出力保護は解除されません。バッテリー電圧が低電圧保護値まで低下すると、半出力保護を終了します（続きは原典物理9頁）。

<span id="cool9030-p9-folio" data-translation-unit="cool9030-p9-folio"></span>

原典印刷ページ: 8

<span id="cool9030-p9-half-power-cont" data-translation-unit="cool9030-p9-half-power-cont"></span>

低電圧保護状態へ移行し、モーターの出力制御を行いません。

<span id="cool9030-p9-overvoltage" data-translation-unit="cool9030-p9-overvoltage"></span>

3. 過電圧保護：入力電源の電圧がこの値を上回ると、ESCはモーターの出力制御を停止し、入力信号に応答しなくなります。電源インジケーターが点滅して知らせます。過電圧保護状態でバッテリー電圧が過電圧保護値を下回ると、システムは通常動作を再開し、モーターの通常出力制御が復帰します。原典は通常動作と出力制御の復帰を重ねて記載しています。

### 2.3 信号入力

<span id="cool9030-p10-signal-format" data-translation-unit="cool9030-p10-signal-format"></span>

このブラシ付きDCモーター用ESCの信号入力（スロットル信号入力）が認識できるのは、受信機の単一チャンネルが出力するPWM信号のみです。PPM信号やS.BUS信号など、複数チャンネルを符号化した信号は認識できません。また、制御信号によってシステムを安定して制御するには、PWM信号が以下の表の仕様を満たす必要があります。

<span id="cool9030-p10-signal-table" data-translation-unit="cool9030-p10-signal-table"></span>

| パラメーター | 最小 | 最大 |
| --- | --- | --- |
| PWM信号周波数 | 7.15 Hz（140 ms） | 400 Hz（2.5 ms） |
| PWM信号振幅 | 2.8 V | 5.4 V |
| PWM信号遅延 | 0 ms | 150 ms |
| PWM信号パルス幅 | 0.8 ms（800 μs） | 2.2 ms（2200 μs） |

<span id="cool9030-p10-signal-warning" data-translation-unit="cool9030-p10-signal-warning"></span>

:::caution[注意]
注意：表のPWM信号遅延は、突然の信号中断（信号喪失）に対するESCの耐性の範囲を示すもので、PWM信号の中断（喪失）から回復までの時間を表します。
:::

<span id="cool9030-p10-abnormal-intro" data-translation-unit="cool9030-p10-abnormal-intro"></span>

このESCシステムには、基本的な制御機能に加えて、制御入力信号の異常に対応する機能があります。制御入力信号の異常には以下の2つの場合があります。

<span id="cool9030-p10-loss" data-translation-unit="cool9030-p10-loss"></span>

1. 入力信号なし：ESCが電源に接続されているとき、スロットル入力信号を検出できない場合、またはスロットル信号の遅延時間がPWM信号遅延のパラメーターを超えた場合、ESCは入力信号がない状態と判定します。異常状態の通知方法は原典物理11頁に続きます。

<span id="cool9030-p11-loss-cont" data-translation-unit="cool9030-p11-loss-cont"></span>

（物理10頁「入力信号なし」の続き）状態表示灯の点滅とモーターのブザー音を同時に用いて、現在の異常状態を知らせます。

<span id="cool9030-p11-abnormal-signal" data-translation-unit="cool9030-p11-abnormal-signal"></span>

2. 入力信号異常：ESCへ電源が接続され、スロットル入力が中立範囲にない場合、入力信号異常と判定し、状態表示灯の点滅とモーター音で知らせます。標準中立は1500µs、その±50µs（1450～1550µs）が中立範囲です。校正後はその校正結果を優先します。

<span id="cool9030-p11-signal-note" data-translation-unit="cool9030-p11-signal-note"></span>

注意：信号異常時は、スロットル入力を中立範囲へ戻すと異常通知を解除できます。

## 第5部 ESCの状態表示

赤・緑の2灯で状態を表示します。緑の電源灯は自己診断と給電状態、赤の状態灯は自己診断と動作状態を示します。点灯・消灯・点滅の3状態があり、点滅間隔は通知により異なります。

モーターの振動と発音も利用し、光と音で通知します。短い音、長い音、メロディー音の3種類があり、回数と間隔が通知により変わります。
