### 1.1 安全上の注意

<span id="t16d-ch1-1-1" data-translation-unit="t16d-ch1-1-1"></span>

:::caution[安全上の注意]
1. 雨天の屋外、水たまりを通過する場所、視界の悪い状況では使用しないでください。送受信機などの構成部品に水や雪が入ると、誤動作や操縦不能につながるおそれがあります。
2. 人や道路の近くでは使用しないでください。
3. 本製品は玩具ではなく、14歳未満のお子様には適していません。大人の方は子供の手が届かない場所に保管し、子供がいる場所では十分注意して使用してください。
4. 飛行時は地域の法令を厳守し、安全に飛行してください。
5. 電源を入れる前に、スロットルスティックとトリムボタンが最下端にあることを確認してください。送信機の電源を入れ、電源容量が十分であることを確認してから、受信機の電源を入れてください。
6. 模型を動作させる前に、各サーボの動作が対応するスティックの操作方向と一致していることを確認してください。一致しない場合は調整してから使用してください。
7. 電源を切るときは、受信機と制御対象の機器を先に切り、その後で送信機を切ってください。逆の順序で操作すると操縦不能となり、事故につながるおそれがあります。
:::
