## 4. ESC設定

<span id="am32_70a_4in1_esc-p5-u02" data-translation-unit="am32_70a_4in1_esc-p5-u02"></span>

(1) フライトコントローラーのFirmwareを書き込みます。

<span id="am32_70a_4in1_esc-p5-u03" data-translation-unit="am32_70a_4in1_esc-p5-u03"></span>

ESCパラメーターを設定する際は、ESCとパソコンの通信ブリッジとしてBetaflight、INAV、またはArduPilot Firmwareが動作するフライトコントローラーが必要です。まず、現在のフライトコントローラーでBetaflight、INAV、またはArduPilot Firmwareが動作していることを確認します。そうでない場合は、フライトコントローラーにFirmwareを書き込みます。具体的な書き込み方法は、フライトコントローラーの取扱説明書を参照してください。

<span id="am32_70a_4in1_esc-p5-u04" data-translation-unit="am32_70a_4in1_esc-p5-u04"></span>

(2) フライトコントローラーを設定します。

<span id="am32_70a_4in1_esc-p5-u05" data-translation-unit="am32_70a_4in1_esc-p5-u05"></span>

BetaflightまたはArduPilot Firmwareでは設定は不要です。INAV Firmwareでは、初期状態で無効になっているモーター出力を有効にする必要があります。
