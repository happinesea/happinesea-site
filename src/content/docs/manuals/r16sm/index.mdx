### 1. R16SMの概要

<span id="r16sm-w027" data-translation-unit="r16sm-w027"></span>

RadioLink R16SMは、操縦距離3000 mの小型16チャンネル受信機です。データ伝送機能を内蔵し、外部センサーなしで豊富な情報を伝送できます。RSSI値と模型のバッテリー電圧のリアルタイム伝送に加え、R16SMをフライトコントローラーおよびGPSに接続し、CRSF動作モードにすると、緯度、経度、速度、機首方位、受信GPS衛星数、距離、PITC、ROLL、YAW、バッテリー電圧、電流、容量、飛行モードなどのOSD情報が送信機画面に表示されます。

### 4. 動作モード

<span id="r16sm-w048" data-translation-unit="r16sm-w048"></span>

R16SMには2種類の動作モードがあります。一方は非反転SBUS信号出力、もう一方はCRSF信号出力です。青色LEDはCRSF信号出力、赤色LEDは非反転SBUS信号出力を示します。バインドボタンを1回短く押すと動作モードが切り替わります。

<span id="r16sm-w049" data-translation-unit="r16sm-w049"></span>

### 5. リアルタイム内蔵テレメトリーとフライトコントローラーへの接続

<span id="r16sm-w050" data-translation-unit="r16sm-w050"></span>

R16SMが伝送できるテレメトリー情報は、SBUS信号出力時とCRSF信号出力時で異なります。CRSF信号出力では、信号強度、RSSI値、動力用バッテリー電圧、経度・緯度、距離、衛星数などのテレメトリーに対応します（下図参照）。SBUS信号出力では、経度・緯度と動力用バッテリー電圧のテレメトリーのみに対応するため、CRSF動作モードを推奨します。注：CRSFプロトコルは受信機電圧のテレメトリーに対応しないため、R16SMも受信機電圧のテレメトリーに対応しません。

### 6. アンテナ取り付け時の注意

<span id="r16sm-w092" data-translation-unit="r16sm-w092"></span>

受信機アンテナを模型に正しく取り付けることは非常に重要です。取り付けが正しくないと信号に影響します。取り付け時は、次の要件に注意してください。

<span id="r16sm-w093" data-translation-unit="r16sm-w093"></span>

:::caution[注意]
(1) 受信機アンテナを折り曲げないでください。
:::

<span id="r16sm-w094" data-translation-unit="r16sm-w094"></span>

:::caution[注意]
(2) アンテナを金属物の近くに配置しないでください。金属からの反射により信号が著しく悪化します。
:::

<span id="r16sm-w095" data-translation-unit="r16sm-w095"></span>

(3) アンテナはできるだけまっすぐにしてください。曲がっていると有効操縦距離が短くなります。

<span id="r16sm-w096" data-translation-unit="r16sm-w096"></span>

(4) 大型の模型には信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状況でも最良の信号状態を保つため、アンテナを模型の両側に配置してください。

<span id="r16sm-w097" data-translation-unit="r16sm-w097"></span>

:::caution[注意]
(5) アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に折り曲げないでください。
:::

<span id="r16sm-w098" data-translation-unit="r16sm-w098"></span>

(6) アンテナをモーター、ESC、その他の干渉源となり得るものから離してください。

<span id="r16sm-w099" data-translation-unit="r16sm-w099"></span>

(7) 受信機の取り付け時は、振動を防ぐためスポンジや発泡材を使用することを推奨します。

<span id="r16sm-w100" data-translation-unit="r16sm-w100"></span>

:::caution[注意]
(8) 受信機には高精度な電子部品が含まれています。強い振動や高温を避けてください。
:::

<span id="r16sm-w101" data-translation-unit="r16sm-w101"></span>

(9) 受信機を保護するため、RC用の発泡材やゴム布などの専用防振材で包みます。密閉性の高いビニール袋に入れることで、制御不能の原因となり得る湿気やほこりを防げます。

<span id="r16sm-w102" data-translation-unit="r16sm-w102"></span>

アンテナの取り付けガイドは、次のリンクを参照してください。
https://www.radiolink.com/newsinfo/886600.html

### 7. RSSIテスト

<span id="r16sm-w104" data-translation-unit="r16sm-w104"></span>

操縦距離が短い場合は、この手順で送信機と受信機の間のRSSIをテストしてください。送信機のRSSI値のテスト手順と、異常なRSSI値への対処方法を説明します。

<span id="r16sm-w105" data-translation-unit="r16sm-w105"></span>

原典印刷ページ：9

<span id="r16sm-w107" data-translation-unit="r16sm-w107"></span>

(1) 送信機と受信機の電源を同時に入れると、両者が接続されます（接続されない場合は再バインドが必要です）。送信機画面に電波塔のアイコンが表示されれば、バインド成功です。ホーム画面にRSSI値が表示され（右図参照）、送信機と受信機の距離に応じて値が変化します。

<span id="r16sm-w108" data-translation-unit="r16sm-w108"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="r16sm-w109" data-translation-unit="r16sm-w109"></span>

(2) 受信機と送信機のアンテナを平行にします。両者を約60 cm離し、両アンテナをまっすぐにします。RSSI値が0～−30 dBmの範囲であれば正常です。値が0に近いほど信号が強いことを示します。

<span id="r16sm-w110" data-translation-unit="r16sm-w110"></span>

### 信号強度が異常な場合の対処

<span id="r16sm-w111" data-translation-unit="r16sm-w111"></span>

受信機と送信機のアンテナに損傷がないか確認してください。信号強度の低下の多くはアンテナの損傷が原因です。損傷している場合はアンテナを交換する必要があります。損傷がない場合は、受信機を交換して送受信機の故障を切り分けることができます。解決しない場合は、after_service@radiolink.com.cnにメールでサポートを依頼してください。
