## 概要

<span id="ts100v2-text-03" data-translation-unit="ts100v2-text-03"></span>

RadioLink M10N GPS TS100 V2.0は、RadioLinkの技術者が22年以上にわたり培った無線技術の経験を活用し、回路設計から基板上の部品配置まで工夫することで、ICの感度指標の限界を超える性能を実現しています。

<span id="ts100v2-text-04" data-translation-unit="ts100v2-text-04"></span>

測位精度は50 cmです。開けた場所では6秒で20基の衛星を捕捉します。谷間での位置保持性能は業界トップクラスです。

## 構成

<span id="ts100v2-text-08" data-translation-unit="ts100v2-text-08"></span>

GPS受信チップ：RadioLink M10N GPS TS100はu-blox M10050を採用し、単一GNSSの7Nより高い性能を備えています。

<span id="ts100v2-text-09" data-translation-unit="ts100v2-text-09"></span>

高精度電子コンパスIST8310内蔵（I2Cポート）。

<span id="ts100v2-text-10" data-translation-unit="ts100v2-text-10"></span>

アンテナ：利得2.5 dBiの高利得・高選択性セラミックチップアンテナ。

<span id="ts100v2-text-11" data-translation-unit="ts100v2-text-11"></span>

二重フィルター：村田製作所の2段SAWF（弾性表面波フィルター）。

<span id="ts100v2-text-12" data-translation-unit="ts100v2-text-12"></span>

測位精度は50 cmです。

<span id="ts100v2-text-13" data-translation-unit="ts100v2-text-13"></span>

開けた場所では6秒で20基の衛星を捕捉します。

<span id="ts100v2-text-14" data-translation-unit="ts100v2-text-14"></span>

谷底でも高い測位性能を発揮します。

<span id="ts100v2-text-15" data-translation-unit="ts100v2-text-15"></span>

複数の測位システム（BD1、GPS/L1、Galileo/E1、GLONASS/G1）に対応し、4システムを同時に利用できます。

<span id="ts100v2-text-16" data-translation-unit="ts100v2-text-16"></span>

3周波数：1561±1 MHz、1575±1 MHz、1602～1610 MHz。

<span id="ts100v2-text-17" data-translation-unit="ts100v2-text-17"></span>
