## 安全上の注意

- 悪天候のときは模型を操作しないでください。視界不良により方向を見失い、模型を制御できなくなるおそれがあります。
- 人が密集している場所や使用が禁止されている場所では使用しないでください。
- 受信機を接続する前に、トリムレバーが0であり、バッテリーが適切に充電されていることを必ず確認してください。
- 使用前に必ずすべてのサーボとその接続を確認してください。
- 電源を切るときは、必ず先に受信機、次に送信機の電源を切ってください。

### 警告

本製品は玩具ではなく、14歳未満の子どもには適していません。大人は子どもの手の届かない場所に保管し、子どもが近くにいるときは操作に十分注意してください。

<span id="rc4gsv3-p2-water-ingress" data-translation-unit="rc4gsv3-p2-water-ingress"></span>

:::caution[注意]
アンテナや操作部の隙間から送信機内部に水や湿気が入り、模型の動きが不安定になり、制御を失うおそれがあります。
:::
