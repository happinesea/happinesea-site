### はじめに

<span id="r8ef-w006" data-translation-unit="r8ef-w006"></span>

Radiolink R8EFはS-BUS、PPM、PWM信号に対応する2.4 GHz・8チャンネル受信機です。Radiolink送信機T8FB、T8S、RC4GS V2、RC6GS V2で使用します。

<span id="r8ef-w011" data-translation-unit="r8ef-w011"></span>

#### 2. S-BUS・PPM信号出力モード

<span id="r8ef-w015" data-translation-unit="r8ef-w015"></span>

青／紫色LEDはSBUS・PPM信号出力を示します。合計8チャンネルです。S-BUS・PPM信号出力モードでは、SBUS信号とPWM信号を同時に動作させることができます。
CH1はS-BUS信号、CH2はPPM信号を出力し、CH3～CH8は同時にPWM信号を出力します。

### 3. S-BUS・PPMとPWMの信号切り替え
1秒以内にID SETスイッチを素早く2回押すと、信号がPWMからS-BUS・PPMへ切り替わります。赤色LEDはPWM、青／紫色LEDはS-BUS・PPM・PWMを示します。

<span id="r8ef-w020" data-translation-unit="r8ef-w020"></span>

### 4. 受信機の接続
受信機の接続ケーブルは上図のとおりです。一般的なケーブルの線色は白／赤／黒、または黄／赤／茶です。どちらのサーボケーブルも、明るい色の線が信号線、暗い色の線がグランド線、中央が5 V電源です。3本の線は、信号波形・＋・－の各記号に対応します。

<span id="r8ef-w025" data-translation-unit="r8ef-w025"></span>

:::caution[注意]
注意：
1. Radiolinkの受信機はすべて逆接続保護を備えています。サーボケーブルを逆向きに差し込むと、受信機は動作しません。
2. 受信機の動作電圧は4.8～10 Vです。受信機に別のバッテリーから独立して電源を供給する場合、バッテリーの極性を逆に接続しても受信機は破損しませんが、この状態でサーボを接続していると、サーボが破損します。
:::

<span id="r8ef-w026" data-translation-unit="r8ef-w026"></span>

### 送信機とのバインド（リンク）方法
1. 送信機と受信機を1 m以内に近づけます。
2. 送信機の電源を入れてから、R8EFに電源を供給します。
3. R8EFの黒いバインドボタンを1秒間押し、受信機のLEDが点滅し始めたら放します。約8回点滅した後、受信機の信号LEDが点灯状態になれば、バインド完了です。

:::note[原典について]
バインドボタンの「in one second」は押下時間の表現が曖昧。1秒間という暫定訳とし実機未確認。
:::

<span id="r8ef-w027" data-translation-unit="r8ef-w027"></span>

### 受信機アンテナの取り付け
1. アンテナはできるだけまっすぐに保ちます。曲がっていると有効範囲が狭くなります。
2. 大型模型航空機では金属部品が信号に干渉する場合があります。この場合はアンテナを機体の側面に配置します。
3. アンテナは、金属やカーボンなどの導電性材料から少なくとも0.5インチ離してください。アンテナの同軸部分にはこの配置条件は適用されませんが、小さな曲げ半径で曲げないでください。

4. アンテナは、モーター、ESC、その他のノイズ源からできるだけ離します。
5. 機体に取り付けるときは、衝撃を防ぐため受信機をスポンジや発泡材で包むことができます。
6. 上記の手順をすべて終えたら、各機能を操作し、正しく接続されて送信機で制御できることを確認します。

<span id="r8ef-w031" data-translation-unit="r8ef-w031"></span>

### 仕様
1. チャンネル数：8チャンネル
2. 動作電圧：4.8～10 V
3. 動作電流：30 mA（入力電圧：5 V）
4. 寸法：48.5 × 21 × 11 mm
5. 重量：7 g
6. 分解能4096段階、1段階あたり0.5 μs。サーボの舵の振動を抑えます。
7. 操縦距離：上空で約2000 m。実際の操縦距離は環境によって異なります。

:::note[原典について]
「servo anti-shake rudder」の具体的機能は不明。原文の範囲で暫定訳。
:::
