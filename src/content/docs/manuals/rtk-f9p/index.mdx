## 1. はじめに

<span id="rtkf9p-w010" data-translation-unit="rtkf9p-w010"></span>

高精度ナビゲーション：ドローンによる地図作成や測量、高精度の離着陸など、多くのドローン用途では、従来のGNSSよりも高い精度が求められます。

<span id="rtkf9p-w011" data-translation-unit="rtkf9p-w011"></span>

RTK F9Pは、RadioLinkの4系統の衛星測位システムに対応するリアルタイムGNSSシステムです。2台のRTK F9Pモジュールを使用し、1台を機体側、もう1台を基地局側に使用します。

<span id="rtkf9p-w012" data-translation-unit="rtkf9p-w012"></span>

## 2. 技術パラメータ

<span id="rtkf9p-w013" data-translation-unit="rtkf9p-w013"></span>

|---|---|
|受信機タイプ|RTK F9P|
|GNSS|BeiDou、Galileo、GLONASS、GPS／QZSS|

|GNSS帯域|GPS L1C/A L2C、GLONASS L1OF L2OF、GALILEO E1B/C E5b、BDS B1I B2I、QZSS L1C/A L2C|

|測位精度|RTK 0.01 m＋1 ppm CEP|
|RTKサーベイイン時間|RTK＜10秒|
|捕捉|コールドスタート24秒|

|捕捉|再捕捉2秒|
|感度|トラッキング・ナビゲーション：−167 dBm|
|感度|コールドスタート：−148 dBm|
|感度|ホットスタート：−157 dBm|
|感度|再捕捉：−160 dBm|
|ジャミング対策|アクティブCW検出・除去、オンボードフィルター|
|スプーフィング対策|高度なスプーフィング対策アルゴリズム|

:::note[原典について]
仕様表のサーベイイン時間はRTK＜10秒ですが、後の節は基地局精度への収束に時間が必要で、高精度ほど長くなると説明しています。どの条件にも10秒未満で完了するという保証へ広げず、それぞれの原典記載と測位状態の説明を保持します。
:::

## 5. Mission PlannerでのRTK基地局設定

<span id="rtkf9p-w034" data-translation-unit="rtkf9p-w034"></span>

### 5.1 RTK基地局の構築

<span id="rtkf9p-w035" data-translation-unit="rtkf9p-w035"></span>

ArduPilotファームウェアでRTK差分測位システムを構築する場合は、Mission Plannerで基地局の測位設定とデータ転送を行います。基地局の測位設定中は、移動局とドローンを起動する必要はありません。

<span id="rtkf9p-w036" data-translation-unit="rtkf9p-w036"></span>

- Mission Plannerを開きます。
- 初期設定へ入ります。
- 「Optional Hardware」をクリックします。
- 「RTK/GPS Inject」をクリックすると、次のページが表示されます。

<span id="rtkf9p-w037" data-translation-unit="rtkf9p-w037"></span>

注意：使用しているMission Plannerに「RTK/GPS Inject」がない場合は、Mission Plannerを最新版へ更新してください。

:::note[原典について]
原典のMission Planner画面は1.3.77と1.3.68の例を含みます。画面内の版・例示値・言語表示をそのまま保持し、現在の最新版または日本語実機表示を示すものと読み替えていません。
:::

<span id="rtkf9p-w043" data-translation-unit="rtkf9p-w043"></span>

- 「Position is invalid」：基地局がまだ有効な位置を取得していません。

<span id="rtkf9p-w044" data-translation-unit="rtkf9p-w044"></span>

- 「In Progress」：衛星探索が進行中です。

<span id="rtkf9p-w045" data-translation-unit="rtkf9p-w045"></span>

- 「Duration」：現在の衛星探索を実行している秒数です。

<span id="rtkf9p-w046" data-translation-unit="rtkf9p-w046"></span>

- 「Observation」：取得した観測数です。

<span id="rtkf9p-w047" data-translation-unit="rtkf9p-w047"></span>

- 「Current Acc」：現在の基地局が達成できる地理的な絶対精度です。Mission Plannerの下部にある緑の縦棒は、基地局が現在受信している衛星と信号強度を示します。基地局が希望する精度条件に達するまでには、一定の収束時間が必要です。より高い絶対精度が必要な場合は、さらに時間がかかることがあります。

:::note[原典について]
仕様表のサーベイイン時間はRTK＜10秒ですが、後の節は基地局精度への収束に時間が必要で、高精度ほど長くなると説明しています。どの条件にも10秒未満で完了するという保証へ広げず、それぞれの原典記載と測位状態の説明を保持します。
:::

<span id="rtkf9p-w048" data-translation-unit="rtkf9p-w048"></span>

ヒント：通常、「Surveyin」を2.5～3.0に設定できます。値が小さいほど待ち時間が長くなります。基地局の精度が2.5 mでも、移動局で解を求めた後にはセンチメートル級の測位精度を得ることができます。RTK基地局の設定が正常に完了すると、Mission Plannerに次のページが表示されます。

:::note[原典について]
原典は基地局のCurrent Accを絶対精度として説明する一方、基地局2.5mでも移動局でセンチメートル級精度を得られると記載しています。両者を同じ精度指標と推測で統合せず、原典の説明として保持します。実測精度や絶対座標精度を独立に保証したものではありません。

### 5.2 RTK測位状態

<span id="rtkf9p-w053" data-translation-unit="rtkf9p-w053"></span>

ペアになったデータ通信モジュールで同じMission Plannerへ接続すると、基地局のデータがデータ通信モジュールを通じてドローンのRTK移動局へ送られます。Mission Plannerでドローンの現在のGPS状態が「RTK Float」「RTK Fixed」「3D RTK」と表示され、RTK測位状態に入ったことを確認できます。

<span id="rtkf9p-w054" data-translation-unit="rtkf9p-w054"></span>

- 「RTK Float」はフロート解です。

<span id="rtkf9p-w055" data-translation-unit="rtkf9p-w055"></span>

- 「RTK Fixed」は固定解（フィックス解）です。

<span id="rtkf9p-w056" data-translation-unit="rtkf9p-w056"></span>

RTK Fixedはより高い精度を得られますが、周囲の環境について非常に厳しい条件があります。十分に良好な信号状態のときにだけ、RTK Fixed状態へ入ることができます。「3D RTK」は、中国語版Mission PlannerでRTK Float／RTK Fixedをまとめて表示する名称です。
