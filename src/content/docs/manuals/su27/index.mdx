1.2 SU27の各部品の使い方

1.2.1 使用上の注意

SU27の内部に水、油、砂などの異物が入っていないことを確認してください。SU27、送信機、バッテリーを含め、すべての機器が正常に機能することを確認してください。機体や関連部品を独自に改造しないでください。機能に影響し、飛行中の事故につながるおそれがあります。

1.2.2 送信機と受信機

SU27のRTF（Ready To Fly）版には、RadioLinkの8チャンネル送信機T8Sと小型受信機R8XMが付属します。安定した操縦距離は最大4,000 mで、リアルタイムテレメトリー機能を内蔵しています。最大距離は障害物と電波干渉のない場所で測定した値で、現地の法令によって異なる場合があります。

スティックモード

初心者は、各スティックとチャンネルの対応を理解し、自分に合ったモードを選ぶことが重要です。スロットルはスティックの上下で操作します。最上端が最大100%、最下端が最小0%です。以下はスロットルスティックが左側にあるMODE 2の例です。

- 左スティック：上下でモーターを制御します。上げると加速し、下げると減速します。左右に倒してもSU27の操舵面は動きません。
- 右スティック：上下でSU27のエレベーターミキシング、左右でエルロンミキシングを操作します。

T8S送信機の使い方

- 送信機のバッテリーが満充電であることを確認してください。T8Sの電池残量はLED表示で確認できます。LED 1灯が25%を示し、4灯すべてが点灯している場合は満充電です。
- 送信機を変更した場合は、使用前にバインドをやり直してください。詳細はRadioLink公式サイトのT8S取扱説明書を参照してください。https://www.radiolink.com/t8s_manual
- 着陸時は送信機より先にSU27の電源を切ってください。

SU27に標準で付属するR8XM受信機は、RSSI、受信機電圧、機体電圧をリアルタイムに送信します。テレメトリーの通信距離は操縦距離と同じ4,000 mです。R8XMは最大6S（25.2 V）のバッテリー電圧のテレメトリーに対応します。R8XMと他の機器の接続は、1.2.3「フライトコントローラー Byme-DB」を参照してください。

受信したRSSI、受信機電圧、機体電圧が設定した警報値を下回ると、送信機が警報音を鳴らします。

1. 送信機の低電圧警報：DDDDという短い音がすばやく連続します。T8Sはバッテリーを内蔵しています。警報電圧の既定値は3.7 Vで変更できません。
2. 機体の低電圧警報：DDDの3回を1組とする警報音が連続します。
3. 低RSSI警報：DDDDの4回を1組とする警報音が連続します。
4. 受信機の低電圧警報：DDDDDの5回を1組とする警報音が連続します。

機体電圧の警報値は既定で7.4 V（2Sバッテリー）です。SU27のバッテリー電圧が7.4 Vを下回ると、送信機がDDDと3回鳴って警告します。R8XM受信機の詳細はRadioLink公式サイトの取扱説明書を参照してください。https://www.radiolink.com/r8xm_manual

:::caution[受信機の電圧測定範囲]
6S（25.2 V）はR8XM受信機の電圧テレメトリーの測定上限です。この値を基準に機体の動力用バッテリーを選ばないでください。
:::
