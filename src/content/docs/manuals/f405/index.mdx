## ESCとコンデンサーの取り付け

<span id="f405-p16-esc" data-translation-unit="f405-p16-esc"></span>

:::caution[注意]
## 1. ESCの取り付け

レース用や曲技飛行用ドローンの一部は、CNC加工した導電性材料の底板を使用しています。正しく取り付けないと、ESC底部の電子部品と金属底板の安全な間隔が不足する場合があります。防振ボールや防振ブラケットの緩衝作用により、衝突・着陸時の衝撃でESCがずれて底板へ直接接触し、短絡してESCやフライトコントローラーを損傷するおそれがあります。
:::

大容量コンデンサーは、電圧の安定化、干渉の抑制、瞬間的なエネルギー供給により、複雑な動作条件でのESCの信頼性を大きく改善します。無人航空機の電源系統を安定動作させる重要な部品です。ESCにコンデンサーがないと、フライトコントローラーが損傷しやすくなります。
:::

<span id="f405-p17-functions" data-translation-unit="f405-p17-functions"></span>

## 大容量コンデンサーの機能

1. 電源電圧の安定化：モーターの始動・加速・急停止時には瞬間的に大電流を消費し、電源電圧が変動することがあります。コンデンサーが蓄えたエネルギーを素早く放出して一時的な電流不足を補い、電圧降下を防ぎます。
2. 高周波干渉の除去：ESCは高周波スイッチングでモーター速度を制御し、電流スパイクや電磁ノイズを発生させます。コンデンサーが高周波干渉を吸収し、ESCやFCへの信号干渉を減らします。
3. 電子部品の保護：モーターの急停止や拘束時には瞬間的な高電圧が発生することがあります。コンデンサーが異常エネルギーを吸収し、ESC内のMOSFETや電源回路の損傷を防ぎます。
4. 動的性能の改善：機体姿勢が急変するとき、一時的な電源としてESCの素早い制御応答を助け、モーター出力の連続性を保ちます。
