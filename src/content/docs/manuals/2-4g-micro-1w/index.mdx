### 注意

<span id="elrsmicro-p3-u16" data-translation-unit="elrsmicro-p3-u16"></span>

:::caution[注意]
（1）電源を入れる前にアンテナを取り付けてください。取り付けずに電源を入れると、Microモジュール内のPAチップが恒久的に損傷します。
:::

<span id="elrsmicro-p3-u17" data-translation-unit="elrsmicro-p3-u17"></span>

:::caution[注意]
（2）XT30ポートからMicroモジュールへ電源を供給する際は、3S以上のバッテリーを使用しないでください。使用すると、モジュール内の電源チップが恒久的に損傷します。
:::
