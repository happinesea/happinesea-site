## 第1部 安全上の注意

<span id="cb86plus-p3-safety1" data-translation-unit="cb86plus-p3-safety1"></span>

:::caution[注意]
1. 安全に使用するため、本書をよくお読みください。
:::

<span id="cb86plus-p3-safety2" data-translation-unit="cb86plus-p3-safety2"></span>

:::caution[注意]
2. DC電源が必要です。出力10.5～15V、出力電流15A以上のDC電源を用意してください。
:::

<span id="cb86plus-p3-safety3" data-translation-unit="cb86plus-p3-safety3"></span>

:::caution[注意]
3. 入力電源が大きく変動すると、充電器の焼損や、電池・電源の損傷を招く場合があります。電源仕様に応じて入力保護電圧を設定し、過負荷を防いでください。過負荷保護付き電源でも電圧が大きく変動するものがあります。
:::

<span id="cb86plus-p3-safety4" data-translation-unit="cb86plus-p3-safety4"></span>

:::caution[注意]
4. 先に電源へ充電器を接続して起動し、モード・電圧・電流を設定してから電池を接続し、STARTで充電します。電池を先に接続してから充電器へ通電してはいけません。満充電後は電池を外してから充電器の電源を切ってください。
:::

<span id="cb86plus-p3-safety5" data-translation-unit="cb86plus-p3-safety5"></span>

:::caution[注意]
5. 独立した1～6S電池を8ポートで順次充電できますが、12S電池は非対応です。12Sを充電する場合は独立した6Sパック2個へ分割する必要があります。2個の6Sパックを外部電気部品へ接続したままにすると、充電器や電池が焼損するおそれがあります。
:::

<span id="cb86plus-p3-safety6" data-translation-unit="cb86plus-p3-safety6"></span>

:::caution[注意]
6. 子供やペットから常に離してください。
:::

<span id="cb86plus-p3-safety7" data-translation-unit="cb86plus-p3-safety7"></span>

:::caution[注意]
7. 充放電中は監視してください。離れる必要がある場合は、予期しない危険や損傷を防ぐため電池を取り外してください。
:::

<span id="cb86plus-p3-safety8" data-translation-unit="cb86plus-p3-safety8"></span>

:::caution[注意]
8. 電池に合った充電電圧・電流へ設定してください。誤設定は損傷や発火を招きます。
:::

<span id="cb86plus-p3-safety9" data-translation-unit="cb86plus-p3-safety9"></span>

:::caution[注意]
9. 充電器へ金属や電線を入れないでください。
:::

<span id="cb86plus-p3-safety10" data-translation-unit="cb86plus-p3-safety10"></span>

:::caution[注意]
10. 漏液、膨張、外皮剥離、変色、変形など異常のある電池は充放電しないでください。
:::

<span id="cb86plus-p3-safety11" data-translation-unit="cb86plus-p3-safety11"></span>

:::caution[注意]
11. 異なる種類・容量・メーカーの電池を混ぜないでください。
:::

<span id="cb86plus-p3-safety12" data-translation-unit="cb86plus-p3-safety12"></span>

:::caution[注意]
12. 充電器を改造・分解しないでください。
:::

<span id="cb86plus-p3-safety13" data-translation-unit="cb86plus-p3-safety13"></span>

:::caution[注意]
13. 可燃性の台や可燃物の近くで使用せず、RC模型内や実車の車内で充放電しないでください。
:::

<span id="cb86plus-p3-safety14" data-translation-unit="cb86plus-p3-safety14"></span>

:::caution[注意]
14. 吸気穴を塞がず、閉鎖空間や高温環境で使用しないでください。内部温度保護で充放電が異常になる場合があります。
:::

<span id="cb86plus-p3-safety15" data-translation-unit="cb86plus-p3-safety15"></span>

:::caution[注意]
15. 充電できない乾電池を充電しないでください。
:::

<span id="cb86plus-p3-safety16" data-translation-unit="cb86plus-p3-safety16"></span>

:::caution[注意]
16. 電池の推奨最大充電レートを超えず、電池メーカーの推奨事項・安全上の助言に従ってください。
:::

<span id="cb86plus-p3-child-warning" data-translation-unit="cb86plus-p3-child-warning"></span>

:::caution[注意]
注意：14歳未満の子供に触れさせないでください。玩具ではありません。子供がいる場所での操作には十分注意してください。
:::

## 第2部 CB86-PLUSの概要

### 2.1 機能

1. 高精度：0.001Vで、0.01Vの競合品の10倍の精度です。
2. 充放電ポート8個。各ポートは1～6Sに対応し、個別に設定できます。
3. バランス電流6A。一般的な0.5Aより大きく、充電効率を高めます。
4. パラメーター設定後に全ポートの電池を自動走査し、順次充放電します。
5. 電源の最大出力が足りないときは、自動的に電流を下げて対応します。スムーズパワー技術で、瞬間的に定格出力を開始できない電源の問題へ対応します。

<span id="cb86plus-p3-folio" data-translation-unit="cb86plus-p3-folio"></span>

原典印刷ページ：2

<span id="cb86plus-p4-repair" data-translation-unit="cb86plus-p4-repair"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="cb86plus-p4-functions" data-translation-unit="cb86plus-p4-functions"></span>

7. 逆極性接続時は動作せず、充電器を保護します。
8. 入力電圧が高すぎると自動認識し、損傷を防ぎます。
9. 各セル専用のPUSH-PULLスイッチ回路を採用し、バランス充電で抵抗による電力消費がなく発熱を減らします。動作電流は最小135mA、充電効率最大97%、待機・動作にかかわらず動作温度は35℃と説明しています。
10. 初期・完了電圧、各セル容量、内部抵抗などをキー1つで表示します。
11. 充電開始10秒後から内部抵抗を表示し、セルのバランスと放電性能を判断できます。
12. 3S×2、4S＋2S、2S×3、1S×6を1つの6S相当として組み合わせ、組電池の6セルを同時に充放電できます。

<span id="cb86plus-p4-spec" data-translation-unit="cb86plus-p4-spec"></span>

## 2.2 仕様

寸法：188×104×57mm（7.4×4.09×2.24インチ）。重量：0.89kg。入力：DC10.5～15V。対応：1～6S（リチウム、リチウム鉄、高電圧リチウム）、8ポート。モード：CHARGE／DISCHARGE／STORAGE／修復充電。充電電圧：3.5～4.35V。普通のリチウムは1セル4.2V、リチウム鉄の終止電圧は3.6V、高電圧リチウムは4.35Vを推奨します。充電電流：0.3～6.0A。バランス電流：0.3～6.0A（充電電流と同じ）。放電電流：固定1.2A。画面：2.8インチTFT。ブザー：オン／オフ設定可能。最大出力：162W。

## 第6部 電圧校正

正常な充電器は校正しないでください。誤校正は過放電・過充電や爆発を招きます。誤差が0.2V以内なら校正できますが、0.3Vなど0.2Vを超える場合は故障の可能性があり、先にRadioLinkサポートへ相談してください。先に確認しないと過充電・爆発を招くおそれがあります。

注意：電池と電源の電圧を正確に測り、正確に入力してください。
:::

<span id="cb86plus-p15-calibration1" data-translation-unit="cb86plus-p15-calibration1"></span>

校正方法：
1. テスターで電源電圧を測り記録します。11～15Vの範囲である必要があります。
