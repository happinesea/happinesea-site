## 1. R8FGの概要

<span id="r8fg-w056" data-translation-unit="r8fg-w056"></span>

RadioLink R8FGは、防滴仕様の2.4 GHz・8チャンネル受信機です。プロのドリフト走行向けにジャイロを内蔵し、高電圧サーボに対応します。

<span id="r8fg-w057" data-translation-unit="r8fg-w057"></span>

R8FGに対応するRadioLink送信機は、RC8X、RC6GS V3、RC4GS V3、RC6GS V2、RC4GS V2、RC6GS（3ポジションスイッチ版）、RC4GS（製造日P.Dが180101より後の版）、T8FB(BT)、T8S(BT)、T8FB(OTG)、T8S(OTG)です。

<span id="r8fg-w058" data-translation-unit="r8fg-w058"></span>

<ManualFigure src="/assets/radiolink/r8fg/web-ja-v1/r8fg-p4-f2.jpeg" width={1000} height={500} figureId="r8fg-p4-f2" alt={"受信機の端子・各部名称。Reservedは未使用、Signalは信号、VCCは電源、GNDは接地を示します。CH1はステアリング、CH2はスロットル、CH3～CH7は補助、CH8は補助／SBUSです。バインドボタン（ID SET）と模型用バッテリー電圧のTelemetryポートも示しています。"} caption={"受信機の端子・各部名称。Reservedは未使用、Signalは信号、VCCは電源、GNDは接地を示します。CH1はステアリング、CH2はスロットル、CH3～CH7は補助、CH8は補助／SBUSです。バインドボタン（ID SET）と模型用バッテリー電圧のTelemetryポートも示しています。"} />

## 2. 受信機プロトコルの選択

<span id="r8fg-w060" data-translation-unit="r8fg-w060"></span>

R8FGをRC8X送信機で使用する場合は、最初にRC8Xで正しい受信機プロトコルを選択してからバインドしてください。RC8Xの「基本メニュー（Basic Menu）」→「受信機設定（Receiver setting）」で、FHSS V1またはFHSS V2を選択します（下図参照）。FHSS V1受信機のPWM出力分解能は2048、FHSS V2受信機は4096です。分解能が高いほど、サーボの動きをより細かい角度で制御できます。

<span id="r8fg-w061" data-translation-unit="r8fg-w061"></span>

<ManualFigure src="/assets/radiolink/r8fg/web-ja-v1/r8fg-p4-f3.jpeg" width={402} height={465} figureId="r8fg-p4-f3" alt={"「Receiver setting」のFHSS V1選択画面。ヒントはFHSS V1のPWM出力分解能2048、FHSS V2は4096で、R8FG_V1.0はFHSS V2非対応と説明しています。"} caption={"「Receiver setting」のFHSS V1選択画面。ヒントはFHSS V1のPWM出力分解能2048、FHSS V2は4096で、R8FG_V1.0はFHSS V2非対応と説明しています。"} />

<span id="r8fg-w062" data-translation-unit="r8fg-w062"></span>

<ManualFigure src="/assets/radiolink/r8fg/web-ja-v1/r8fg-p4-f4.jpeg" width={392} height={461} figureId="r8fg-p4-f4" alt={"「Receiver setting」のFHSS V2選択画面。「Servo Speed」は14 msです。FHSS V1はPWM出力分解能2048、FHSS V2は4096、R8FG_V1.0はFHSS V2非対応というヒントを表示しています。"} caption={"「Receiver setting」のFHSS V2選択画面。「Servo Speed」は14 msです。FHSS V1はPWM出力分解能2048、FHSS V2は4096、R8FG_V1.0はFHSS V2非対応というヒントを表示しています。"} />

<span id="r8fg-w063" data-translation-unit="r8fg-w063"></span>

図の「受信機リスト（Receivers List）」をクリックし、使用する受信機がFHSS V1とFHSS V2のどちらに対応するか確認してください。R8FG V1.0（製造日が2023年2月6日より前）はFHSS V1のみ対応し、FHSS V2には対応しません。R8FG V2.0以降（製造日が2023年2月6日以降）は、FHSS V1とFHSS V2の両方に対応します。模型を操作する前に、受信機プロトコルが正しく選択されていることを確認してください。誤った設定では、一部の機能が正常に動作しません。

:::note[原典について]
FHSS V2対応の製造日条件（2023年2月6日以降）と、3 ms／4 msデジタルサーボ対応の条件（V2.1または2023年4月26日以降）は別です。原典の版・製造日をそのまま保持し、同一条件として読み替えていません。
:::

## 3. サーボスピード設定

<span id="r8fg-w069" data-translation-unit="r8fg-w069"></span>

RC8XでFHSS V2を選択すると、画面に「サーボスピード（Servo Speed）」が表示されます（下図参照）。

<span id="r8fg-w070" data-translation-unit="r8fg-w070"></span>

<ManualFigure src="/assets/radiolink/r8fg/web-ja-v1/r8fg-p5-f2.jpeg" width={389} height={420} figureId="r8fg-p5-f2" alt={"FHSS V2で「Servo Speed: 14 ms」を表示した受信機設定画面。"} caption={"FHSS V2で「Servo Speed: 14 ms」を表示した受信機設定画面。"} />

<span id="r8fg-w071" data-translation-unit="r8fg-w071"></span>

### サーボスピードの設定方法

<span id="r8fg-w072" data-translation-unit="r8fg-w072"></span>

（1）送信機：RC8XのファームウェアをV1.1.5以降へ更新し、FHSS V2を選択すると、この設定項目が表示されます。サーボスピードは14 ms、4 ms、3 msから選択できます。既定値は14 ms（アナログサーボ用）です。4 msと3 msはデジタルサーボ用です。

<span id="r8fg-w073" data-translation-unit="r8fg-w073"></span>

（2）受信機：デジタルサーボを使用する場合は、4 msまたは3 msを選択する必要があります。使用する受信機がデジタルサーボに対応することを確認してください。R8FG V2.1と、製造日が2023年4月26日以降のR8FGがデジタルサーボに対応します。R8FG V1.0などの旧版はデジタルサーボに対応しません。旧版を使用して4 msや3 msを選択しても、既定の14 msで動作します。

:::note[原典について]
FHSS V2対応の製造日条件（2023年2月6日以降）と、3 ms／4 msデジタルサーボ対応の条件（V2.1または2023年4月26日以降）は別です。原典の版・製造日をそのまま保持し、同一条件として読み替えていません。
:::

<span id="r8fg-w074" data-translation-unit="r8fg-w074"></span>

（3）状態表示：サーボスピードを切り替えたとき、受信機の緑LEDが2回点滅すれば、切り替えは成功です。切り替え時に緑LEDが点滅しなければ、切り替えに失敗したか、受信機がデジタルサーボに対応していません。

<span id="r8fg-w075" data-translation-unit="r8fg-w075"></span>

## 4. バインド

<span id="r8fg-w076" data-translation-unit="r8fg-w076"></span>

各受信機には固有のIDコードがあり、使用前に送信機とバインドする必要があります。バインドが完了するとIDコードは送信機に保存され、毎回バインドし直す必要はありません。新しくR8FGを購入した場合は、送信機で使用するためにバインドを行ってください。

<span id="r8fg-w077" data-translation-unit="r8fg-w077"></span>

### バインド手順

<span id="r8fg-w078" data-translation-unit="r8fg-w078"></span>

（1）RC8Xで正しい受信機プロトコルを選択します（「2. 受信機プロトコルの選択」を参照）。注意：RC6GSやRC4GSなど、RC8X以外の送信機を使用する場合は、直接手順2へ進みます。

<span id="r8fg-w079" data-translation-unit="r8fg-w079"></span>

（2）送信機と受信機を約60 cm離して置きます。

<span id="r8fg-w080" data-translation-unit="r8fg-w080"></span>

（3）送信機と受信機の電源を入れると、R8FGのLEDがゆっくり点滅し始めます。

<span id="r8fg-w081" data-translation-unit="r8fg-w081"></span>

（4）受信機の側面にある黒いバインドボタン（ID SET）を1秒より長く押してから離します。LEDが速く点滅し、バインド処理中であることを示します。

<span id="r8fg-w082" data-translation-unit="r8fg-w082"></span>

（5）LEDの点滅が止まり、常時点灯すればバインド完了です。送信機のIPS画面上部に電波マークが表示されます（右図参照）。成功しなかった場合はLEDがゆっくり点滅し続けるため、上記の手順を繰り返してください。

## 6. サブID

<span id="r8fg-w121" data-translation-unit="r8fg-w121"></span>

RC8Xは複数の受信機とバインドできます。RC8Xと複数の受信機をバインドし、RC8Xとすべての受信機の電源を同時に入れた場合、以下の2通りの使い方があります。

<span id="r8fg-w122" data-translation-unit="r8fg-w122"></span>

1. サブID機能をOFFにすると、RC8Xで複数の機器を同時に操作できます。

<span id="r8fg-w123" data-translation-unit="r8fg-w123"></span>

<span id="r8fg-w124" data-translation-unit="r8fg-w124"></span>

## 8. ジャイロの概要

<span id="r8fg-w149" data-translation-unit="r8fg-w149"></span>

### 8.1 ジャイロ機能

<span id="r8fg-w150" data-translation-unit="r8fg-w150"></span>

R8FGはジャイロを内蔵しています。高性能ジャイロはソフトウェアフィルターとPIDアルゴリズムを採用し、迅速かつ正確に感度を補正して安定性を高めます。さまざまな模型に柔軟に対応し、ドリフトカーでもプロ向けの性能を実現します。

<span id="r8fg-w151" data-translation-unit="r8fg-w151"></span>

### 8.2 ジャイロの有効化

<span id="r8fg-w152" data-translation-unit="r8fg-w152"></span>

R8FGのジャイロは、既定でOFFになっています。内蔵ジャイロが自己点検を行うため、電源を入れるときはR8FGを静止させることが重要です。赤LEDはジャイロの状態表示で、消灯はジャイロOFFを示します。バインドボタンを1秒未満の間隔で3回押すと、赤LEDが3回点滅し、ジャイロが有効になったことを示します。

<span id="r8fg-w153" data-translation-unit="r8fg-w153"></span>

:::caution[注意]
注意：ジャイロがONの場合は、ジャイロがステアリングサーボの角度を自動補正するため、受信機に接続したサーボが揺れ続けることがあります。これは正常な動作です。この機能が不要な場合は、ジャイロをOFFにできます。
:::

<span id="r8fg-w154" data-translation-unit="r8fg-w154"></span>

:::caution[注意]
受信機を動かしていないのにサーボが揺れ続ける場合は、以下の2つの原因があります。
①サーボが受信機のSBUSチャンネルに接続されている：通常のサーボはPWM信号入力にのみ対応するため、CH1／2／3／4／5／6／7のいずれかに接続し直してください。
②ジャイロ感度が高すぎる：DL1スイッチを回して感度を下げてください。
:::

<span id="r8fg-w155" data-translation-unit="r8fg-w155"></span>

### 8.3 ジャイロリバース

<span id="r8fg-w156" data-translation-unit="r8fg-w156"></span>

### 8.4 ジャイロ感度の調整

<span id="r8fg-w162" data-translation-unit="r8fg-w162"></span>

ジャイロ感度は、既定でDL1／PS3ノブスイッチに割り当てられたCH8で調整します。ノブを時計回りに回すと感度が上がり、反時計回りに回すと下がります。ノブを回すと画面上部に黄色いヒントが表示され、チャンネル値も変わります。値が＋100に近いほど感度が高くなります。値が0の場合はジャイロがOFFであることを示します。

<span id="r8fg-w163" data-translation-unit="r8fg-w163"></span>

## 10. アンテナ取り付け時の注意

<span id="r8fg-w172" data-translation-unit="r8fg-w172"></span>

信号の伝送を最大限に活かすため、以下を強く推奨します。

<span id="r8fg-w173" data-translation-unit="r8fg-w173"></span>

:::caution[注意]
1. アンテナはできるだけまっすぐにしてください。曲がっていると有効操縦距離が短くなります。
:::

<span id="r8fg-w174" data-translation-unit="r8fg-w174"></span>

:::caution[注意]
2. 下図のように、2本のアンテナを90°の角度に保ってください。
:::

<span id="r8fg-w175" data-translation-unit="r8fg-w175"></span>

<ManualFigure src="/assets/radiolink/r8fg/web-ja-v1/r8fg-p12-f2.jpeg" width={700} height={383} figureId="r8fg-p12-f2" alt={"2本のアンテナを90°の角度に保つ取り付け例。"} caption={"2本のアンテナを90°の角度に保つ取り付け例。"} />

<span id="r8fg-w176" data-translation-unit="r8fg-w176"></span>

:::caution[注意]
3. 大型の模型には、信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状態でも最良の信号状態を確保できるよう、模型の両側にアンテナを配置してください。
:::

<span id="r8fg-w177" data-translation-unit="r8fg-w177"></span>

:::caution[注意]
4. アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。
:::

<span id="r8fg-w178" data-translation-unit="r8fg-w178"></span>

:::caution[注意]
5. アンテナはモーター、ESC、その他の干渉源となり得るものから離してください。
:::

<span id="r8fg-w179" data-translation-unit="r8fg-w179"></span>

:::caution[注意]
6. 受信機の取り付けには、振動を抑えるためスポンジや発泡材の使用を推奨します。
:::

<span id="r8fg-w180" data-translation-unit="r8fg-w180"></span>

:::caution[注意]
7. 受信機には高精度の電子部品が含まれます。強い振動や高温を避けてください。
:::

<span id="r8fg-w181" data-translation-unit="r8fg-w181"></span>

:::caution[注意]
8. 受信機を保護するため、発泡材やゴム布など、RC用の防振材で包んでください。密閉したビニール袋に入れると、受信機が制御不能になる原因となり得る湿気やほこりを防げます。
:::
