### 1. 安全上の注意

:::note[原典について]
本文に版・適用製品世代の明示がない。公式リンクの日付のみで現行全ロットに適用できるとは認定しない。

<span id="cm210-p3-safety" data-translation-unit="cm210-p3-safety"></span>

:::caution[注意]
(1) CM210を安全に操作するため、使用前に本書をよくお読みください。

(2) 先にCM210を電源へ接続してから、充電する2S LiPoバッテリーを接続してください。

(3) 充電器は常に子供やペットから離してください。

(4) 充電中は充電器を監視してください。

(5) バッテリーに漏液、膨張、外皮の剥離、変色、変形などの異常がある場合は充電しないでください。

(6) 充電器を改造・分解しないでください。

(7) 使用中は充電器やバッテリーを可燃物に近づけないでください。

(8) 充電できない乾電池を充電しようとしないでください。
:::

### 2. 機能

:::note[原典について]
本文に版・適用製品世代の明示がない。公式リンクの日付のみで現行全ロットに適用できるとは認定しない。
:::

<span id="cm210-p4-function1" data-translation-unit="cm210-p4-function1"></span>

(1) 低電力予備充電：バッテリーの1セルの電圧が3.0V未満であることを検出すると、小電流でバッテリーを活性化して容量を回復させます。

:::note[原典について]
3.0V未満、3.0V超かつ4.16V未満、4.16V超と記述され、ちょうど3.0V/4.16Vの境界状態は明示されない。以上・以下へ変更しない。
:::

<span id="cm210-p4-function2" data-translation-unit="cm210-p4-function2"></span>

(2) 急速充電：バッテリーの1セルの電圧が3.0Vを超え、4.16V未満であることを検出すると、1.5Aで充電します。

:::note[原典について]
3.0V未満、3.0V超かつ4.16V未満、4.16V超と記述され、ちょうど3.0V/4.16Vの境界状態は明示されない。以上・以下へ変更しない。
:::

<span id="cm210-p4-function3" data-translation-unit="cm210-p4-function3"></span>

(3) トリクル充電：バッテリーの1セルの電圧が4.16Vを超えたことを検出すると、0.8Aで充電して満充電にし、過充電を防ぎます。

:::note[原典について]
3.0V未満、3.0V超かつ4.16V未満、4.16V超と記述され、ちょうど3.0V/4.16Vの境界状態は明示されない。以上・以下へ変更しない。
:::

<span id="cm210-p4-function4" data-translation-unit="cm210-p4-function4"></span>

(4) 温度制御：基板温度が75℃を超えたことを検出すると、充電電流を所定の電流の2/3へ下げて基板温度を下げます。基板温度が70℃未満になったことを検出すると、所定の電流に戻して充電します。

<span id="cm210-p4-function5" data-translation-unit="cm210-p4-function5"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="cm210-p4-function6" data-translation-unit="cm210-p4-function6"></span>

(6) バランス充電：バッテリー電圧が4.16Vまで充電されたとき、2つのバッテリーの電圧が等しくないことを検出すると、バランス充電を開始し、電圧をそろえます。

:::note[原典について]
原典(6)はtwo batteriesと記載し、4.16Vの対象も明示していません。2Sのセル電圧と推測で置換せず、2つのバッテリーという原文表現を保持しています。
:::

<span id="cm210-p4-function7" data-translation-unit="cm210-p4-function7"></span>

(7) 充電異常通知：長時間電流が検出されないと、充電を自動的に停止し、赤色LEDが点滅して異常を知らせます。

<span id="cm210-p4-function8" data-translation-unit="cm210-p4-function8"></span>

(8) 充電時間：500mAhの2Sバッテリーで約40分です。

<span id="cm210-p4-function9" data-translation-unit="cm210-p4-function9"></span>

(9) 電圧精度：満充電電圧は4.20V±0.02Vです。

<span id="cm210-p4-function10" data-translation-unit="cm210-p4-function10"></span>

(10) 充電効率：82%を超えます。

### 4. 使用方法

:::note[原典について]
本文に版・適用製品世代の明示がない。公式リンクの日付のみで現行全ロットに適用できるとは認定しない。
:::

<span id="cm210-p5-step1" data-translation-unit="cm210-p5-step1"></span>

1. 標準USBケーブルの一端をCM210充電器のType-C入力端子へ挿入し（下図参照）、もう一端をモバイルバッテリー、コンピューター、携帯電話用アダプターなどの電源機器へ接続します。正しく接続すると、赤色LEDが点灯し続けます。

:::note[原典について]
最大出力20W、入力5V、充電電流1.5A、バランス電流0.8Aは原典の別項目として保持しています。最大出力の測定条件および通常充電用アダプターの必要入力電流は明示されていません。校正時の5V/3Aを通常充電用の推奨値とみなさず、出力から入力電流を推測していません。
:::

<span id="cm210-p5-step2" data-translation-unit="cm210-p5-step2"></span>

2. A560標準の2Sリチウムバッテリーのバランス端子をCM210の充電端子へ挿入します（下図参照）。緑色LEDが点滅を始め、充電開始を示します。（注意：充電中の緑色LEDの点滅は正常充電を示し、赤色LEDの点滅は充電異常を示します。バッテリーとケーブルを接続し直して異常を解消してください。）

3. 4つのLEDがすべて緑色で点灯し続けると満充電となり、充電器は自動的に充電を停止します。

| LEDの色 | 状態 | 意味 |
| --- | --- | --- |
| 赤 | 点滅 | 充電器が異常を検出。 |

| 緑 | 最初の3つが点灯し続け、4つ目が点滅。他のLEDは消灯 | バッテリー電圧が8.4V未満。 |

### 7. よくある問題のトラブルシューティング

:::note[原典について]
本文に版・適用製品世代の明示がない。公式リンクの日付のみで現行全ロットに適用できるとは認定しない。
:::

<span id="cm210-p7-problem1" data-translation-unit="cm210-p7-problem1"></span>

1. 充電器の電源を入れ、バッテリーを挿入した直後、または1分以内に赤色LEDが点滅する。

A. 電流検出抵抗が焼損し、MCUが過大な電流を検出しています。

B. スイッチング素子が損傷して正常にスイッチングできません。電流出力がないか、電源の出力電流が小さすぎます。

<span id="cm210-p7-problem2" data-translation-unit="cm210-p7-problem2"></span>

2. 充電器の電源を入れてバッテリーを挿入し、しばらく正常に充電した後で赤色LEDが点滅する。

A. 電源の出力電流が小さすぎるか、バッテリーが損傷しています。

対処：電源またはバッテリーを交換して再度充電してください。それでも異常が発生する場合、充電器が損傷しています。
