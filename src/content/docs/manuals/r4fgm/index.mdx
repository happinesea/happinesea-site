## 2. 受信機プロトコルの選択

<span id="r4fgm-w036" data-translation-unit="r4fgm-w036"></span>

R4FGMをRC8X送信機と組み合わせる場合は、最初にRC8Xで正しい受信機プロトコルを選択し、その後でバインド（リンク）してください。RC8Xの基本メニュー（Basic Menu）から受信機設定（Receiver setting）を開き、下図のようにFHSS V1またはFHSS V2プロトコルを選択します。FHSS V1受信機のPWM出力分解能は2048、FHSS V2受信機は4096です。分解能が高いほど、サーボの動作角を細かく制御できます。

<span id="r4fgm-w037" data-translation-unit="r4fgm-w037"></span>

<ManualFigure src="/assets/radiolink/r4fgm/web-ja-v1/r4fgm-p5-f2.jpeg" width={402} height={465} figureId="r4fgm-p5-f2" alt={"受信機設定画面：FHSS V1の選択例。図中のヒントにはFHSS V1のPWM出力分解能2048、FHSS V2は4096、およびR8FG_V1.0はFHSS V2に非対応と表示されています。"} caption={"受信機設定画面：FHSS V1の選択例。図中のヒントにはFHSS V1のPWM出力分解能2048、FHSS V2は4096、およびR8FG_V1.0はFHSS V2に非対応と表示されています。"} />

:::note[原典について]
原図画面のヒントはR8FG_V1.0を名指ししています。画面を改変せず保持し、その製品名をR4FGMの適用条件へ読み替えていません。本文に記載されたR4FGMの版条件を参照してください。
:::

:::

<span id="r4fgm-w043" data-translation-unit="r4fgm-w043"></span>

サーボ速度の設定方法：

<span id="r4fgm-w044" data-translation-unit="r4fgm-w044"></span>

（1）送信機：この項目を表示するには、RC8XのファームウェアをV1.1.5以降に更新し、FHSS V2プロトコルを選択する必要があります。サーボ速度は14 ms、4 ms、3 msから選択できます。初期設定は14 ms（アナログサーボ速度）で、4 msと3 msはデジタルサーボ速度です。

## 6. 動作モード

<span id="r4fgm-w072" data-translation-unit="r4fgm-w072"></span>

R4FGMには2つの動作モードがあります。工場出荷時の初期設定は、ジャイロを使用せずPWM信号を出力する標準モードです。もう一つはジャイロモードです。

<span id="r4fgm-w073" data-translation-unit="r4fgm-w073"></span>

### 6.1 標準モード（工場出荷時の初期設定）

<span id="r4fgm-w074" data-translation-unit="r4fgm-w074"></span>

緑色表示灯が点灯している場合、Ch1～Ch4は標準PWM信号を出力します。

<span id="r4fgm-w075" data-translation-unit="r4fgm-w075"></span>

### 6.2 ジャイロモード

<span id="r4fgm-w076" data-translation-unit="r4fgm-w076"></span>

R4FGMは、本格的なドリフト走行や小型カー（MINIZ）向けのジャイロを内蔵しています。

<span id="r4fgm-w077" data-translation-unit="r4fgm-w077"></span>

ID SETを1秒未満の間隔で3回短く押すと、赤色表示灯が3回点滅します。赤色LEDの点灯／消灯は、ジャイロ機能のON／OFFを示します。

<span id="r4fgm-w078" data-translation-unit="r4fgm-w078"></span>

進行方向を安定させ、車のスリップを抑えます。高速走行時の横滑りを防ぎ、より安全に旋回できます。

<span id="r4fgm-w079" data-translation-unit="r4fgm-w079"></span>

## 7. ジャイロ機能

<span id="r4fgm-w080" data-translation-unit="r4fgm-w080"></span>

R4FGMに内蔵された本格的なカー用ジャイロは、有効／無効を切り替えられます。有効にすると、競技中の旋回安定性を最大限に高められます。姿勢が乱れた場合も、ジャイロ機能により車をまっすぐ進ませ、正確に旋回させます。

<span id="r4fgm-w081" data-translation-unit="r4fgm-w081"></span>

### 7.1 ジャイロを有効にする

<span id="r4fgm-w082" data-translation-unit="r4fgm-w082"></span>

工場出荷時の初期設定では、ジャイロ機能はOFFです。R4FGMの電源を入れると、ジャイロがセルフチェックを行います。R4FGMには2つの表示灯があり、緑色LEDの常灯はジャイロなしの動作モードを示します。

ID SETを1秒未満の間隔で3回短く押すと、赤色表示灯が3回点滅します。緑色と赤色の両LEDが常灯する状態は、ジャイロありの動作モードです。

<span id="r4fgm-w083" data-translation-unit="r4fgm-w083"></span>

:::caution[注意]
注意：受信機に接続したサーボが揺れ続けることがありますが、これは正常です。ジャイロ機能をONにしている場合、ジャイロがサーボのステアリング角を自動補正しているためです。この機能が不要であれば、ジャイロ機能をOFFにできます。
:::

<span id="r4fgm-w084" data-translation-unit="r4fgm-w084"></span>

:::caution[注意]
受信機を動かしていないのにサーボが揺れ続ける場合は、ジャイロ感度が高すぎる可能性があります。ジャイロ感度を下げてください。
:::

<span id="r4fgm-w085" data-translation-unit="r4fgm-w085"></span>

### 7.2 ジャイロの動作方向

<span id="r4fgm-w086" data-translation-unit="r4fgm-w086"></span>

模型飛行機と同様に、カー用ジャイロにも動作方向があります。正しい動作方向に設定されている場合にのみ、ジャイロは常に正しい方向へ補正できます。ジャイロの正方向を有効にした状態で模型の車体を回し、車輪が補正されるか確認します。通常、車体を左へ回すと車輪は右へ、車体を右へ回すと車輪は左へ向いて補正します。ジャイロの動作方向が逆の場合は、ID SETを1秒未満の間隔で2回短く押します。赤色表示灯が2回点滅すると、ジャイロの動作方向の設定は完了です。

### 7.3 ジャイロ感度の調整

<span id="r4fgm-w090" data-translation-unit="r4fgm-w090"></span>

ジャイロ感度は、初期設定（工場出荷時設定）ではCH3に割り当てられています。RC6GS／RC4GS送信機を使用する場合は、VRダイヤルでジャイロ感度を調整できます。調整時にはパーセント表示され、値が大きいほど感度が高くなります。VRダイヤル／CH3に別の機能を設定している場合は、送信機のメニュー設定でジャイロ感度を調整できます。RC8X送信機をR4FGMと組み合わせる場合は、感度調整をDL1に設定するか、ジャイロミキシングの設定画面で「-」または「+」をクリックして調整できます。

## 9. アンテナ設置時の注意

<span id="r4fgm-w094" data-translation-unit="r4fgm-w094"></span>

:::caution[注意]
信号伝送を最大限に確保するため、次の事項を強く推奨します。

- アンテナはできるだけまっすぐにしてください。曲がっていると有効制御距離が短くなります。
- 大型模型には、信号の放射に影響する金属部品が含まれる場合があります。この場合は、あらゆる状況で良好な信号状態を確保するため、模型の両側にアンテナを配置してください。
- アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。
- アンテナはモーター、ESC、その他の干渉源となる可能性のある機器から離してください。
- 受信機の取り付け時には、防振のためにスポンジや発泡材の使用を推奨します。
- 受信機には高精度の電子部品が含まれています。強い振動や高温を避けるよう注意してください。
:::
