### R8XMの概要

<span id="r8xm-w031" data-translation-unit="r8xm-w031"></span>

RadioLink R8XMは、制御距離4000 mの2.4G・8チャンネル受信機です。PPMおよびSBUS信号出力に対応し、RadioLink送信機T8FB(BT)／T8S(BT)／T8FB(OTG)／T8S(OTG)／RC6GS V3／RC6GS V2／RC6GS／RC4GS V3／RC4GS V2／RC4GSに対応しています（フライトコントローラーと組み合わせて使用する必要があります）。

### バインド

<span id="r8xm-w034" data-translation-unit="r8xm-w034"></span>

各受信機には固有のIDコードがあり、使用前に送信機とのバインド（リンク）が必要です。バインドが完了すると、IDコードが送信機に保存され、再度バインドする必要はありません。そのため、新しいR8XMを購入した場合は、送信機で使用するためにバインドを行う必要があります。（注意：R8XMは2016年12月より前に製造されたT8FBには対応していません。）

<span id="r8xm-w035" data-translation-unit="r8xm-w035"></span>

バインド手順

1. 送信機とR8XM受信機を50 cmより離して置きます。

<span id="r8xm-w036" data-translation-unit="r8xm-w036"></span>

:::caution[原典確認待ち]
この箇所は原典の記載または適用条件に確認が必要なため、操作・接続の案内を保留しています。確認が取れるまで、この箇所を根拠に機器を操作・接続しないでください。
:::

<span id="r8xm-w037" data-translation-unit="r8xm-w037"></span>

3. 受信機側面の「ID SET」を1秒より長く押すと、LED表示が点滅し、バインドが開始したことを示します。

<span id="r8xm-w038" data-translation-unit="r8xm-w038"></span>

4. LED表示の点滅が止まると、バインドは完了です。
5. 模型のサーボをテストし、送信機で操作できることを確認します。

<span id="r8xm-w039" data-translation-unit="r8xm-w039"></span>

:::caution[注意]
注意：
1. R8XMには信号増幅機能があり、テレメトリー範囲は制御範囲と同じ4000 mです。そのため、バインド時には送信機とR8XM受信機を50 cmより離しておくのが最適です。送信機とR8XM受信機が近すぎると信号が遮断されやすく、バインドできません。バインド成功後でも、送信機とR8XM受信機が近すぎる場合（例：50 cm以内）は、信号を失うことがあります。送信機とR8XM受信機をさらに離すと、信号の喪失は自動的に解消します。
:::

### アンテナ取り付け上の注意

<span id="r8xm-w049" data-translation-unit="r8xm-w049"></span>

信号伝送を最大限に確保するため、以下を強く推奨します。

1. アンテナはできるだけまっすぐにしてください。そうしないと、有効な制御範囲が狭くなります。
2. 大型模型には、信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状況でも良好な信号状態を確保できるよう、アンテナを模型の両側に配置してください。
3. アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。
4. アンテナはモーター、ESC、その他の干渉源となる可能性のあるものから離してください。
5. 受信機の取り付け時には、振動を防ぐため、スポンジや発泡材の使用を推奨します。
6. 受信機には高精度の電子部品が含まれています。強い振動や高温を避けるよう注意してください。
7. 発泡材やゴム布などのR/C用防振材で受信機を包んで保護します。密閉したビニール袋に入れることで、受信機が制御不能になる原因となり得る湿気やほこりを防げます。

### リアルタイム内蔵テレメトリー

<span id="r8xm-w052" data-translation-unit="r8xm-w052"></span>

R8XMは、RSSI、受信機電圧、機体電圧のリアルタイム伝送に対応しています。テレメトリー範囲は制御範囲と同じ4000 mです。

<span id="r8xm-w053" data-translation-unit="r8xm-w053"></span>

#### RSSIと受信機電圧のテレメトリー

<span id="r8xm-w054" data-translation-unit="r8xm-w054"></span>

送信機と受信機のバインドが成功すると、RSSIと受信機電圧が表示されます。

<span id="r8xm-w055" data-translation-unit="r8xm-w055"></span>

#### 機体電圧のテレメトリー

<span id="r8xm-w056" data-translation-unit="r8xm-w056"></span>

バッテリーのバランス端子をR8XMのテレメトリーポートに接続すると、機体電圧が表示されます。外付けの動力用バッテリー電圧テレメトリーモジュールは不要で、R8XMは最大6S（25.2 V）のバッテリー電圧テレメトリーに対応します。標準では2Sバッテリー用テレメトリーケーブルが付属しています。3S、4S、5S、6Sなどの別のバッテリーを接続する場合は、テレメトリーケーブルを自身で交換してください。

:::note[原典について]
バッテリーのテレメトリーは最大6S（25.2 V）ですが受信機の動作電圧は3～6 Vです。機体電圧テレメトリーポートと受信機電源を混同しないことが必要です。接続図と本文は保持し、端子を推測で変更しません。
:::

#### RSSIおよび低電圧アラームの通知音

<span id="r8xm-w071" data-translation-unit="r8xm-w071"></span>

<span id="r8xm-w073" data-translation-unit="r8xm-w073"></span>

② 受信機の低電圧アラーム：DDDDDの5回のビープ音を1組として、連続して通知します。

<span id="r8xm-w074" data-translation-unit="r8xm-w074"></span>

③ 機体の低電圧アラーム：DDDの3回のビープ音を1組として、連続して通知します。

### R8XMの仕様

<span id="r8xm-w081" data-translation-unit="r8xm-w081"></span>

- 型名：R8XM
- 寸法：22×17 mm（0.87×0.67インチ）
- 重量：3 g（ケーブルを含む場合4 g）
- アンテナ長：90 mm
- チャンネル数：8チャンネル
- 動作電圧：DC 3～6 V
- 動作電流：40 mA±5 mA（5 V時）
- 信号：SBUS／PPM
- 出力周波数：2.4 GHz ISM帯（2400～2483.5 MHz）
- スペクトラム拡散方式：FHSS、67チャンネルの疑似ランダム周波数ホッピング
- 対応模型：レーシングドローン／回転翼機／固定翼機／グライダー／マルチコプター／車／ボート／ロボット（フライトコントローラーと組み合わせて使用する必要があります）
- 制御距離：空中で4000 m（2.49マイル）。障害物や干渉のない場所で試験した最大範囲で、地域の規制によって異なる場合があります。
- 伝送：信号、RSSI、受信機電圧、機体電圧のテレメトリー（テレメトリー距離は制御距離と同じ）
- 機体電圧テレメトリー：2S～6S LiPoバッテリー（7.4～25.2 V）
- 対応送信機：T8FB(BT)／T8S(BT)／T8FB(OTG)／T8S(OTG)／RC6GS V3／RC6GS V2／RC6GS／RC4GS V3／RC4GS V2／RC4GS（フライトコントローラーと組み合わせて使用する必要があります）
