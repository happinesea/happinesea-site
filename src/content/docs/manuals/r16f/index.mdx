## 1. R16Fの概要

<span id="r16f-w025" data-translation-unit="r16f-w025"></span>

RadioLink R16Fは、リアルタイム内蔵テレメトリーに対応する16チャンネル受信機です。2.4 GHz FHSSスペクトラム拡散方式と67チャンネルの疑似ランダム周波数ホッピングを採用し、PWM、SBUS、CRSF信号に対応します。防滴仕様で、高電圧サーボに対応し、ファームウェアを更新することで新しい機能を追加できます。対応するRadioLink送信機は、T16D、T12D、T8FB、T8S、RC8P、RC8X、RC6GS V3、RC4GS V3、RC6GS V2、RC4GS V2、RC6GS、RC4GSです。

## 4. テレメトリー

<span id="r16f-w055" data-translation-unit="r16f-w055"></span>

R16Fはリアルタイム内蔵テレメトリーに対応し、信号強度、RSSI値、受信機電圧、模型用バッテリー電圧を送信機へ返送します。R16Fをフライトコントローラーに接続し、T16D／T12Dのベイトボート機能を使用すると、釣りポイント名、緯度・経度、距離、方位、受信GPS衛星数などが送信機画面に表示されます。

<span id="r16f-w056" data-translation-unit="r16f-w056"></span>

動力用バッテリーの電圧を返送するには、テレメトリーケーブルの一端をR16Fのテレメトリーポートに、もう一端をESCに接続します。接続方法は下図を参照してください。

<span id="r16f-w057" data-translation-unit="r16f-w057"></span>

<ManualFigure src="/assets/radiolink/r16f/web-ja-v1/r16f-p5-f1.jpeg" width={1700} height={1228} figureId="r16f-p5-f1" alt={"模型用バッテリー電圧テレメトリーケーブルの接続図。受信機、エルロンサーボ、エレベーターサーボ、ラダーサーボ、バッテリー、ESC、モーターの位置を示します。受信機への給電とExtポートの電圧測定を混同しないでください。"} caption={"模型用バッテリー電圧テレメトリーケーブルの接続図。受信機、エルロンサーボ、エレベーターサーボ、ラダーサーボ、バッテリー、ESC、モーターの位置を示します。受信機への給電とExtポートの電圧測定を混同しないでください。"} />

## 6. ファームウェア更新

<span id="r16f-w087" data-translation-unit="r16f-w087"></span>

R16Fはファームウェア更新に対応します。更新手順は以下のとおりです。

<span id="r16f-w088" data-translation-unit="r16f-w088"></span>

（1）Type-CケーブルをR16FのType-Cポートに差し込みます。

<span id="r16f-w089" data-translation-unit="r16f-w089"></span>

<ManualFigure src="/assets/radiolink/r16f/web-ja-v1/r16f-p9-f1.jpeg" width={1076} height={777} figureId="r16f-p9-f1" alt={"ファームウェア更新用Type-Cポートの位置。"} caption={"ファームウェア更新用Type-Cポートの位置。"} />

<span id="r16f-w090" data-translation-unit="r16f-w090"></span>

（2）R16Fのバインドボタンを押したままにします。

<span id="r16f-w091" data-translation-unit="r16f-w091"></span>

（3）Type-Cケーブルのもう一端をパソコンに接続し、バインドボタンを離します。

<span id="r16f-w092" data-translation-unit="r16f-w092"></span>

（4）受信機のLEDが点灯し、パソコンにUSBフラッシュドライブが表示されます。

<span id="r16f-w093" data-translation-unit="r16f-w093"></span>

（5）R16Fの新しいファームウェアをUSBフラッシュドライブへコピー＆ペーストすると、更新が完了します。

## 7. アンテナの取り付け

<span id="r16f-w095" data-translation-unit="r16f-w095"></span>

受信機のアンテナは模型に正しく取り付けることが重要です。取り付けが不適切だと、信号品質が低下します。

<span id="r16f-w096" data-translation-unit="r16f-w096"></span>

<ManualFigure src="/assets/radiolink/r16f/web-ja-v1/r16f-p9-f2.jpeg" width={1000} height={500} figureId="r16f-p9-f2" alt={"2本のアンテナを90°の角度に保つ取り付け例。"} caption={"2本のアンテナを90°の角度に保つ取り付け例。"} />

<span id="r16f-w097" data-translation-unit="r16f-w097"></span>

受信機のアンテナの取り付け方は、信号品質にどのように影響するのでしょうか。以下は、アンテナ取り付け時の一般的な誤りです。

<span id="r16f-w098" data-translation-unit="r16f-w098"></span>

:::caution[注意]
（1）受信機の2本のアンテナを重ねないでください。互いに干渉します。右図のように、2本のアンテナを90°の角度に保ってください。
:::

<span id="r16f-w099" data-translation-unit="r16f-w099"></span>

:::caution[注意]
（2）金属物の近くにアンテナを置かないでください。導電性の板による反射で、信号が大きく悪化します。
:::

<span id="r16f-w100" data-translation-unit="r16f-w100"></span>

:::caution[注意]
（3）アンテナを地面と平行にしないでください。地面に対して垂直に配置してください。
:::

<span id="r16f-w101" data-translation-unit="r16f-w101"></span>

:::caution[注意]
（4）大型の模型には、信号の放射に影響する金属部品が含まれる場合があります。その場合は、どのような状態でも最良の信号状態を確保できるよう、模型の両側にアンテナを配置してください。
:::

<span id="r16f-w102" data-translation-unit="r16f-w102"></span>

:::caution[注意]
（5）アンテナは金属導体やカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。
:::

<span id="r16f-w103" data-translation-unit="r16f-w103"></span>

:::caution[注意]
（6）アンテナはモーター、ESC、その他の干渉源となり得るものから離してください。
:::

<span id="r16f-w104" data-translation-unit="r16f-w104"></span>

:::caution[注意]
（7）受信機の取り付けには、振動を抑えるためスポンジや発泡材の使用を推奨します。
:::

<span id="r16f-w105" data-translation-unit="r16f-w105"></span>

:::caution[注意]
（8）受信機には高精度の電子部品が含まれます。強い振動や高温を避けてください。
:::

<span id="r16f-w106" data-translation-unit="r16f-w106"></span>

:::caution[注意]
（9）受信機を保護するため、発泡材やゴム布など、RC用の防振材で包んでください。密閉したビニール袋に入れると、受信機が制御不能になる原因となり得る湿気やほこりを防げます。
:::

<span id="r16f-w107" data-translation-unit="r16f-w107"></span>

受信機のアンテナ取り付けガイドは、以下のリンクを参照してください。
https://www.radiolink.com/receiver_antenna_installation

## 8. RSSI試験

<span id="r16f-w109" data-translation-unit="r16f-w109"></span>

操縦距離が短い場合は、以下の説明を参考に送受信機間のRSSIを試験してください。送信機のRSSI値の試験手順と、RSSI値の異常への対処方法を説明します。

<span id="r16f-w110" data-translation-unit="r16f-w110"></span>

原典印刷ページ：8

<span id="r16f-w111" data-translation-unit="r16f-w111"></span>

（1）送信機の電源を入れると同時に受信機にも給電します。送受信機が接続されます。接続されない場合は、再度バインドしてください。送信機画面に電波マークが表示されれば、バインド成功です。ホーム画面にRSSI値が表示され、送受信機間の距離に応じて変化します（右図参照）。

<span id="r16f-w112" data-translation-unit="r16f-w112"></span>

<ManualFigure src="/assets/radiolink/r16f/web-ja-v1/r16f-p10-f1.jpeg" width={319} height={241} figureId="r16f-p10-f1" alt={"T16D画面のRSSI表示位置の例。原図はRSSI −99 dBm、RX_V 5 V、EXT_V 12 Vを表示しています。表示値は原典の画面例です。"} caption={"T16D画面のRSSI表示位置の例。原図はRSSI −99 dBm、RX_V 5 V、EXT_V 12 Vを表示しています。表示値は原典の画面例です。"} />

<span id="r16f-w113" data-translation-unit="r16f-w113"></span>

（2）受信機と送信機のアンテナを平行にし、約60 cm離して、両方のアンテナをまっすぐにします。RSSI値が0～−30 dBmの範囲であれば正常です。値が0に近いほど信号が強いことを示します（下図参照）。

<span id="r16f-w114" data-translation-unit="r16f-w114"></span>

<ManualFigure src="/assets/radiolink/r16f/web-ja-v1/r16f-p10-f2.jpeg" width={2017} height={1403} figureId="r16f-p10-f2" alt={"RSSI試験で送信機と受信機を約60 cm離す原典図。"} caption={"RSSI試験で送信機と受信機を約60 cm離す原典図。"} />

<span id="r16f-w115" data-translation-unit="r16f-w115"></span>

### 信号強度が異常な場合の対処

<span id="r16f-w116" data-translation-unit="r16f-w116"></span>

受信機と送信機のアンテナに損傷がないか確認してください。信号強度の低下の多くは、アンテナの損傷が原因です。損傷があればアンテナを交換してください。損傷がない場合は、受信機を交換して送信機または受信機の不具合を確認できます。それでも解決しない場合は、after_service@radiolink.com.cnへメールでサポートを依頼してください。

## 9. サブID（T16D送信機を例に説明）

<span id="r16f-w118" data-translation-unit="r16f-w118"></span>

RadioLink送信機は複数の受信機とバインドできます。T16Dと複数の受信機のバインドが完了し、T16Dとすべての受信機の電源を同時に入れた場合、以下の2通りの使い方があります。

<span id="r16f-w119" data-translation-unit="r16f-w119"></span>

1. サブID機能をOFFにすると、T16Dで複数の機器を同時に操作できます。

<span id="r16f-w120" data-translation-unit="r16f-w120"></span>

2. サブID機能をONにすると、選択したサブIDに対応する機器だけをT16Dで操作できます。T16Dには16組のサブIDがあり、各IDが1台の受信機に対応します。先にサブIDを設定してください。すべての機器の電源を入れた状態で、サブID機能により1台を操作し、その間、ほかの機器は待機します。

<span id="r16f-w121" data-translation-unit="r16f-w121"></span>

例として、T16Dをトラックと車にバインドして、すべての電源を入れます。まずT16Dで車をトラックの荷台へ走らせ、次に受信機IDをトラックへ切り替えて、車を目的地まで運びます。

<span id="r16f-w122" data-translation-unit="r16f-w122"></span>

原典印刷ページ：9

<span id="r16f-w123" data-translation-unit="r16f-w123"></span>

### サブID機能の設定手順

<span id="r16f-w124" data-translation-unit="r16f-w124"></span>

1. サブID機能をONにします。模型に合わせてID番号を設定し、各受信機のバインドとパラメータ設定を完了します。

<span id="r16f-w125" data-translation-unit="r16f-w125"></span>

<span id="r16f-w126" data-translation-unit="r16f-w126"></span>

2. サブIDをONにすると、T16Dのメイン画面に対応するID番号が表示されます。

<span id="r16f-w127" data-translation-unit="r16f-w127"></span>

:::caution[注意]
注意：T16D／T12Dでは、2ポジションまたは3ポジションスイッチを割り当て、サブID番号を切り替えられます。詳細はT16D／T12Dの「CONDITION」機能を参照してください。
