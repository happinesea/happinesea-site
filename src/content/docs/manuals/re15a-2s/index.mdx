## 1. 主な特長

<span id="re15a-p3-u02" data-translation-unit="re15a-p3-u02"></span>

- 固定翼用に最適化したBLHeli_Sアルゴリズムと高性能MCU EFM8BB21F16Gを採用し、スロットルに高速で応答します。
- 電源投入時にスロットル信号を自動検出します。パルス幅1～2 msの標準スロットル方式に対応し、停止を防ぐ安全機構を内蔵しています。
- ESC制御アルゴリズム、最適化した基板回路、消磁補償技術を組み合わせ、モーターを滑らかかつ正確に動かします。
- 温度保護、低回転時の出力保護、安全始動保護などを備えます。
- 高効率5 V BECを搭載し、受信機とサーボへ安定した5 Vを供給します。
- PWMとDshot300に対応し、RadioLink A560、SU27、D460および他社の固定翼機に幅広く対応します。
- モータータイミングを調整でき、さまざまなモーターに対応します。

## 6. 注意事項

<span id="re15a-p6-u03" data-translation-unit="re15a-p6-u03"></span>

:::caution[注意]
- ESC内部の電子部品を自分で分解しないでください。恒久的な破損や情報の消失につながります。
- ESCとモーターを試験するときは、機体にプロペラを取り付けないでください。
- ひび割れや破損のあるバッテリーパックを使用しないでください。
- 過熱しやすいバッテリーパックを使用しないでください。
- 規格に適合しないケーブル絶縁材を使用しないでください。
- 規格に適合しないケーブルコネクターを使用しないでください。
- バッテリー電圧はESCの動作電圧範囲を超えてはいけません。
- バッテリーの極性に注意してください。極性を誤るとESCが破損します。
- ESCを湿気にさらしたり、過度に露出した場所に置いたりしないでください。
- モーター動作中にバッテリーを抜かないでください。大きなピーク電流が発生し、ESCが破損します。
- ESCの外側を物で覆わないでください。できるだけ通風・放熱の良い場所に設置してください。
:::
