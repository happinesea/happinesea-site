## 1.1 安全上の注意

1. 雨天の屋外で操作したり、水たまりの中を走行したり、視界が制限される場所で使用したりしないでください。水や雪などの水分がシステムのいずれかの部品に入ると、誤動作や操縦不能が発生するおそれがあります。

2. 人や道路の近くでは操作しないでください。

3. 本製品は玩具ではなく、14歳未満のお子様には適していません。大人は製品をお子様の手の届かない場所に保管し、お子様がいる場所で操作するときは十分注意してください。

4. 使用時は地域の法令および規則を厳守してください。

5. 送信機と受信機の電源を入れる前に、送信機のスロットルトリガーがニュートラル位置にあることを必ず確認してください。電源を切る前に、エンジンが停止していること、またはモーターが停止していることを必ず確認してください。

6. 先に受信機と制御機器の電源を切り、その後で送信機の電源を切ってください。逆の順序で操作すると、操縦不能や事故の原因になります。

7. 長期間使用しない場合は、必ずバッテリーを取り外してください。長期間装着したまま、または過放電したバッテリーは液漏れや腐食が起こりやすく、送信機の基板や金属接点を損傷し、短絡や部品故障などの安全上の危険を生じるおそれがあります。

8. 注記: RC8PのType-Cポートの入力電圧は5 Vです。Type-CポートでRC8Pを充電または給電する場合、入力電圧は5 Vを超えないようにしてください。超えると基板が損傷します。

### 1.2.4 RC8Pの電源

RC8Pの動作電圧は3.4～4.2 Vで、18650バッテリーが付属します。バッテリーを装着して送信機の電源を入れます。Type-CケーブルでPCまたはモバイルバッテリーに接続して充電できます。Type-Cポートの入力は5 Vなので、充電または一時的な給電に5 Vを超える電圧を使用しないでください。

Type-Cケーブルを接続すると、電源ボタンの赤色ランプは充電中、青色ランプは充電完了を示します。バッテリーを装着せずに接続した場合、電源ボタンは赤と青で交互に点滅します（青は長く、赤は短く点滅します）。バッテリーカバーを矢印方向へ平らにスライドして放すと、カバーが開きます。18650バッテリーは、突起のあるプラス端子を外側に向けて装着し、カバーを押し下げて矢印方向へスライドして閉じます。

## 1.3 R8FGの概要

<span id="section-1.3.1"></span>

### 1.3.1 R8FGの特長

RC8P送信機には、2.4 GHz・8チャンネル、ジャイロ内蔵、高電圧サーボ対応のR8FG受信機が付属します。FHSSおよび67チャンネル疑似ランダム周波数ホッピングにより、優れた耐干渉性能を備えます。R8FGはPWMおよびSBUS信号を出力できます。

::: note
注記: R8FGのジャイロ機能は初期状態で無効です（緑色ランプ）。有効にする方法は「1.3.5 R8FGのジャイロ機能」を参照してください。
:::

受信機図の`Signal / VCC / GND`は信号/電源/グランドを示します。CH1はステアリング、CH2はスロットル、CH3～CH7は補助、CH8は補助/SBUSです。`Reserved (No function)`は予約部（機能なし）、`Binding Button (ID SET)`はバインドボタン、`Telemetry Port of Model Battery Voltage`はモデルバッテリー電圧のテレメトリーポートです。別図の`Antenna`はアンテナ、`Coaxial Cable`は同軸ケーブルを示します。

### 1.3.2 バインド

RC8Pと付属のR8FGは初期状態でバインド済みです。RC8PとR8FGの電源を入れ、画面上部に電波塔が表示されればバインド済みです。

<ManualFigure
  src="/assets/radiolink/rc8p/full-manual/image-033.webp"
  width={479}
  height={436}
  alt="RC8P 1.3.2"
  caption="RC8P 1.3.2"
  figureId="RC8P-P010-I03"
/>

新しい受信機を使用する場合は、受信機ごとのIDコードを送信機に登録するため、使用前にバインドします。バインド後、IDコードは送信機に保存されるため、再バインドは不要です。

1. 送信機と受信機を約60 cmまで近づけます。近すぎると信号が遮断され、バインド失敗や信号喪失の原因になることがあります。

2. 送信機と受信機の電源を入れます。R8FGのLEDがゆっくり点滅します。

3. 受信機側面の黒いバインドボタン（ID SET）を1秒を超えて押して放します。LEDが速く点滅し、バインド中であることを示します。

4. LEDが点滅を止めて点灯状態になるとバインド完了です。送信機LCD上部に電波塔が表示されます。失敗した場合はLEDがゆっくり点滅し続けるため、手順を繰り返してください。

R8FG以外のR7FG、R6FGなどを使用する場合は、RF設定メニューで「FHSS V1」を選択してからバインドします。通信プロトコルを誤って選ぶとバインドに失敗します。詳細は「2.7 RF設定」を参照してください。

### 1.3.4 R8FGの動作モード

R8FGには通常PWM、PWM+SBUS、PWM+ジャイロ、PWM+SBUS+ジャイロの4動作モードがあります。

| 項目      | PWM | PWM+SBUS | PWM+ジャイロ | PWM+SBUS+ジャイロ | 用途         |
| --------- | --- | -------- | ------------ | ----------------- | ------------ |
| LED表示色 | 緑  | 青       | 赤           | 青/紫             | —            |
| CH1       | PWM | PWM      | PWM          | PWM               | ステアリング |
| CH2       | PWM | PWM      | PWM          | PWM               | スロットル   |
| CH3       | PWM | PWM      | PWM          | PWM               | 補助         |
| CH4       | PWM | PWM      | PWM          | PWM               | 補助         |
| CH5       | PWM | PWM      | PWM          | PWM               | 補助         |
| CH6       | PWM | PWM      | PWM          | PWM               | 補助         |
| CH7       | PWM | PWM      | PWM          | PWM               | 補助         |
| CH8       | PWM | S.BUS    | PWM          | S.BUS             | 補助         |

TELEMETRYポート（+ / -）は2S～8Sモデルバッテリー電圧の測定専用です。受信機への給電には使用できません。

- ジャイロのオン/オフ: 2秒以内にバインドボタンを3回短く押します。

- ジャイロ位相: 2秒以内にバインドボタンを2回短く押します。

- SBUSのオン/オフ: バインドボタンを1回短く押します。

### 1.3.5 R8FGのジャイロ機能

R8FGはソフトウェアフィルターとPIDアルゴリズムを備えた内蔵ジャイロにより、車体の安定性を補正します。初期状態ではジャイロはオフです。電源投入時は自己チェックのためR8FGを動かさないでください。赤色LEDが消灯している場合はジャイロが無効です。バインドボタンを1秒未満の間隔で3回押すと赤色LEDが3回点滅し、ジャイロが有効になります。

ジャイロ有効時、送信機を操作していなくてもサーボが補正のために振動することがあります。振動が続く場合は、サーボをSBUSチャンネルからPWMチャンネルへ接続し直すか、ジャイロ（GYRO）メニューで感度を下げてください。

ジャイロ補正が不要な場合はジャイロをオフにできます。通常のサーボはPWM入力のみに対応するため、受信機を動かしていないのにサーボが振動し続ける場合は、接続チャンネルとジャイロ感度を確認してください。

車を右または左へ向け、ジャイロの方向を確認します。車を右へ向けたときホイールが左へ動き、左へ向けたとき右へ動けば正方向です。逆の場合はバインドボタンを2回押し、赤色LEDが2回点滅することを確認します。

ジャイロ有効後、ジャイロメニューで感度を調整できます。Encoder（スクロールキー）、VRノブ、DL1を割り当てられます。100%が最大感度、0%が感度ゼロです。詳細は「2.15 ジャイロ」を参照してください。

### 1.3.6 受信機アンテナの取り付け

アンテナを誤って取り付けると信号品質が低下します。

1. 2本のアンテナを重ねないでください。互いに90°の角度にします。

<ManualFigure
  src="/assets/radiolink/rc8x/full-manual/image-065.webp"
  width={606}
  height={332}
  alt="RC8P 1.3.6"
  caption="RC8P 1.3.6"
  figureId="RC8P-P013-I01"
/>

2. 金属物の近くに置かないでください。導体板の反射で信号が大きく劣化します。

3. 地面と平行にせず、地面に対して垂直に配置してください。

4. 大型モデルではモデルの両側にアンテナを配置してください。

5. 金属導体およびカーボンファイバーから少なくとも0.5インチ離し、過度に曲げないでください。

6. モーター、ESCなどの干渉源から離してください。

7. 取り付け時はスポンジやフォームを使用して振動を防いでください。

8. 受信機は精密電子部品を含むため、強い振動と高温を避けてください。

9. R/C用の防振フォームまたはゴム布で受信機を保護してください。受信機を密閉したビニール袋に入れると、操縦不能の原因となり得る湿気やほこりを防げます。

受信機アンテナの取り付けの詳細: https://www.radiolink.com/receiver_antenna_installation

### 1.3.7 RSSIテスト

車やボートの操作距離が短い場合は、次の手順でRSSI値を確認します。

<ManualFigure
  src="/assets/radiolink/rc8p/full-manual/image-042.webp"
  width={479}
  height={535}
  alt="RC8P 1.3.7"
  caption="RC8P 1.3.7"
  figureId="RC8P-P014-I02"
/>

1. 送信機と受信機の電源を同時に入れます。接続できない場合は再バインドします。接続されると送信機画面に電波塔が表示され、ホーム画面にRSSI値が表示されます。RSSI値は送信機と受信機の距離に応じて変化します。

<ManualFigure
  src="/assets/radiolink/rc8p/full-manual/image-043.webp"
  width={2276}
  height={1378}
  alt="RC8P 1.3.7"
  caption="RC8P 1.3.7"
  figureId="RC8P-P014-I01"
/>

2. 送信機と受信機のアンテナを平行にし、約60 cm離して両方をまっすぐにします。RSSIが0～-30 dBmの範囲なら正常です。0に近いほど信号が強いことを示します。

異常な信号強度の場合は、送信機と受信機のアンテナが損傷していないか確認してください。損傷していれば交換します。損傷がない場合は受信機を交換して送信機または受信機の故障を確認してください。それでも解決しない場合は `after_service@radiolink.com.cn` へ連絡してください。
