## 1. 注意事項

<span id="trainercable-p3-u04" data-translation-unit="trainercable-p3-u04"></span>

:::caution[注意]
1. 機体の電源が切れていることを確認してください。
2. 教官側と生徒側の送信機を同じモデルタイプに設定してください。
3. 教官側と生徒側の送信機が他の機体に接続されていないことを確認してください。
:::
