## 1. 概要

<span id="er16-w011" data-translation-unit="er16-w011"></span>

RadioLink ER16受信機は、オープンソースプロジェクトExpressLRSを基に開発された、2.4 GHzの受信機です。ExpressLRS 2.4 GHzモジュールおよび送信機に対応します。LoRa変調技術を採用し、高い受信感度、強い耐干渉性、長い到達距離を特長としています。世界的に開放されている2.4 GHz周波数帯で動作します。

:::note[原典について]
原典は2.4 GHz帯を世界的に開放された帯域と説明していますが、この記述は日本国内の法令適合や使用許可を確認したことを意味しません。原典の説明と国内での使用可否を区別してください。
:::

## 2. 仕様

<span id="er16-w016" data-translation-unit="er16-w016"></span>

- 寸法：20 × 12.5 mm
- 重量：1.2 g
- 動作電圧：4～9 V
- 周波数帯：2.4 GHz ISM
- テレメトリー出力：22 dBm
- アンテナコネクター：IPEX MHF 1 × 2
- 出力プロトコル：CRSF
- 対応送信機：2.4 GHz ExpressLRSモジュールに対応するすべての送信機

<span id="er16-w017" data-translation-unit="er16-w017"></span>

## 3. LED表示

<span id="er16-w018" data-translation-unit="er16-w018"></span>

- 常灯：バインド成功／送信信号を受信中
- 素早い2回点滅：バインド状態
- 遅い点滅：送信信号を受信していない状態
- 速い点滅：Wi-Fi更新状態

<span id="er16-w019" data-translation-unit="er16-w019"></span>

## 4. バインド

<span id="er16-w020" data-translation-unit="er16-w020"></span>

（1）電源投入の間隔を1.5秒未満にして、ER16受信機の電源を連続して3回入れます。

<span id="er16-w021" data-translation-unit="er16-w021"></span>

（2）受信機の表示灯が2回点滅し、バインド状態に入ったことを示します。

<span id="er16-w022" data-translation-unit="er16-w022"></span>

（3）ExpressLRSの送信機またはモジュールのBINDボタンを押します。

<span id="er16-w023" data-translation-unit="er16-w023"></span>

（4）受信機の表示灯が常灯し、バインド成功を示します。

<span id="er16-w024" data-translation-unit="er16-w024"></span>

（5）バインド成功後、プログラムはペアリングした送信機器を記録します。次回の電源投入時には最後のバインド記録が復元されるため、受信機の電源を入れるたびにバインドする必要はありません。

<span id="er16-w025" data-translation-unit="er16-w025"></span>

## 5. Betaflightフライトコントローラーの設定

<span id="er16-w027" data-translation-unit="er16-w027"></span>

（1）ER16をBetaflightフライトコントローラーの任意のシリアルポートへ接続します。以下では、UART6を例に設定を説明します。

<span id="er16-w028" data-translation-unit="er16-w028"></span>

<ManualFigure src="/assets/radiolink/er16-2-4g/web-ja-v1/er16-p4-f1.jpeg" width={650} height={176} figureId="er16-p4-f1" alt={"ER16とBetaflightフライトコントローラーの接続図。GND同士、5V同士、ER16のTXとフライトコントローラーのRX、ER16のRXとフライトコントローラーのTXを接続しています。"} caption={"ER16とBetaflightフライトコントローラーの接続図。GND同士、5V同士、ER16のTXとフライトコントローラーのRX、ER16のRXとフライトコントローラーのTXを接続しています。"} />

<span id="er16-w029" data-translation-unit="er16-w029"></span>

（2）フライトコントローラーをパソコンに接続します。Betaflight Configuratorを開いて接続し、ポート（Ports）メニューをクリックして、UART6の「Serial RX」を有効にします。

<span id="er16-w030" data-translation-unit="er16-w030"></span>

<ManualFigure src="/assets/radiolink/er16-2-4g/web-ja-v1/er16-p4-f2.jpeg" width={1147} height={510} figureId="er16-p4-f2" alt={"BetaflightのPorts画面。UART6の「Serial Rx」を有効にした例です。"} caption={"原典4頁の図"} />

BetaflightのPorts画面。UART6の「Serial Rx」を有効にした例です。

図中の注意には、すべての組み合わせが有効とは限らないこと、内容を理解せずに最初のシリアルポートのMSPを無効にしないことが示されています。VTXテーブル設定に関する警告もありますが、原画像では右端の文が途中で切れています。

:::note[原典について]
Ports画面の警告は原画像の右端で切れているため、欠けた文を推測で補っていません。画像は原典の設定例であり、現在のUI版や警告全文を保証するものではありません。
:::

<span id="er16-w031" data-translation-unit="er16-w031"></span>

（3）受信機（Receiver）メニューをクリックします。受信機モード（Receiver Mode）を「Serial (via UART)」にし、シリアル受信機プロバイダー（Serial Receiver Provider）を「CRSF」に設定します。

<span id="er16-w032" data-translation-unit="er16-w032"></span>

<ManualFigure src="/assets/radiolink/er16-2-4g/web-ja-v1/er16-p4-f3.jpeg" width={800} height={231} figureId="er16-p4-f3" alt={"受信機設定画面。「Receiver Mode」は「Serial (via UART)」、「Serial Receiver Provider」は「CRSF」です。"} caption={"原典4頁の図"} />

受信機設定画面。「Receiver Mode」は「Serial (via UART)」、「Serial Receiver Provider」は「CRSF」です。

図中の注意：受信機用UARTはPortsタブで「Serial Rx」に設定する必要があります。下のドロップダウンから正しいデータ形式を選択してください。

## 7. ファームウェアの更新

<span id="er16-w039" data-translation-unit="er16-w039"></span>

この例では、公式公開ファームウェアをダウンロードした後、ELRSでファームウェアをコンパイルする方法を使用します。初期ファームウェア版はExpressLRS-3.3です。

:::note[原典について]
原典の初期ファームウェア版はExpressLRS-3.3ですが、後続の展開・コンパイル例はExpressLRS-2.0.1、リリースページ画像はV3.2.1です。いずれも原典の例として保持し、現在の最新版・実機導入版と読み替えていません。送受信機の版を合わせる注意と、3.xxの別Device指定を保持しています。
:::

<span id="er16-w040" data-translation-unit="er16-w040"></span>

:::caution[注意]
（1）ELRSの公式ファームウェアをダウンロードします。最新版、または古い版を選択できます。送信機と受信機の版は、同じものにそろえることを推奨します。版が一致しないと、不具合が発生する場合があります。ファームウェアのダウンロード先：

https://github.com/ExpressLRS/ExpressLRS/releases
:::

（12）コンパイラーがシリアルポート番号を認識します。「Manual serial device selection」で、認識されたシリアルポート番号COMxxを選択します。空欄のままにすることもでき、その場合は後のダウンロード時にツールが自動検出します。
