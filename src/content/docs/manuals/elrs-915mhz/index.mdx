## 1. はじめに

<span id="elrs915receiver-p3-u02" data-translation-unit="elrs915receiver-p3-u02"></span>

ELRS 915MHzは、オープンソースプロジェクトExpressLRSを基に開発された受信機です。

<span id="elrs915receiver-p3-u03" data-translation-unit="elrs915receiver-p3-u03"></span>

ExpressLRS 915MHzモジュールおよび送信機に対応します。

<span id="elrs915receiver-p3-u04" data-translation-unit="elrs915receiver-p3-u04"></span>

LoRa変調技術を採用し、高い受信感度、強い耐干渉性能、長い制御距離を特徴とします。

## 2. 仕様

<span id="elrs915receiver-p3-u07" data-translation-unit="elrs915receiver-p3-u07"></span>

寸法：20×11 mm（0.79×0.43インチ）。

<span id="elrs915receiver-p3-u08" data-translation-unit="elrs915receiver-p3-u08"></span>

重量：0.9 g（0.03 oz）。

<span id="elrs915receiver-p3-u09" data-translation-unit="elrs915receiver-p3-u09"></span>

チャンネル数：16チャンネル。

<span id="elrs915receiver-p3-u10" data-translation-unit="elrs915receiver-p3-u10"></span>

アンテナ長：水平エレメントの幅は約145 mm、給電ケーブルは110 mm。

<span id="elrs915receiver-p3-u11" data-translation-unit="elrs915receiver-p3-u11"></span>

出力周波数：915 MHz（FCC）／868 MHz（EU）。

<span id="elrs915receiver-p3-u12" data-translation-unit="elrs915receiver-p3-u12"></span>

プロトコル：CRSF。

<span id="elrs915receiver-p3-u13" data-translation-unit="elrs915receiver-p3-u13"></span>

スペクトラム拡散方式：LoRa（CSS）。

<span id="elrs915receiver-p3-u14" data-translation-unit="elrs915receiver-p3-u14"></span>

送信出力：100 mW（20 dBm）。

<span id="elrs915receiver-p3-u15" data-translation-unit="elrs915receiver-p3-u15"></span>

受信感度：-123.5 dBm。

<span id="elrs915receiver-p3-u16" data-translation-unit="elrs915receiver-p3-u16"></span>

入力電圧：DC 4～9 V。

<span id="elrs915receiver-p3-u17" data-translation-unit="elrs915receiver-p3-u17"></span>

動作電流：45 mA未満。

<span id="elrs915receiver-p3-u18" data-translation-unit="elrs915receiver-p3-u18"></span>

更新レート：500 Hz／25 Hz。

<span id="elrs915receiver-p3-u19" data-translation-unit="elrs915receiver-p3-u19"></span>

データインターフェース：ELRSインターフェース。

<span id="elrs915receiver-p3-u20" data-translation-unit="elrs915receiver-p3-u20"></span>

アンテナコネクター：IPEXソケット。

<span id="elrs915receiver-p3-u21" data-translation-unit="elrs915receiver-p3-u21"></span>

アンテナ形式：T字型ダイポールアンテナ。

<span id="elrs915receiver-p3-u22" data-translation-unit="elrs915receiver-p3-u22"></span>

アンテナインピーダンス：50 Ω。

<span id="elrs915receiver-p3-u23" data-translation-unit="elrs915receiver-p3-u23"></span>

ハードウェアインターフェース：4ピン 1.0ソケット／4ピン 2.54パッド。

<span id="elrs915receiver-p3-u24" data-translation-unit="elrs915receiver-p3-u24"></span>

制御距離：最大5,000 m（開けた干渉のない条件での試験値）。実際の制御距離は飛行環境によって変わる場合があります。

<span id="elrs915receiver-p3-u25" data-translation-unit="elrs915receiver-p3-u25"></span>

原典印刷ページ：2

<span id="elrs915receiver-p4-u01" data-translation-unit="elrs915receiver-p4-u01"></span>

テレメトリー：フライトコントローラーとGPSに接続すると、電圧、電流、緯度、経度、衛星数などのテレメトリーに対応します。

<span id="elrs915receiver-p4-u02" data-translation-unit="elrs915receiver-p4-u02"></span>

機体バッテリー電圧テレメトリーの範囲：フライトコントローラーの設定によります。

## 4. バインド

<span id="elrs915receiver-p4-u13" data-translation-unit="elrs915receiver-p4-u13"></span>

(1) ELRS 915MHz受信機の電源を連続して3回入れます。各回の電源投入間隔は1.5秒未満にします。

<span id="elrs915receiver-p4-u14" data-translation-unit="elrs915receiver-p4-u14"></span>

(2) 受信機のインジケーターが2回点滅し、バインド状態に入ったことを示します。

<span id="elrs915receiver-p4-u15" data-translation-unit="elrs915receiver-p4-u15"></span>

(3) ExpressLRS送信機（送信機本体またはモジュール）のBINDボタンを押します。

<span id="elrs915receiver-p4-u16" data-translation-unit="elrs915receiver-p4-u16"></span>

(4) 受信機のインジケーターが点灯状態になり、バインド成功を示します。

<span id="elrs915receiver-p4-u17" data-translation-unit="elrs915receiver-p4-u17"></span>

(5) バインドに成功すると、プログラムがペアリングした送信機を記録します。次回の電源投入時には最後のバインド記録が復元されるため、受信機の電源を入れるたびにバインドする必要はありません。

<span id="elrs915receiver-p4-u18" data-translation-unit="elrs915receiver-p4-u18"></span>

## 5. Betaflightフライトコントローラーの設定

<span id="elrs915receiver-p4-u19" data-translation-unit="elrs915receiver-p4-u19"></span>

(1) ELRS 915MHz受信機をBetaflightフライトコントローラーの任意のシリアルポートに接続します。以下ではUART6を例に設定を示します。

<span id="elrs915receiver-p4-f1-unit" data-translation-unit="elrs915receiver-p4-f1-unit"></span>

<ManualFigure src="/assets/radiolink/elrs-915mhz/web-ja-v1/elrs915receiver-p4-f1.jpeg" width={2057} height={617} figureId="elrs915receiver-p4-f1" alt={"ELRS 915MHz受信機とBetaflightフライトコントローラーの配線例。RX/TXの交差接続と5V/GNDを表示"} caption={"ELRS 915MHz受信機とBetaflightフライトコントローラーの配線例。RX/TXの交差接続と5V/GNDを表示"} />

<span id="elrs915receiver-p4-u20" data-translation-unit="elrs915receiver-p4-u20"></span>

原典印刷ページ：3

<span id="elrs915receiver-p5-u01" data-translation-unit="elrs915receiver-p5-u01"></span>

(2) フライトコントローラーをパソコンに接続し、Betaflight Configuratorを開いて接続します。Portsメニューを開き、UART6のSerial RXを有効にします。

<span id="elrs915receiver-p5-f1-unit" data-translation-unit="elrs915receiver-p5-f1-unit"></span>

<ManualFigure src="/assets/radiolink/elrs-915mhz/web-ja-v1/elrs915receiver-p5-f1.jpeg" width={1147} height={510} figureId="elrs915receiver-p5-f1" alt={"Betaflight ConfiguratorのPortsタブ。UART6のSerial RXを強調表示"} caption={"Betaflight ConfiguratorのPortsタブ。UART6のSerial RXを強調表示"} />

<span id="elrs915receiver-p5-u02" data-translation-unit="elrs915receiver-p5-u02"></span>

(3) Receiverメニューを開き、受信機モードにSerial (via UART)を選択し、シリアル受信機プロバイダーにCRSFを設定します。

<span id="elrs915receiver-p5-f2-unit" data-translation-unit="elrs915receiver-p5-f2-unit"></span>

<ManualFigure src="/assets/radiolink/elrs-915mhz/web-ja-v1/elrs915receiver-p5-f2.jpeg" width={800} height={231} figureId="elrs915receiver-p5-f2" alt={"Betaflight ConfiguratorのReceiver設定。Serial (via UART)とCRSFを表示"} caption={"Betaflight ConfiguratorのReceiver設定。Serial (via UART)とCRSFを表示"} />

## 6. APMフライトコントローラーの設定

<span id="elrs915receiver-p5-u04" data-translation-unit="elrs915receiver-p5-u04"></span>

(1) ELRS 915MHz受信機をAPMフライトコントローラーのTELEM1ポートに接続します。以下の例ではRadioLink CrossFlightフライトコントローラーのTELEM1ポートを使用します。

<span id="elrs915receiver-p5-f3-unit" data-translation-unit="elrs915receiver-p5-f3-unit"></span>

<ManualFigure src="/assets/radiolink/elrs-915mhz/web-ja-v1/elrs915receiver-p5-f3.jpeg" width={3373} height={1428} figureId="elrs915receiver-p5-f3" alt={"受信機とRadioLink CrossFlightのTELEM1を接続する配線図。5V、TX、RX、GNDのラベルを表示"} caption={"受信機とRadioLink CrossFlightのTELEM1を接続する配線図。5V、TX、RX、GNDのラベルを表示"} />

<span id="elrs915receiver-p5-u05" data-translation-unit="elrs915receiver-p5-u05"></span>

原典印刷ページ：4

<span id="elrs915receiver-p6-u01" data-translation-unit="elrs915receiver-p6-u01"></span>

(2) CrossFlightフライトコントローラーをパソコンに接続し、Mission Plannerで次の3つのパラメーターを設定します。SERIAL1_BAUDを115、SERIAL1_OPTIONSを0、SERIAL1_PROTOCOLを23に設定します。
