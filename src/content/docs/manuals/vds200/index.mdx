## 第1章 VDS200の紹介

<span id="vds200-text-003" data-translation-unit="vds200-text-003"></span>

### 1.1 VDS200の特長

<span id="vds200-text-004" data-translation-unit="vds200-text-004"></span>

VDS200はコアレスモーターを搭載したドローンサッカー用機体です。ジャイロ、加速度センサー、気圧計による慣性航法と、カルマンフィルターによる高度保持アルゴリズムにより、高速性と安定性の両立を実現し、初心者の操作の難しさを大幅に軽減して、誰もが安定した飛行を楽しめます。高度保持（低速）モード、高度保持（高速）モード、安定モードに対応しています。

<span id="vds200-text-005" data-translation-unit="vds200-text-005"></span>

RTF版には、スマートフォンアプリでパラメーターを調整できる8チャンネル送信機が付属します。

<span id="vds200-text-006" data-translation-unit="vds200-text-006"></span>

モーターには独自のソフトウェアによるノイズ低減技術を採用し、VDS200の飛行中の騒音をなくすとともに、モーターの寿命を大幅に延ばします。

<span id="vds200-text-007" data-translation-unit="vds200-text-007"></span>

VDS200は従来のオイラー角の制約を克服し、回転ベクトルアルゴリズムを採用することで、高度保持モードでの高速上昇・下降飛行を実現しています。操縦者は空中でドローン競技を楽しめます。

<span id="vds200-text-008" data-translation-unit="vds200-text-008"></span>

### 2.6 T8S送信機のスティック校正

<span id="vds200-text-108" data-translation-unit="vds200-text-108"></span>

T8Sのスティックが中央位置にない場合や、操作量に大きな差がある場合は、校正が必要です。T8Sのスティック校正方法は次のとおりです。

<span id="vds200-text-109" data-translation-unit="vds200-text-109"></span>

送信機の電源を切った状態で、両スティックを中央位置にします。ラダートリムボタン（左側の1番目のボタン）を押しながら、送信機の電源を入れます。4個の緑色LEDが点滅を始めると、T8Sの校正準備ができています。

<span id="vds200-f11-unit" data-translation-unit="vds200-f11-unit"></span>

<ManualFigure src="/assets/radiolink/vds200/web-ja-v1/vds200-f11.jpeg" width={647} height={453} figureId="vds200-f11" alt={"校正開始時にT8Sの左側ラダートリムボタンと電源ボタンを同時に押す写真。"} caption={"校正開始時にT8Sの左側ラダートリムボタンと電源ボタンを同時に押す写真。"} />

<span id="vds200-text-110" data-translation-unit="vds200-text-110"></span>

2. 可動範囲の校正：両スティック（CH1～4）を最大位置と最小位置まで動かし、中央位置に戻します（下図参照）。

<span id="vds200-f12-unit" data-translation-unit="vds200-f12-unit"></span>

<ManualFigure src="/assets/radiolink/vds200/web-ja-v1/vds200-f12.jpeg" width={959} height={610} figureId="vds200-f12" alt={"両スティックを外周いっぱいに動かす矢印。Rudder（ラダー）、Throttle（スロットル）、Elevator（エレベーター）、Aileron（エルロン）の各トリムボタンの位置を示します。"} caption={"両スティックを外周いっぱいに動かす矢印。Rudder（ラダー）、Throttle（スロットル）、Elevator（エレベーター）、Aileron（エルロン）の各トリムボタンの位置を示します。"} />

<span id="vds200-text-111" data-translation-unit="vds200-text-111"></span>

3. 中央位置の校正：スティックを中央位置に置き、ラダートリムボタン（左側の2番目のボタン）を押すと、「DD」という音が鳴ります。点滅していた4個のLEDが緑色の点灯に変わると、スティック校正完了です。

<span id="vds200-f13-unit" data-translation-unit="vds200-f13-unit"></span>

<ManualFigure src="/assets/radiolink/vds200/web-ja-v1/vds200-f13.jpeg" width={637} height={446} figureId="vds200-f13" alt={"中央位置校正でラダートリムの2番目のボタンを押す写真。開始時とは別のボタンを押しています。"} caption={"中央位置校正でラダートリムの2番目のボタンを押す写真。開始時とは別のボタンを押しています。"} />
