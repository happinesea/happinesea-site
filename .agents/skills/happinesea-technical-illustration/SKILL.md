name: happinesea-technical-illustration
description: Prepare evidence-backed editorial diagrams for happinesea articles, with editable source, offline raster exports, accessibility text, and a separate adoption decision.
---

1. Record the reader question, audience, diagram type, and exact source locator for each label, relationship, and quantity. For a parallel comparison, use peer elements. Use arrows only for relationships the sources establish. Mark a schematic as 模式図 and state whether it is to scale where relevant.
2. Keep editorial categories broad when the topic is sensitive. Exclude operational procedures, actionable design details, inferred quantities, and unsupported causal links. Use the article's confirmed terminology and document uncertainty instead of filling gaps.
3. Make a self-contained editable original using the existing brand palette and local fonts. Export PNG and WebP from the same original. Provide Japanese ALT that states the information conveyed, a short caption with source locators, and the rights or provenance note.
4. Inspect the source and both exports at desktop and a 360px display width. Check text size, contrast, clipping, reading order, and that color is not the only cue. Verify exports open offline, have matching dimensions, and contain no remote resources. If text cannot be readable at display width, provide a compact layout.
5. Keep a candidate outside deployed asset directories and article Markdown until an editor explicitly approves adoption. Record the placement, ALT, caption, and source provenance at that decision. Keep unpublished material in a local review folder.
