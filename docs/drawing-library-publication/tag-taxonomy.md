大分類は機体の設計図／エンジン・製作資料。ユーザーの主導線は複数タグです。タグは原題、パス、member名、既存公開タイトル、明示された型式に基づきます。各recordにconfidenceと一致した根拠を保持します。航模だけではRC模型と断定せず、模型用資料へnormalizeします。資料名が不明な場合は名称・機種未確認を表示します。材質や作者、ライセンスを補完しません。
