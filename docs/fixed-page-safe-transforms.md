## Asset and manual fidelity

All six source fixed pages were freshly HTTP 200; body and rendered-HTML digests are recorded in `src/data/legacy-fixed-page-resolution.json`. All 30 source content images from RC4GS, the old landing, Byme-A and Style Guide were fetched, decoded and inspected. All 32 GIF frames were reviewed; `Without GYRO` / `With GYRO` orientation and oval driving remain in the original animation, not a generated replacement. Japanese image alternatives describe visible content only.

RC6GS V3 was fetched from the actual `wpdmdl=2032` query, not selected by a similar filename. It contains 47 PDF pages; the rendered cover states RC6GS V3. Received bytes: 9,946,163; SHA-256: `9d2c5485f2ebce5226fcf20b75a33bcc169a6305e3e3d51767aa80b0058c6737`. The exact bytes are published locally. No claim of retranslation, technical correction, full-page editorial review or equivalence with another manual is made.

The RC6GS Amazon ordinary href is already in the source and matches iframe ASIN B08NVHK22H; it returned HTTP 404 to this client. This existing source problem is reported, not replaced with a guessed book. The iframe is explicitly replaced by that ordinary link; advertising/tracking code is not transplanted. Widget metadata with actual values (version, captured download count, size, file count and creation/update dates), source text and copyright notice are retained. Empty `[featured_image]` / `[expire_date]` plugin placeholders have no source value and are explicitly omitted from the static representation; no expiry date is invented. Captured download count is historical, not a live counter.

The source download-tag archive link is retained. It is not declared statically compatible. The original query URL remains a browser handoff using the existing verified-download implementation; a no-JavaScript HTTP response is HTML, not the PDF, and remains a domain cutover gate.
