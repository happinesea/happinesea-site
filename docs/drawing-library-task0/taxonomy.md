# Taxonomy proposal

分類単位はfileでなく機体・資料record。53 root archiveとF-14 directoryを42候補recordに整理した。
同じ機種名のgroupingは暫定であり、内容・版・設計者の確認前に重複削除しない。

| 初期カテゴリ       | source record候補 | 現在の根拠                                                                       |
| ------------------ | ----------------- | -------------------------------------------------------------------------------- |
| 機体の設計図       | 37                | 機体型式・軽飛行機・水上機・回転翼機・紙飛行機・未同定図面                       |
| エンジン・製作資料 | 5                 | kj66資料、パルスエンジン、ジェット製作手引き、小型ジェット製作図、模型の基礎資料 |

既存FIGHTERを加えると機体38、技術資料5の計43。最小カテゴリは5件あり、細分化を避けられる。
実機資料の疑いがあるものはカテゴリ掲載前にRC適用範囲を確認する。上記は公開件数ではない。

ジェット機型の型式は多いが、実機の形状と模型の推進方式は同じとは限らない。
初期filterは上記2カテゴリだけとし、`ジェット機型`等はowner確認後の任意tag候補にする。
回転翼2件、複葉機1件、水上機1件は独立カテゴリにせず上位の機体カテゴリへ統合する。
小型・室内、グライダー、スケールの詳細分類はfilenameだけで全量確定できないため未設定。
技術資料の内訳もカテゴリを増やさず、engine型式や製作資料の種別をmetadataに保持する。

sourceそのもののextension分布は以下。archive内部extensionはinventoryの各archiveに記録し、container違いの重複を含むため独立binary数と混同しない。

| extension | files |       bytes |
| --------- | ----: | ----------: |
| .rar      |    44 | 190,889,898 |
| .zip      |    10 |  33,070,901 |
| .pdf      |    12 |   6,072,312 |
| .jpg      |     3 |      73,581 |
| .gif      |     2 |     297,573 |

archive54のうち52は一覧成功、1は分割archive review、1は後続volume単独の一覧失敗。記録memberは367件。
CAD（DWG/DXF/STEP）、PDF、Office文書、画像、nested archive、Thumbs.dbを含む。
Thumbs.dbは今後の公開対象から除外する。nested archive内部は今回recursive展開・一覧を実施していない。
文字化けしたZIP内部名は原文観測値を保持し、encoding修正候補を公開slugやidentityの確定根拠にしない。
