# RC8X 後続Task候補

今回の対象は商品ページと、既存オンラインマニュアルの第1章・第2章だけ。メーカー確認後に次を扱う。

## 日本語PDF

- 3–4ページの安全表示、適合表示、仕様表を現行Firmwareと照合して再配置する。
- 10ページの受信機動作モード図、12ページのバインド後確認図を章内へ追加する。
- 11ページの各種テレメトリーケーブル単体図を接続手順ごとに分割する。
- 14ページのQRコード、保証・問い合わせ案内は、公開先と国内サポート導線をメーカー確認後に反映する。
- 日本語PDFで扱われない詳細画面は、英語版User Manualと現行Firmware実機画面を照合してから全節へ展開する。

## 公式商品素材

- カラー、持ち方、ホイール左右反転、バッテリーボックス、各受信機の追加画像。
- 公式ページのアニメーション素材。静止画で説明できない操作に限って採用を検討する。

## 公式動画

- スロットルカーブ以外の走行調整: ESCキャリブレーション、信号ロスト、遅延設定、近距離信号試験。
- 操作部: ホイール交換、ホイールばね調整、左手用変更の詳細。
- カスタマイズ: 壁紙、音声、チャンネル割当。
- 車種別設定: ニトロ車、ボート、ブルドーザー、クローラーなど。
- 製品紹介・デモ動画の重複整理と、日本語字幕・説明文のメーカー確認。

参照URLと取得日は `src/data/manual-sections.json` および `src/data/publication-assets/rc8x.json` に保持する。
